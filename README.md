# ひと問

短い時間で始められる、応用情報技術者試験の学習アプリです。1問ずつ解き、段階ヒントを使い、後から解き直せます。静的ファイルだけで動作し、GitHub Pagesで無料公開できます。

## できること

- 2021〜2025年の春・秋、午前全800問（80問×10回、図表を含む）
- 全800問に問題別の3段階ヒント（注目点 → 考え方 → 具体的な当てはめ）
- 全問の正解をIPA公式解答と照合。個別解説の追加状況を明示
- 年度・春秋・分野・キーワード・個別解説の有無で検索、20問ずつ表示
- 原本画像を表示し、スマートフォンでは拡大してスクロール可能
- 自力正解／ヒントで正解／不正解／解答確認の区別
- 解答前と解答後のヒント閲覧を分けて記録
- 選択した答え・ヒント・スクロール位置を保存して再開
- 未解答を不正解扱いにせず「あとで解く」に保存
- 不正解・ヒント利用・自信なし・復習日の問題を解き直し
- 1問・3問・5問のボタンから、1操作で学習を開始
- 手元の教科書で読んだ分野に絞った演習、任意の章・ページメモ
- 同じ分野だけを出題し、分野内を一巡した後も範囲を維持
- 今日の解答数・累計・前回比較を表示。学習日と達成の詳細は折りたたみ
- 前回からのヒント削減・不正解からの自力正解を記録からフィードバック
- 任意の終了、大きな文字
- 学習記録のJSON書き出し・読み込み・初期化
- 自作ヒント・解説のブラウザ内編集と教材の書き出し
- 人間向け[HTML定義書](docs/requirements.html)

## ローカルで動かす

```sh
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。ES modules と fetch を使うので、HTMLを直接ファイルとして開かずHTTP経由で利用してください。npmインストールやビルドは不要です。

## 教科書から演習する

教科書は利用者が別に持っているものを使います。アプリ内に教科書本文は用意しません。「分野別演習」で読んだ分野を選び、その分野だけの問題を開始できます。章やページのメモは任意で、開始に必須の操作ではありません。

現在は基礎理論、アルゴリズム、データベース、ネットワーク、セキュリティ、マネジメント、法務など17分野、計800問です。詳細分野はアプリ独自の分類です。分野別の開始ボタンは実際の収録数に合わせています。分野内を一巡したら、同じ分野の解き直しになります。問題を増やすと、その問題の分野が自動で一覧に現れます。

達成の表示は学習記録の事実から算出します。ヒント利用や解答確認も、取り組みとして数えます。正誤・ヒント数は別に残し、ポイントの減点や連続利用が途切れた際のリセットは設けません。

## 保存のしくみ

記録は利用中のブラウザのlocalStorageに保存します。ログインや端末間同期はありません。ブラウザのデータ削除・別端末・別URL・プライベートブラウズには注意し、必要な記録は「表示・データ」から書き出してください。保存できないときは画面に表示します。

教材を編集しても、既存の学習記録にはその時点のヒント・解説を残します。編集と復習目安の計算は端末のローカル日付を使います。複数タブでの同時学習は未対応です。1つのタブで利用してください。

## 問題を増やす

`data/questions.json` に問題を追加します。問題・選択肢・正解・年度・期・出典URL・原本画像・段階ヒント・関連問題IDを記述してください。`hintStatus: individual` は個別ヒント付き、`enrichment: reviewed` は詳しい個別解説付きです。`enrichment: topic-guide` は詳しい個別解説が未追加で、解答後に分野の復習メモを表示します。ヒントと解説の状態は別々に扱います。個別解説がない場合の `choiceReasons` は空配列にします。既存問題を雛形にできます。正解は0始まりの選択肢インデックスです。

ブラウザで編集したヒント・解説を公開教材に反映するには、「問題と教材」→「教材を書き出す」のJSONで `data/questions.json` を更新してコミットします。問題文・正解・図は公式資料と照合してから公開してください。画面上の教材編集では正解や問題文は変更しません。

開発中のため仕様・データ形式は変更可能です。後方互換や移行機構は現段階の要件に含めません。

## 個別ヒントの編集

`data/hint-authoring/` の14ファイルに、追加した791問のヒントを問題IDで明示的に割り当てています。残る9問は既存の個別教材を保持しています。同じ概念・解法の問題では、同じ行へ複数IDを指定できます。分野名だけを使った共通テンプレートへの置換は行いません。

行の形式は `問題ID（空白区切り）|概念|ヒント1|ヒント2|ヒント3|正答開示の設定` です。最後の設定は省略時 `000`、例えば `010` は2段目で答えを含むことを示します。画面では開く前に「答えを含む」と表示し、回答前に見れば解答閲覧として記録します。

```sh
python tools/apply-hints.py
python tests/corpus.py
```

`hintSource` に作成ファイルと行番号を保存しています。検索用OCRをそのままヒントへ転記せず、数式・単位・図表は公式原本画像で照合します。詳しい個別解説の追加はヒントとは別に進めます。

## ブラウザでの確認

ローカルサーバーを起動した別のターミナルで、次を実行できます。

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/e2e.py
```

直接開始、分野を維持した演習・再開・一巡後の出題、任意メモ、進歩のフィードバック、記録の書き出し・読み込み、スマートフォン表示を確認します。確認用のブラウザは新しく作り、普段の学習記録は変更しません。スクリーンショットは一時フォルダーへ保存します。

公開版を確認する場合は `AP_STUDY_URL=https://donald-shrimp.github.io/ap-study/ python tests/e2e.py` を使えます。

## 表示方針

ブランド名「ひと問」とホームの開始カードには少し個性を残します。その他の画面は、英語の飾り見出しやキャッチコピーを省き、機能名・操作・記録を中心に表示します。問題画面では問題文と選択肢を優先し、説明・達成の詳細は必要なときに開ける配置にしています。

## 800問の取り込みと確認

問題・解答の公式URLとSHA-256は `data/sources.json`、80問ずつの正解は `data/answer-keys.json`、一問ずつの切り出し座標は `data/source-crops.json` に保存しています。2022年春・秋と2023年春は、問題がPDFの3ページ目から始まるため、表紙枚数を固定せず問番号を確認しています。800個の問番号を原本画像で照合しました。

新規問題は原本を損失のないWebP画像で保存しています。検索用テキストは自動読み取りであり、数式や文字に読み取り誤りがあります。解答時の正本は画像です。画像のみの問題文はスクリーンリーダーで全文を読み上げられません。最初の5問は従来の文字・図での表示も残しています。

2022年春の解答PDFは画像形式です。80個の正解を表から転記して原本と再照合しました。その他9回は公式解答PDFのテキストから取得しています。全800問に問題別の3段階ヒントを追加しています。詳しい個別解説は9問に追加済みで、残り791問は解答後に分野の復習メモを表示します。個別解説が未追加であることは、一覧と解答画面の両方に表示します。

```sh
python tests/corpus.py
python tests/e2e.py
python tests/scale.py
```

公式問題PDFを手元に置けば、次のコマンドで800画像と原本のピクセル一致も確認できます（PillowとPyMuPDFを使用）。

```sh
python tools/rebuild-images.py --pdf-dir /path/to/official-pdfs --verify
```

同じコマンドから `--verify` を外すと、保存された座標で画像を再生成します。問題文や個別解説のJSONは変更しません。

検索用TSVを読み直す場合は `python tools/reindex-search.py --ocr-dir /path/to/ocr` を使います。問題画像・正解・分野・ヒントは変更しません。
