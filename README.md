## ホーム画面に追加・オフライン利用

Android・Chrome等では「設定」にインストールボタンが表示される場合があります。ブラウザのインストールメニューも使えます。iPhone・iPadではSafariの共有メニューから「ホーム画面に追加」を選びます。

Android Chromeでインストール項目が無効になった報告は、広告ブロックを除外することでインストール成功を確認しています。アプリ追加を抑制するフィルターは、マニフェストへのリンクを削除する場合があります。該当する場合は `donald-shrimp.github.io` をサイト除外して再読み込みしてください。`?pwa-check=1` を付けて開くと、端末のブラウザ情報・マニフェストとアイコンの取得結果・サービスワーカーの状態・インストール通知の有無をコピーできます。診断には学習記録を含めず、削除や初期化も行いません。JavaScriptからChrome内部の不適格理由を直接取得することはできません。

アプリと問題データを保存し、表示した問題画像を追加で保存します。初回はオンラインで開いてください。通信が切れても、保存した問題を再開・解き直しでき、選択した回答とヒントの段階を保持します。新しく自動出題する場合も、オフラインで読める問題を選びます。画像未保存の問題を直接選んだ場合は、その理由を表示し、途中の記録を変更しません。全800画像の一括ダウンロードは行いません。

通信できるときは公開教材を取得して保存し、オフラインでは保存済みの教材を使います。アプリ本体の更新が準備できた場合は「設定」に「更新して再読み込み」を表示し、学習中には自動再読み込みしません。学習記録は利用者・資格別のIndexedDB、公開教材の一時保存はCache Storageと分けています。Googleログイン時はFirebaseで学習履歴・ヒント・中断状態を同期します。単語帳の自己評価も同期します。教科書メモと端末別カード再開位置も同期対象です。表示設定・前回の入口・教材編集は端末内です。試行の再開範囲・個人の紙ペン指定・先送りは別コレクションの同期対象です。回答の送信形式は維持し、Firestore Rulesへlearningの本人用ルールを追加しています。learning用Rulesの公開は利用者が報告済みです。cards用Rulesの公開は2026-10-11に利用者が報告済みです。personal用Rulesの公開も2026-10-11に利用者が報告済みです。ログインなしで別ブラウザへ記録を移す場合は、学習記録の書き出し・読み込みを使ってください。

`manifest.webmanifest` の起動先・スコープ・画像は相対パスなので、GitHub Pagesの `/ap-study/` でも動作します。 アプリIDは `/ap-study/` で固定します。`id` は起動先やマニフェストのディレクトリではなくオリジン基準で解決されるため、`./` を使うと同じホストの別プロジェクトと識別子が衝突します。アプリ本体を変更する際は `sw.js` の `RELEASE` と、`templates/study.html` のJS/CSS・マニフェストと `app.js` の共通モジュールURLのリビジョンをそろえ、`python tools/build-content.py` で入口を再生成してください。アイコンは `python tools/generate-icons.py` で再生成できます（開発時のみPillowが必要）。

```sh
python tests/pwa.py
```

マニフェスト・アイコン・サブフォルダー、実際のオフライン再読み込み、選択・ヒント・画像の復元、未保存問題の拒否、更新後の保存済み教材を検証します。公開版では `AP_STUDY_PWA_URL=https://donald-shrimp.github.io/ap-study/ python tests/pwa.py` を使います。インストールそのもののOS操作は利用端末で行います。

## 教科書から演習する

教科書は利用者が別に持っているものを使います。アプリ内に教科書本文は用意しません。「分野別演習」で読んだ分野を選び、その分野だけの問題を開始できます。章やページのメモは任意で、開始に必須の操作ではありません。

現在は基礎理論、アルゴリズム、データベース、ネットワーク、セキュリティ、マネジメント、法務など17分野、計800問です。詳細分野はアプリ独自の分類です。分野別の開始ボタンは実際の収録数に合わせています。分野内を一巡したら、同じ分野の解き直しになります。問題と分野設定を追加すると、その分野が一覧に現れます。

達成の表示は学習記録の事実から算出します。ヒント利用や解答確認も、取り組みとして数えます。正誤・ヒント数は別に残し、ポイントの減点や連続利用が途切れた際のリセットは設けません。

## 保存のしくみ

記録は利用中のブラウザのIndexedDBに、端末のゲストID・資格ID・試行UUIDで分けて保存します。ログインなしでは端末内、Googleログイン時は資格別のクラウド同期を使います。ブラウザのデータ削除・別端末・別URL・プライベートブラウズには注意し、必要な記録は「設定」から書き出してください。保存できないときは画面に表示します。

教材を編集しても、既存の学習記録にはその時点のヒント・解説を残します。以前のガイドや更新前のヒントで再開した場合は、「最新のヒントで続ける」から最新教材へ移れます。途中の回答候補を引き継ぎ、ヒントは閉じた新しい試行になります。以前のヒント閲覧履歴は前の記録に残します。編集日時は端末の表示を使い、復習日は計画のタイムゾーン（未登録なら応用情報は日本時間）で計算します。別タブの新しい試行を全履歴で上書きしません。同じ中断問題へ同時に回答した場合は、継続記録として両方を残します。別タブで初期化・読み込みが行われた場合、古いタブの保存を止めて画面に案内し、消した記録を復活させません。


記録の更新と未同期の送信待ちは1つのトランザクションで保存します。スクロールだけの変更は送信待ちを増やしません。Googleログイン時だけ、UID・資格別の送信待ちをFirestoreへ送ります。「この端末に保存済み」と「同期済み」を別に表示し、通信失敗でも学習を続けられます。分野メモは同期します。表示設定・教材編集は端末内に保持します。別端末で中断から再開するときは新しい継続記録を作り、同時に解いた回答を両方残します。

現在と同じ記録形式のlocalStorageデータがある場合、初回のみ内容を検証してIndexedDBへコピーします。元の値は変更せず残します。別バージョンの変換・互換レイヤーはありません。読めない値は上書きせず、画面からそのまま書き出せます。読み込みは64MB以下の同じ仕様のJSONを対象とします。

## 分野と記録の整理（2026-10-09）

[採用した画面案](docs/field-practice-mock.html)。分野一覧は矢印をブロックの中央に配置し、行を押すだけで1問を開始。診断の表示切替やメモ編集は分野一覧に置きません。現在の紙ペン条件と候補不足を明示し、別条件の問題へ無言で切り替えません。

記録の先頭は「自力正答率・直近28日・割合・取り組んだ問題数・自力正解数」だけ。問題ごとの最後の完了記録を数え、同じ問題の再回答で分母を増やしません。自力正解÷（自力・ヒント付き正解・不正解・解答閲覧）で、診断・未完了・未来の記録は含めません。率だけで学習効果や合格を断定しません。詳しい内訳は分野別グラフで確認します。

メモは記録タブの入力欄に直接書き、空なら「メモを書く」。既存の端末・アカウント・資格別の保存先を使用し、過去の試行に保存した章・ページは変更しません。回答履歴・学習日と達成、計画・診断・復習の入口も保持。

分野画面からの再開は、同じ分野・パート・紙ペン条件で始めた通常の分野演習のみ。通常の全分野・復習・検索・複数分野の計画からの中断を、別の範囲として再開しません。分野別復習の「もう1問」も同じ分野・パートを維持します。全分野の復習へは明示的に戻れます。保存形式とFirestore Rulesは変更していません。

## メモと単語帳の端末別再開（2026-10-11）

## 固定80問の模試（2026-10-11）

学習タブの「模試」カード→模試選択→模試A・Bの固定80問。前回の正答率と中断中の「続きから」を表示します。記録タブには「模試結果」を追加し、各回の受験履歴・結果・全4択理由を開けます。受け直しは別の受験記録。問題と順序をランダムにせず、C以降も資格別のセット定義から追加できます。

支援なし・終了後に一括採点。未回答も80問の分母に含め、途中終了は部分結果と表示。通常の自力正答率・復習・計画実績と30問診断へ混ぜません。中断は終了と区別し、保存済みの選択と80問からオフライン再開できます。Googleログイン時の同期、全体バックアップ、AIへの学習状況Exportにも対応。

[画面・出題・保存の仕様](docs/mock-mode.md)。通常800問、個別教材800問、単語帳681枚、派生180問は保持。アプリのGitHub Pages公開と別に、模試の保存を許可する最新版Firestore Rulesの再公開が必要です。
