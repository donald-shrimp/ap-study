# 物流業の事業計画

## この問題は、何を考える問題だった？

関東甲信越エリアを中心に運送業務と倉庫保管業務を請け負っている中規模の物流事業者B社は、同業他社との激しい競争によってここ数年収益が悪化しています。この状況を打開するため、経営企画部のD部長とE課長が「顧客に新たな価値を提供する事業計画」を立案することになりました。

この大問は、単に経営分析フレームワークの用語を暗記しているかではなく、**「①外部・内部の環境分析で自社の置かれた状況と強みを把握し（設問1）、②ドライバーの気付きから顧客の本当の困りごとを分析し（設問2）、③自社の強みと提携先の強みを組み合わせて顧客の要望を満たす新サービス（3PL）を組み立てる（設問3）」**という、事業企画の一連の思考プロセスを追体験する問題です。

## まず、B社の分析ステップと事業計画の全体像を整理しよう

設問に入る前に、本文の3つのセクションでE課長がどの順番で分析・企画を進めているか、全体像を整理しておきましょう。

| 段階 | 分析手法・アプローチ | 本文で明らかになった主な内容 |
| --- | --- | --- |
| **1. 外部環境分析（マクロ）** | **PEST分析**（**マクロ的視点**：政治・経済・社会・技術） | 法改正による総労働時間規制や少子高齢化により、ドライバーを含む労働力の総量・なり手が減少する |
| **2. 外部環境分析（ミクロ）** | **ファイブフォース分析**（ミクロ的視点：業界内の5つの競争要因） | 運送・保管だけではコモディティ化して**価格**競争に陥り、ドライバー不足から「売手の交渉力（賃金上昇に伴う調達コスト増）」の脅威も大きい |
| **3. 内部環境分析** | **内部環境分析**（自社の経営資源の棚卸し） | B社は**好立地にある営業所と倉庫**（高速道路・幹線道路へのアクセスが良く空きスペースもある）を持つが、顧客要望に十分生かせていない |
| **4. 顧客情報の定性的分析** | **マーケットイン**志向＋**テキストマイニング** | ドライバーの自由記述回答から**顧客の事業に関するテキストデータ**を選別して分析した結果、「**一括委託**」「**コア業務**」「**集中**」の共起関係が判明 |
| **5. 新たな価値の提供** | **3PL**（サードパーティ・ロジスティクス）＋R社との業務提携 | B社の「運送・倉庫保管（＋好立地の拠点）」とR社の「流通加工（検品・タグ付け・箱詰め）」を組み合わせ、物流を一括受託する |

この流れを頭に入れておくと、各設問が「どの段階の、何の判断を聞いているのか」がすぐに見えてきます。

## 設問1(1) a｜労働時間の規制は政治的要因

設問1(1)は、表1（PEST分析）と表2（ファイブフォース分析）の空欄a・b・cを埋める問題です。

まず空欄aから考えましょう。**PEST分析**とは、自社を取り巻く外部環境の変化を、**政治（Politics）・経済（Economy）・社会（Society）・技術（Technology）**の4つの観点で整理する手法です。表1では次のように分類されています。
- **政治的要因（P）**：法改正や参入規制・外国人労働者規制の変化
- **経済的要因（E）**：燃料費の上昇、運送の需給バランス
- **社会的要因（S）**：少子高齢化によるドライバー不足、EC市場の拡大
- **技術的要因（T）**：自動運転技術の発展、SNSを活用した購買方法の登場

表1の項番1（政治的要因）にある「［a］改正による総労働時間に関する規制の設定」は、労働時間の上限などの労働条件の基準を定める法律の改正を指しています。したがって、空欄aに入る法律名は **労働基準法** です。

- **公式解答例**：「労働基準法」

本文では、この労働基準法の改正によってドライバー1人あたりの労働時間が規制され、労働力の総量が減少する懸念が述べられており、続く設問1(2)の「人材を確保するための費用」の話へとつながっていきます。

## 設問1(1) b｜サービスの差が見えにくいと価格が比較される

続いて表2の項番1「業界内の競争の脅威」にある空欄b（「運送・倉庫保管だけの物流サービスではコモディティ化して，過当競争となりがちであり，［b］競争が常に発生していることから脅威は大きい」）を見ましょう。

**コモディティ化**とは、市場に同じような商品やサービスが普及し、他社との機能や品質の違いが顧客から見えにくくなることを指します。基本的な「荷物を運ぶ・倉庫に保管する」だけのサービスでは他社との差別化が難しく、顧客は「どれだけ安いか」で業者を選ぶようになります。その結果、注文を獲得するために各社が値下げを競い合い、利益を確保しにくくなります。

したがって、空欄bには **価格** が入ります。

- **公式解答例**：「価格」

## 設問1(1) c｜別の方法で同じ輸送の目的を果たせるか

次に表2の項番3「［c］サービスの脅威」を見ましょう。

項番3の説明文には、「航空輸送や海上輸送といった手段があるが，現状では車両による陸送に代わるものではなく脅威は小さい」「車両の自動運転による配送やドローン配送の実証実験が行われているが，実用化はまだ先であり，現状の脅威は小さい」と書かれています。

このように、既存のサービス（トラックなどの車両による陸送）とは別の手段で顧客の同じ目的（荷物を届けること）を満たし、既存サービスに取って代わる可能性があるものを **代替サービス（代替品）** と呼びます。したがって、空欄cには **代替** が入ります。

- **公式解答例**：「代替」

## 設問1(2) d｜B社に労働力を供給する側の交渉力

設問1(2)は、表2の項番4「売手の交渉力の脅威」および本文中の空欄dに入る最も適切な記述を解答群から選ぶ問題です。

**ファイブフォース分析**は、業界の収益性を左右する「5つの競争要因（①業界内の競争、②新規参入の脅威、③代替サービスの脅威、④売手の交渉力、⑤買手の交渉力）」を分析する手法です。ここで「売手」と「買手」の立場をB社目線で整理しましょう。
- **買手（顧客）**：B社から物流サービスを購入する荷主企業
- **売手（供給者）**：B社が物流サービスを行うために必要な資源（労働力や燃料など）をB社に供給する側。本問では、労働力を供給する**ドライバー**が「売手」に当たります。

本文を確認すると、「PEST分析の結果から，労働基準法が改正されたことによって，ドライバーを含む労働力の総量が減少することが懸念され，また，社会的要因によってドライバーのなり手が減ることを認識した。…ドライバーの需要に対して供給が減ることから，［d］と考えた」とあります。

労働力の供給が減ってドライバー不足が深刻になると、B社が必要なドライバーを確保するためには、賃金を引き上げるなどより良い処遇を提示せざるを得なくなり、人件費などの調達コストが増加します。したがって、正解は **ウ**（「ドライバーの賃金上昇に伴う調達コスト増加の脅威が大きい」）です。

| 選択肢 | 判断と理由 |
| --- | --- |
| ア ITの活用による省力化の脅威が大きい | ITによる省力化は効率化の話であり、労働力を供給する側の交渉力が強まる理由にはなりません |
| イ 運送料の値下げの要求による脅威が大きい | 運送料の値下げを要求するのはサービスを購入する顧客であり、「買手の交渉力」に当たります |
| **ウ ドライバーの賃金上昇に伴う調達コスト増加の脅威が大きい** | **ドライバー不足（需要に対する供給減）により、人材確保のために賃金が上昇して調達コストが増える「売手の交渉力」の脅威に合致します** |
| エ 陸送に代わる新たな輸送方法の脅威が大きい | 陸送に代わる輸送方法は項番3の「代替サービスの脅威」であり、かつ現状の脅威は小さいと判断されています |

## 設問1(3)｜PEST分析は広い範囲から始める

設問1(3)は、下線①「PEST分析，ファイブフォース分析の順に分析し」について、PEST分析を先に実施した理由として「PEST分析がどのような視点での分析であるからか」を、本文中の字句を用いて6字で答える問題です。

［B社の環境分析］の第1段落を確認すると、「自社を取り巻く経営環境のうち，自社以外の要因を**マクロ的視点**とミクロ的視点で分析する外部環境分析と…」と書かれています。
- **マクロ的視点（PEST分析）**：法改正や人口動態、技術革新など、個々の業界や取引先の枠を超えて社会全体に影響する「広い範囲」の変化を捉える視点です。
- **ミクロ的視点（ファイブフォース分析）**：その大きな変化が、自社が属する「特定の業界（物流業界）」の競争や取引関係にどう影響するかという、より身近で具体的な範囲を捉える視点です。

まず広い範囲の変化（法改正や少子高齢化）を把握してから、それが業界内の競争要因（売手の交渉力など）にどう波及するかを考える順序になっているため、答えは **マクロ的視点** です。

- **公式解答例**：「マクロ的視点」（6字）

## 設問1(4)｜自社にある強みを内部環境分析で探す

設問1(4)は、下線②「B社が業界内において競争優位を確立するための分析が必要」について、この分析の名称を本文中の字句を用いて10字以内で答える問題です。

下線②の直後の文を見ると、「E課長は，その分析を実施した結果，**B社は，好立地にある営業所と倉庫をもっているにもかかわらず**，そのことを生かして，多様化する顧客の要望に応えられていないことが収益悪化の原因であると結論付けた」とあります。

ここで調べているのは、社外の環境ではなく「B社自身が持っている経営資源（人材・設備・立地など）と、その活用状況」です。［B社の環境分析］の第1段落にある「自社の経営資源に関する要因を分析し，自社の特徴を洗い出す**内部環境分析**」にそのまま該当します。

- **公式解答例**：「内部環境分析」（6字）

なお、文中の「**競争優位**」とは、顧客が同業他社ではなく自社のサービスを選ぶ決め手になる優位性のことで、この内部環境分析で見つけた強み（好立地の営業所と倉庫）が後半の設問3で生かされます。

## 設問2(1)｜マーケットインは顧客の要望を起点にする

設問2(1)は、下線③の**マーケットイン志向**に該当する行動として最も適切なものを解答群から選ぶ問題です。

商品やサービスを企画するときの2つの対照的な考え方を確認しましょう。
- **マーケットイン**：まず市場や顧客が抱えているニーズ（要望・困りごと）を調査し、それを満たす商品やサービスを企画・提供する考え方です。
- **プロダクトアウト**：自社の得意な技術や既存の設備・製品を出発点として、作れるものを作って市場へ売り込む考え方です。

本文でも、B社はこれまでの受注履歴や契約金額だけでは分からなかった「顧客の本当の要望・業務上の負担」を調査してから新サービスを検討しています。したがって、市場調査を行って顧客ニーズを満たすサービスを提供する **エ** が正解です。

| 選択肢 | 判断と理由 |
| --- | --- |
| ア 既存市場向けの物流サービスを新たな市場に提供する。 | 既存のサービスをそのまま別市場へ展開する行動であり、顧客ニーズを調べてサービスを作る手順が示されていません |
| イ 競合他社よりも相対的に低価格となる物流サービスを提供する。 | 価格競争の手段であり、顧客のどのような困りごとを解決するかを調べるマーケットインの考え方ではありません |
| ウ 自社が市場で優位性をもつ技術を活用した物流サービスを提供する。 | 自社の得意技術を出発点にする「プロダクトアウト」の考え方に当たります |
| **エ 市場調査を行い，顧客ニーズを満たす物流サービスを提供する。** | **市場や顧客のニーズを調査し、それを起点にサービスを提供する「マーケットイン」の考え方に合致します** |

## 設問2(2)｜顧客の事業に関係する記述を選ぶ

設問2(2)は、［顧客情報の定性的分析］の下線④「テキストデータを選別するよう」について、ドライバーから集めたテキストデータをどのように選別するのかを35字以内で答える問題です。

まず、本文の条件から「何のために調査したのか」と「どんなデータが混ざっていたのか」を整理しましょう。
1. **調査の目的**：「ドライバーのもつ**顧客の事業に関する気付き**を把握するために調査を実施した」とあります。数量や金額を扱う定量的分析に対し、自由記述の文章から単語の出現頻度や結びつきを調べる**テキストマイニング**（定性的分析）を行うのが狙いです。
2. **集まったデータの中身**：ドライバーの回答には、「顧客の事業に関する未知の情報、B社に対する期待やクレーム、顧客に対する感想、相対する顧客社員への好悪の感情といった**顧客の事業に関する情報とそれ以外の種々雑多な情報が混在していた**」と書かれています。

たとえば「荷物が届くたびに顧客が検品作業に追われている」といった記述は顧客の事業上の要望を探る手がかりになりますが、「担当者の〇〇さんが好きだ／嫌いだ」といった個人的な感情は分析のノイズになります。

したがって、混在している回答の中から**「顧客の事業に関するテキストデータ」を取り出して分析の対象にする**ように選別します。本文の表現を使って35字以内でまとめましょう。

- **公式解答例**：「顧客の事業に関するテキストデータを分析の対象とする。」（26字）

## 設問3(1)｜R社が求める荷物を扱いやすい作業場所

設問3(1)は、［顧客への新たな価値の提供］の下線⑤「B社のもつ経営資源は，R社の事業を展開する上で魅力的なものである」について、B社のもつ経営資源とは何かを、本文中の字句を用いて15字以内で答える問題です。

1. **R社が求めている条件を確認する**：
   流通加工（検品・タグ付け・箱詰めなど、物流の過程で荷物に手を加える作業）を行うR社は、需要拡大で作業所が手狭になっており、次の条件で新しい作業所を探していました。
   - **最優先事項**：「荷物の受入れと発送をスムーズに行えること」
   - **費用面の条件**：「土地の取得費や倉庫の建築費といった初期費用の負担が大きい自前の作業所新設は回避したい」
2. **B社が持っている経営資源と照らし合わせる**：
   設問1(4)の内部環境分析や冒頭の段落を振り返ると、B社は高速道路や幹線道路へのアクセスが良く、空きスペースも確保した「**好立地にある営業所と倉庫**」を持っています。ここをR社の作業所として使えれば、荷物の受入れ・発送がスムーズに行え、初期費用も抑えられます。

したがって、本文中の字句をそのまま抜き出して15字以内で答えます。

- **公式解答例**：「好立地にある営業所と倉庫」（12字）

## 設問3(2)｜物流を一括委託して、顧客がコア業務に集中する

設問3(2)は、下線⑥について「E課長の事業化案を実現することで，B社の顧客の物流に関わる作業に対するどのような要望を満たすことができるか」を、**選別したテキストデータの分析の結果の字句**を用いて30字以内で答える問題です。

次の3ステップで答案を組み立てましょう。

1. **テキストデータの分析結果の字句を確認する**：
   ［顧客情報の定性的分析］の最後の段落を見ると、選別したテキストデータの分析結果として、次の3つのキーワードが挙がっています。
   - 頻出している単語：「**コア業務**」「**一括委託**」
   - 「コア業務」と強い**共起関係**（複数の単語が同じ文章中に一緒に出現する関係）がある単語：「**集中**」
2. **顧客の実際の業務負担と3PLの仕組みを確認する**：
   顧客はこれまで、B社から荷物が届いた後に検品・タグ付け・箱詰めなどの流通加工を自社内で行うか別業者へ委託しており、負担になっていました。そこでB社とR社が提携し、運送・倉庫保管から流通加工までをまとめて引き受ける **3PL（3rd Party Logistics）** サービスを提供します。
3. **3つのキーワードをつなげて顧客の要望を表現する**：
   顧客は、バラバラに行っていた物流関連の作業を「**一括委託**」することで、自社の本来の中心業務である「**コア業務**」に「**集中**」したいと望んでいます（委託するのはあくまで物流作業であり、コア業務そのものを委託するわけではない点に注意しましょう）。

分析結果の3つの語句（「一括委託」「コア業務」「集中」）をすべて使って30字以内でまとめます。

- **公式解答例**：「一括委託することでコア業務に集中したいという要望」（24字）

## 次の問題でも使うこと

- 外部環境分析では、まず**マクロ的視点**の**PEST分析**（政治・経済・社会・技術）で社会全体の大きな変化を捉え、次にミクロ的視点の**ファイブフォース分析**で業界内の5つの競争要因（業界内競争・新規参入・代替サービス・売手の交渉力・買手の交渉力）への影響を整理する。
- ファイブフォース分析の「**売手**」は自社に資源（労働力や原材料など）を供給する側、「**買手**」は自社の商品・サービスを購入する顧客側であり、人手不足による賃金上昇は「売手の交渉力」の脅威に当たる。
- 自社の得意技術や設備を起点にする「プロダクトアウト」と、市場調査によって顧客のニーズや困りごとを起点にする「**マーケットイン**」を区別する。
- テキストマイニングの設問では、「頻出語」と「共起語（一緒に現れる語）」として挙げられたキーワードを漏れなく組み合わせて、顧客の要望や課題を一文にまとめる。
