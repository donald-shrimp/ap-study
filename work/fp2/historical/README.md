- このフォルダの年度別 `questions.json`、`practical-cases.json`、`source-files.json` はGitHubに直接登録した作成者Draft。元データの学科正答と実技回答欄は公式模範解答と紐付けている。
- **原本PDF計12点・図表画像・空のレビュー台帳はGitHub Actions成果物に含む**。このGitフォルダには重複保存していないため、このフォルダ単体で納品チェッカーを実行しないこと。
- 完全な納品フォルダは、`python tools/build-fp2-historical-drafts.py` で再生成する。各 `deliveries/fp2-jafp-<回>-draft/` に原本PDF・SHA-256・画像・JSON・レビュー台帳が揃う。
- 再生成と `python tools/check-fp2-delivery.py` による各回のDraft構造検査は [GitHub Actions](https://github.com/donald-shrimp/ap-study/actions/workflows/fp2-historical-authoring.yml) で行い、3回分を別々のアーティファクトとして保存する。CI成果物は保存期限があるため、必要に応じて再実行する。
- 解説および選択肢別理由は**公式正答から導いた作成者の初稿で、法令・計算の具体的根拠に未完成の箇所がある**。この段階で「完成した教材」「レビュー済み」とは扱わない。
- `practical-cases.json` の語群・選択肢のうちPDFテキストから確定できなかった説明は、原本本文／図表への参照表示にしている。修正・個別検証の対象。
- 資料画像は機械的にトリミングしており、隣接設問や欠落・判読性を含め目視確認が必要。改訂時は同一問題IDで版を上げる。
- 原本の出典・加工を明記し、[日本FP協会の問題利用条件](https://www.jafp.or.jp/exam/mohan/files/exam_riyou.pdf) に従う。
