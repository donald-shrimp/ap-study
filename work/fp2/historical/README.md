## 重要ポイント強調と品質方針

- **過去に改善済みの学科80問の重要ポイント強調を適用済み**：2025年1月・問1〜60／2024年9月・問1〜20。`summary` の「何が問われるか」、`explanation` の「判断の根拠」、`takeaway` の「類題に使える重要ルール」に `**...**` を付与。正答・選択肢・法令基準日・元の解説内容は維持。2025年1月の問36〜40のみ、以前切れていた要約・要点を意味の通る文章に修復。
- **解説や選択肢別理由の文字数下限は廃止。** 正答に至る判断軸・理由・例外の理解を優先し、CIでは必須項目・正答照合・選択肢数・段階ヒント・強調構文等のみ確認する。内容の正確性と分かりやすさは [FP2級作問ルーブリック](../../../docs/fp2-authoring.md) に沿った独立レビューで判断する。
- 公開アプリの解答画面では、強調記法だけを安全に `<strong>` 表示する。任意のHTMLは無効。Draftにある変更を独立レビュー・マージ・公開したとは扱わない。
