## ブロッカー／納品までの作業
1. 公式PDFの**実バイナリ**を入手して `delivery/sources/fp2/` へ保存し、完全なSHA-256を実ファイルから計算する。外部閲覧テキストだけではハッシュを確定できない。
2. 手順書の `sourceRecord` と `legalReview` を各問へ記載する。前者に正しい原本ハッシュ、法令基準日 `2025-04-01`、未確認の公表日は `null`、後者に `unverified` を使う。
3. 問1〜10の記述・選択肢・正答・解説を原本表示と突合する。問11〜60を同品質で作成する。図表・第三者著作物があれば別処理。
4. 完成草稿を `delivery/content/fp2/questions.json` へ置き、`practical-cases.json`、両reviewsは `[]` とする。原本の実ハッシュを `source-files.json` に記載する。
5. `python tools/check-fp2-delivery.py /path/to/delivery` を実行し、**draftとして**構造検査する。通過しても内容承認ではない。
6. 作成者と**別担当**が原本・公式解答から独立確認するまで、`reviewed`、本番用 `content/fp2/questions.json`、公開カタログを変更しない。

## 注意
- このJSONはSHA-256等の証跡が揃う前の**中間ファイル**であるため、納品用チェッカーへ投入しない。
- 問題の正答は **2025-04-01の法令基準** に依存する。現行制度との差異がある場合も、公式正答を無断で置換しない。
