## 学習者が理解できるかを重視する品質ゲート（再点検）

**判断基準は文字数・太字の個数・３フィールドを埋めたかどうかではない。** 実際に問題を読んだ人が以下を理解できるか、`summary`・`explanation`・`choiceReasons`・`takeaway` を一体として評価する。

| 観点 | 合格と判断する条件 | 不足していれば |
| --- | --- | --- |
| **何を問うか** | 判断すべき制度・条件・比較軸が明確。初見で「何を考える問題か」が分かる | 問題固有の論点を簡潔に説明。必要な場合だけ `summary` を補う |
| **なぜその答えか** | 設問で決め手となる語句・数値・時点が挙がり、正答までの因果・必要な計算が追える。全肢の正誤理由も一致 | 根拠・途中式・用語の意味を補う。**正答番号の再掲だけで終わらせない** |
| **何を覚えるか** | 別の問題でも使える条件・公式・区別が理解できる | `takeaway` または本文の一文を修正。説明の単なる繰返しは不要 |
| **読みやすさ** | 必要な説明は省かず、同じことを複数フィールドで冗長に繰り返さない | 文を整理するが、**短文化だけを目的に削らない** |
| **内容整合** | 問題文・肢の記述と理由・要点が一致。原本基準日時点の制度に照らして矛盾がない | 当該文を修正し、元の誤り・根拠・修正内容をレビュワーへ報告 |

**編集可否は各問の不足に応じて決める。** 既存の説明が合格条件を満たしているなら改稿不要。強調も任意であり、一律の字数目標や全件リライト義務を設定しない。
