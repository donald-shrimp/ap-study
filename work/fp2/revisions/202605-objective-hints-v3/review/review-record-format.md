# 今回の独立レビューの記録方法

- レビュワー：`Codex /root/fp2_202605_hint_reviewer`。ヒント作者 `Codex /root` とは別のエージェント。
- 対象：2026年5月公表・学科60問へのヒント追加。原本は `sources/fp2/g2_202605_qa.pdf`、原本の法令基準は2025-04-01。
- 原本PDFのテキストをPyMuPDFで抽出して、全60問の印字問番号・公式正答を独立抽出した。本文・選択肢も原本テキストと照合する。表・親族図など配置が必要な部分は原本ページを画像でも確認する。
- 新ヒントは問題文・全選択肢・公式正答・各段階の新情報・残る判断・開示判定・数値や例外を一問ずつ読む。未変更の既存解説等は変更がないことを確認し、以前の独立レビューを参照する。旧レビューを今回のヒントの承認へ読み替えない。
- 作者メモを参照するレビューであり、完全盲検や生徒による試用とは称さない。ブラウザでの表示・採点・保存確認は主担当が別途実施し、その結果と内容レビューを区別する。
- `independent-qXX-qYY.json` に各問の根拠と指摘・再確認を記録する。標準公開台帳へ取り込む `publication-reviews-qXX-qYY.json` は、実際に内容確認して承認した最終版だけを含む。
- 最終公開台帳のsha256とnormalizedSha256は、草稿からenrichmentだけをreviewedへ変更した承認対象に対して計算する。版は各問の旧version+1。草稿・公開作成元・進捗はレビュー担当が編集しない。
