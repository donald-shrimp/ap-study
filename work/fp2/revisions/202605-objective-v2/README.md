## 改訂内容

1. 各問の `explanation` を、判断の決め手・誤りの理由・必要な根拠・計算順を示すように**60問すべて改稿**。
2. `takeaway` を各問に追加し、類題の判別に使える比較・式・規則を簡潔にまとめた。学習画面の共通インライン太字 `**…**` に対応。
3. `summary` は論点整理が有用な**9問だけ**追加（必須項目とはしない）。
4. `choiceReasons` の全240件は、既存の独立レビュー済みの文言を維持し、各肢の判断条件の一部だけを太字化した。内容の再解釈・書き換えは別担当レビューで必要性を判断する。
5. 各IDは不変、版番号を1増加。原本で版2だった問14・35・55は本草稿では版3、その他57問は版2。
6. `stem`・全`choices`・正答ID・分野・採点方式・出典・PDFのハッシュ・原本法令基準日・法令レビュー状態・必要図は変更していない。

## 別担当へのレビュー依頼

1. 各問題について、**原本PDFと公式正答**を直接確認し、問題文・選択肢・正答IDの一致が本当に保持されていることを確認する。原本は `sources/fp2/g2_202605_qa.pdf`、既存の原本ハッシュは `525d190bb489b4187d39d6782eac999fc4b14bfdd1f489842b96685465b804ef`。
2. **原本の2025-04-01基準**に沿って、追加・書き換えた全60件の説明・要点・9件の要約の正確性を確認。現行法令の確認は別管理し、根拠がなければ `unverified` を維持する。
3. 240件の各肢理由は文言不変だが、**強調位置が正誤の分岐点と整合するか**を確認する。抽象的な要点・重複・断定しすぎる説明があれば修正指示する。
4. とくに上記の計算問題は単位・丸め・途中式、図を要する問55は元の親族図を見て人数を再計算する。
5. 指摘がある問題を番号・根拠・修正案つきで記録する。修正後の最終内容を別担当が再確認する。
6. 合格したレコードだけを本来の `content/fp2/questions.json` に統合し、版番号と `enrichment: reviewed` を確定。**新しい版の正規SHA-256・レビュワー・確認日時・原本／図のハッシュを実測して**確認台帳を更新する。既存のレビュー記録を新しい版へ流用しない。
7. `python tools/build-content.py`、`python tests/fp2-content.py`、関連Schema／PWA／ブラウザテストを実施し、公開ファイル一致と実機表示まで確認する。**レビュー・マージ・公開は本PRの担当範囲外。**
