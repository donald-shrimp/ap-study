新規795問は公式問題PDFの一問ずつの原本画像です。改変は切り出しと余白の調整、画像形式の変換です。最初の令和6年春期問1・10・21・36・37は、原文を転記した表示も残しています。問21の選択肢には回路記号の名称を補足しています。問題ごとに年度・期・試験名・午前・問番号と公式PDFへのリンクを表示します。

正解は800問すべて公式解答と照合しています。2022年春の解答は画像から転記し、再照合しました。他9回は公式PDFのテキストから取り込んでいます。詳細な分野名はアプリ独自の分類で、公式のT・M・S区分もデータに保存しています。

検索には自動読み取りテキストを利用します。読み取り誤りがあるため、問題の内容は原本画像が正本です。検索文字は問題文の正確な転記として扱いません。

独自作成の個別ヒントは全800問に3段階ずつあります。詳しい個別解説は9問に追加済みです。残り791問は解答後に分野の復習メモを表示し、個別解説未追加と明示します。いずれもIPAの公式解説ではありません。自分で教材を編集した場合はブラウザに保存し、学習済み記録には当時の教材を残します。

[応用情報技術者試験ドットコム／過去問道場](https://www.ap-siken.com/apkakomon.php)の問題データや独自解説はコピーしていません。[同サイトの利用条件](https://www.ap-siken.com/thissiteis.html)を確認し、収集元はIPA公式資料にしています。

IPAのFAQでは、公表済み問題の教育等での利用に許諾・使用料は不要と案内されています。著作権が放棄されたものではありません。出典と改変内容を明記します。第三者の権利がある問題内資料は個別の扱いに従います。

URL・原本のSHA-256は `data/sources.json`、正解キーは `data/answer-keys.json`、切り出し座標は `data/source-crops.json` に保存しています。
