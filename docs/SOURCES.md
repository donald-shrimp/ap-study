# 教材の出典

このモックの問題は、IPA（独立行政法人 情報処理推進機構）の公開資料から転記しています。

- 出典：令和6年度 春期 応用情報技術者試験 午前 問1・問10・問21・問36・問37
- [公式問題PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/m42obm000000afqx-att/2024r06h_ap_am_qs.pdf)
- [公式解答PDF](https://www.ipa.go.jp/shiken/mondai-kaiotu/m42obm000000afqx-att/2024r06h_ap_am_ans.pdf)
- [IPA 過去問題・解答例](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)
- [IPA 試験FAQ：問題の利用について](https://www.ipa.go.jp/shiken/faq.html)

問題文と選択肢は公式PDFから転記し、表示用に改行・空白を整形しました。問21のタイムチャート・回路図は公式PDFから切り出し、選択肢には回路記号の名称を補足しています。正解は公式解答と照合しました。

ヒント、解答解説、各選択肢の説明、覚え方はこのアプリ用の独自作成です。IPAの公式解説ではありません。公開前に問題文・正解・解説の整合性を確認しましたが、今後も教材を修正できる構成にしています。

問題選びの参考にした[応用情報技術者試験ドットコム／過去問道場](https://www.ap-siken.com/apkakomon.php)から、問題データや独自解説はコピーしていません。[同サイトの利用条件](https://www.ap-siken.com/thissiteis.html)を確認し、問題の収集元はIPA公式資料にしました。

IPAのFAQでは、公表済みの問題について教育等での利用に許諾・使用料は不要と案内されています。著作権が放棄されたものではありません。利用時には出典を明記し、改変した場合はその旨を示します。第三者に権利がある問題内資料は個別確認が必要です。問題・図の権利と、アプリ独自コードの権利は別です。

## 学習設計の根拠

[調査ノート](research-notes.md)と[学習設計](learning-design.md)に、想起練習、間隔を空けた復習、ADHDの学習上の困りごとに関する資料と設計への反映を記載しています。翌日・3日・7日・14日の復習目安はモックの簡易ルールです。個人に最適な間隔の科学的保証や、医療的な効果を意味するものではありません。
