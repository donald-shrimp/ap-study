# 応用情報・科目Bの大問解説を学習アプリに組み込む計画

2026-11-15。対象は2022〜2025年の春期・秋期、計88題。大問全体の解説を、答え合わせの後にアプリ内で読めるようにする。[先行の画面・教材提案](ap-b-case-explanation-proposal.md)

## 学習中の導線

通常学習では回答を確定すると、その小問の解答・解説を表示する。記述はその場で自己評価し、次の小問へ進む。全欄の答え合わせと評価を済ませたら「大問全体の解説を見る」を主操作にする。「次の大問」と「今日はここまで」も選べる。

長文は科目Bの中に設ける独立した「大問の振り返り」画面で読む。原稿の導入と全体整理を先頭に置き、目次から該当節へ移れるようにする。長い節は開閉でき、「すべて開く」で通読できるようにする。目次の設問番号は対応データから表示し、添削後の本文の内容見出しと説明順を保つ。

各節から関係する小問や回答欄の解答例と自己評価へ戻れるようにする。小問からも該当節へ直接移れるようにし、参照後は振り返りの元の位置に戻す。本文や図表への参照は、既存の参照先が確実に特定できる場合はその位置を開く。それ以外は既存の問題文を開ける導線を用意する。スマホでは読み物を一列で表示し、問題文・回答との切替を使う。

| 取り組みの状態 | 大問解説の扱い |
| --- | --- |
| 未確定の欄がある | 大問解説の導線と本文を出さない。小問の答え合わせは既存条件で使える。 |
| 全欄が確定し、答え合わせや自己評価が残る | 欄別の解答・解説を確認し、必要な自己評価を行う。 |
| 全欄の答え合わせと評価が完了 | 振り返りを主導線にする。履歴からも開ける。 |
| 試験形式で途中まで解いて終了した | 確定済みの欄を答え合わせする。 |
| 対応版の解説を利用できない | 欄別の解説と既存の終了・次題の操作を使える。読込み失敗時は同じ画面から再試行できる。 |

通常学習と「最後にまとめて」の両方で、全欄の答え合わせと評価を大問解説の開示条件にする。画面への遷移、履歴・再開、節への直接移動にも同じ条件を適用する。表示中の節とスクロール位置は、既存の端末内チェックポイントで扱う。

## 添削済み原稿を、版付きの教材として配信する

1. 編集用の `catalog.json` が選ぶMarkdownと `explanation-links.json` を読み、公開教材の `caseId` と教材版に照合する。添削後の本文・対応情報のハッシュと最終確認の記録を掲載対象に結び付ける。添削前との差分を見て、条件・数値・単位・答案の意味が変わった箇所を原問に戻って確認する。2025年春期11題は共通カタログに原稿がある。ほかの7回と同じ添削完了台帳がないため、この11題の掲載版は原稿と納品記録を突き合わせて確定する。
2. 見出しと節の本文を、既存の回答欄への対応と一緒にビルドで変換する。 `caseId`、教材版、解説版、節ID、`itemId`・`fieldIds` を持たせる。見出し文字列は原稿内の節を特定するときに使い、アプリ上の参照は安定したIDで扱う。同じ節に複数の回答欄が対応する場合も、設問から同じ節へ移れることを検証する。
3. 変換した解説は、科目Bの教材マニフェストから参照する試験回単位の追加教材として配信する。原稿全体は約1.67 MBある。解説を開くときに該当回を読み込み、既存のハッシュ照合とキャッシュを使う。「オフライン学習用に保存」にも同じファイルを含める。解説が更新されても、採点用の問題データと同期する学習記録の契約は維持する。
4. 完了済みの古い記録からも、保存された問題と現行解説の対象のID・教材版・本文や回答欄の内容が一致する場合は開ける。不一致の場合は保存済みの欄別解説を表示する。以前の問題や完了記録を書き換えず、解説だけを差し替えられる構成にする。
5. 既存の本文表示を、段落・太字・数式・表・コードに再利用する。目次、見出し、箇条書きは振り返り側で安全に組み立てる。編集用HTMLは公開教材に含めず、本文は許可した記法で描画する。

掲載済みの原稿を手で公開用JSONへ転記する工程は設けない。以降の原稿修正も同じ変換・照合を通す。[編集用カタログ](../work/ap/case-explanations/catalog.json)・[教材ビルド](../tools/written_content.py)・[オフライン教材一覧の生成](../tools/offline_content.py)

## 受け入れ時に見ること

- **開示と採点**。未確定欄、一部終了、全欄確定と評価待ち、評価完了を両方の学習設定で確認する。画面、履歴、再読み込み、節への移動を通じた先出しを防ぐ。回答と評価、完了件数、次の大問の範囲を既存テストに加えて確認する。
- **スマホとPC**。320／390／1440px、文字拡大、キーボードで目次と節を確認する。狭い幅で表やSQLだけを横にスクロールできること、往復後のフォーカスと位置が戻ることを確かめる。
- **既存記録とオフライン**。旧版の途中・完了記録、解説のない問題、保存した試験回、通信切断、内容の更新後を試す。対応する解説が取得できない場合にも回答の確認と学習の継続ができることを確認する。
- **影響範囲**。科目A、FP2級実技、診断・模試の既存表示を確認する。共通表示の変更があれば、選択肢・数式・コード・表と開示順も回帰確認する。
