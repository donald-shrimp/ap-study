# 回答形式と採点の共通化

新しい資格の教材は、対応済みの形式なら教材データと確認記録を追加して使えるようにする。回答画面と採点は、科目ごとの設定や教材の出典に依存させない。

1. 通常問題と大問の選択式で、選択肢IDの完全一致を共通化する。画面やAI質問に表示する正答ラベルはIDから求める。練習・診断・模試の進行や開示は各モードが管理する。
2. 大問の入力形式と採点方式を明示し、新規教材は順不同の選択・短答を通常のケースファイルに直接書けるようにする。既存教材に適用した回答欄の差分は、当時の承認と解説を照合するため引き続き読み込む。
3. ビルド時と記録取り込み時に共通の教材例で契約を検証する。既存の教材版、バックアップ、解答開示・自己評価を確認する。新しい形式は入力・判定・表示・保存の一連の動作を確認してから教材に使う。

今回対象とするのは登録済みの選択・短答・数値・自己評価と組合せ採点。部分点、数値の許容差、記述文の意味による自動採点は、必要な資格と採点要件が決まった時点で検討する。
