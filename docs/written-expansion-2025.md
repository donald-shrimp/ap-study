# 科目B：2025年春期・秋期の全大問を追加

IPAが問題・解答例・採点講評を公開している直近2回、令和7年度（2025年）春期・秋期を対象とする。各11大問、合計22題（141小問・194解答欄・32図表クロップ）。既存の春期問1はID・教材版・本文・解説・画像・確認記録を保持し、新規21題を追加する。科目Aの800問、681カード、180派生と固定模試2セット、AB-730の174問、個人記録・移行形式・Rulesは変更しない。

公式の旧午後問題を科目Bの学習教材として収録する。新しいCBTの問題そのものを転載したものではない。問題本文・図表・小問・解答群・字数などの条件を保持し、問題ごとの解説と学習用の確認ポイントを独自に作成する。確認ポイントをIPAの公式配点・部分点基準として扱わない。

- 公式一覧：[IPA 2025年度の問題・解答例・採点講評](https://www.ipa.go.jp/shiken/mondai-kaiotu/2025r07.html)。原本PDFとSHAは [sources.json](../content/ap/written-drafts/two-exams/sources/sources.json) に保存。
- 作成・独立レビュー：4作成担当と、作者とは別の2確認担当。各確認担当は作者草稿と公式解答を読む前に原問から解答方針・検算を保存し、その後公式解答例・講評と完成草稿を照合する。先行解答の誤り・草稿の訂正・再確認も保存する。
- 教材・記録：[written-cases.json](../content/ap/written-cases.json)、[written-reviews.json](../content/ap/written-reviews.json)。全最終教材・原本PDF・原本画像・図表クロップのハッシュを照合し、承認済みだけを生成する。
- 草稿・原本照合の根拠：[作業ディレクトリ](../content/ap/written-drafts/two-exams/)。作成担当の自己確認を別担当レビューとして転記しない。

選択肢1個・登録済み短答例は既存の自動判定を使う。説明文と、順不同の複数解答・図示要件を含む欄は自己評価を使い、片方の答えだけを無条件に正解にしない。図への下線や関係線の記入は、原本の要求を残し、入力欄に図示内容を記述して自己確認する。描画入力や公式の部分点採点は提供しない。字数指定がない欄の2000字はアプリの入力上限であり、公式の字数制約とは区別する。

問題追加でホーム上部のボタンが全件分並ばないよう、開始／再開の主操作は1つに保ち、下の一覧から全大問を選択できる。科目Bの件数は大問22題として生成し、科目Aの問数へ加算しない。途中の記録は開始時の教材を保持し、教材追加で既存の回答・評価・再開位置を置き換えない。

検証・公開の結果は [VERIFICATION.md](VERIFICATION.md) と [progress.json](../content/ap/written-drafts/two-exams/progress.json) に記録する。本人の別端末での移行確認は今回の教材追加と別に未確認として保持する。
