## 結論

第二資格として追加できる。資格切替と資格ごとの記録分離は既存の仕組みを使い、**短い業務シナリオの独自問題＋用語カード**から始めることを勧める。最初から本番そっくりの試験を再現する必要はない。

## 何を学ぶ資格か

正式名称はMicrosoft Certified: AI Business Professional。AB-730はその試験コード。生成AIとMicrosoft 365 Copilotを仕事に活用する初級の資格で、コードを書く技能を前提にしていない。Word・Excel・PowerPoint・Outlook・Teamsなどの利用経験が想定されている。日本語受験に対応し、試験時間は公式ページで45分と案内されている。本番の問題数・形式の内訳は、この調査でAB-730固有の確定値を確認していない。[公式資格ページ](https://learn.microsoft.com/ja-jp/credentials/certifications/ai-business-professional/)

2026-10-13に開いた資格ページの分野表示は次の3つ。

1. 生成AIの基礎
2. プロンプトと会話の管理
3. ビジネスコンテンツの作成・分析

基礎用語だけでなく、「この業務でどの機能を使うか」「どんな情報をプロンプトに含めるか」「生成結果をどう確認するか」を判断する練習が向いている、というのが本調査からの設計判断。

## 日本語版の対象範囲を先に決める

公式資格ページは**英語版を2026-10-20に更新する**と案内している。一方、英語・日本語の学習ガイドは、すでにこの改訂後の4分野を掲載していた。日本語に翻訳されたページであることと、日本語試験への適用日が来ていることは区別する。

| ガイド掲載の英語版2026-10-20の分野 | 比率 |
|---|---|
| 生成AIの基礎 | 25〜30% |
| Copilotのプロンプトとチャット | 20〜25% |
| ビジネスコンテンツと共同作業 | 20〜25% |
| エージェントによる業務の実行 | 20〜25% |

この新版にはWork IQやCopilot Coworkなどが含まれる。ガイドの一般説明では他言語版の更新は英語版から約8週間後とされているが、**AB-730日本語版の適用日をこの調査では確認できていない**。8週間を足した日付を確定日として保存しない。[英語ガイド](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-730)、[日本語ガイド](https://learn.microsoft.com/ja-jp/credentials/certifications/resources/study-guides/ab-730)

推奨：共通の基礎から作成し、資格ページ掲載中の3分野を最初の学習分類にする。正式な日本語範囲・受験予定時期を照合してから対象版を確定する。将来、4分野版への対応が必要になったらエージェント分野を追加する。旧版の学習履歴を無条件に新分野へ付け替えない。対象版は教材情報と計画の前提に表示し、1問開始の前に設定を強制しない。

## 問題はどう用意するか

APの年度別過去問PDFとは教材供給の仕組みが違う。Microsoftの本試験問題は受験者契約で機密として扱われ、公式の無料Practice Assessmentは本試験の問題ではない。ひと問では**公式Learnの説明を根拠とする独自の学習問題**を作る。公式評価は外部へのリンクを置き、問題・解説の転載を前提にしない。[受験者契約](https://learn.microsoft.com/en-us/credentials/support/certification-exam-candidate-agreement)、[公式Practice Assessmentの説明](https://learn.microsoft.com/en-us/credentials/certifications/practice-assessments-for-microsoft-certifications)

各問に、問題文・単一選択の4択・3段階ヒント・解説・各選択肢の理由を付ける。教材を作る際の確認は次を必須とする。

- 出題目標とMicrosoft公式資料の該当箇所を結び付ける。
- 正解の一意性と、他の3択が不適切な理由を公式資料から確認する。
- Copilot Chat／Microsoft 365 Copilotの違い、ライセンス、参照できる情報など、正解を変える前提だけを短く書く。
- 画面の位置を暗記させる問題や、根拠のない「いつでも・必ず」を避ける。
- ヒントは問題の目的・制約・参照資料などから、具体的な最初の判断を示す。
- 作者と異なる確認者、公式資料の確認日、対象版、完成教材ハッシュを残す。確認できない問題は公開しない。

実際のCopilotで操作する体験は公式学習リンクを使う。ひと問内でCopilot環境やMicrosoft Learnの履修状態を再現・同期する機能は初期版に含めない。[公式コース](https://learn.microsoft.com/ja-jp/training/courses/ab-730t00)、[公式ラーニングパス](https://learn.microsoft.com/ja-jp/training/paths/transform-business-workflows-with-ai/)

## 最初の画面

- 上部で「応用情報」と「AB-730」を切り替える。トップ／PWA起動はその端末で前回開いた資格へ戻す。
- AB-730の最上段も「とりあえずはじめる」。最初は1つの開始／続きからボタンで十分。紙ペン分類のない資格は1入口にできる現行機能を使う。
- 単語帳・分野・解き直し・受験計画は既存の位置と操作を使う。
- 未提供の診断・模試は表示しない。30問未満の診断や、準備中の大きなボタンは追加しない。
- 用語カードは略語の正式名・意味・業務上の用途をセットにする。Copilot関連の似た機能の違いも扱う。
- 公式Learnへのリンクは分野一覧や解説の出典から開く。初回ウィザードや新しいナビゲーションタブを増やさない。

## データの置き方

以下は提案。ファイルはまだ登録していない。

```text
content/ab730/
  qualification.json       # 資格・分野・1つの試験パート
  questions.json           # 通常演習用の独自問題
  flashcards.json           # 用語・機能の違い
  syllabus.json             # 対象言語・版・出題目標の対応表（新規提案）
  sources.json              # 公式URL・確認日・資料の版（新規提案）
  question-reviews.json     # 独立確認の根拠と教材ハッシュ（新規提案）
  diagnostic-questions.json # P1以降。通常問題とは別ファイル
  diagnostic-reviews.json   # P1以降。既存の確認形式に対応
  mock-sets.json            # P2以降。問題数可変化の後
```

識別子は`qualificationId: ab730`とし、問題は`ab730-study-001`など安定したIDを使う。表示名や対象範囲を変更しても資格IDを変えない。`correctChoiceId`は既存形式を使い、出典ラベルは「公式資料に基づく独自問題」とする。「公式問題PDF」「公式解答PDF」ではなく「参考資料」などを設定する。

出題目標・資料確認・版の監査情報はまず作成元の対応表とレビューに置く。既存の同期payloadへ未対応の項目を追加しない。通常教材の`reviewed`という文字列だけでは独立確認を保証しないため、AB-730用の教材検査でレビュー・資料・完成ハッシュを照合する。

## 実装順

| 段階 | やること | 完了の目安 |
|---|---|---|
| P0：通常学習 | 日本語対象範囲を整理、代表12問を確認、資格定義と記録分離を検証、通常60問＋用語30枚へ拡充 | まず1問、分野、ヒント、解き直し、計画、同期、AI質問が使える。件数は提案で、作成済みではない |
| P1：診断 | 分野ごとに異なる母問題と業務シナリオを用意。診断専用の別問題を作成・独立確認し、この資格の配分を設定 | 30問・支援なし・通常演習への非混入・元問題重複なし・結果とExport |
| P2：練習模試 | 80問固定を問題数可変にする。固定セット・採点・保存・同期・Rules・検証を揃える | 内容に適した長さの模試A/B。45分の時間表示は必要なら任意追加 |

P0を先に公開できる。診断の出題を本番の比率に近づける場合は、現在の分野均等巡回とは別に重み付き配分を設計し、対象版と配分を開始時に固定する。まずは分野の確認用診断として扱い、合格可能性や公式スコアを推定しない。
