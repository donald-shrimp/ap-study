# 通常学習の出題と復習

2026-10-25改訂。復習の滞留で未着手の問題へ進めないこと、繰り返し自力正解しても14日間隔に留まること、同日に学んだ問題の期限が重なることを改善する。間隔や比率は製品の初期設定であり、科学的に最適な値と断定しない。

## 通常学習の混ぜ方

- 新問と期限到来の復習が両方あれば、新問2問につき復習1問を基本にする。対象範囲の直近2回の通常学習がともに初回回答なら復習を選び、それ以外は新問を選ぶ。復習枠では古い期限を先にする。
- 一方がなければ、利用できるもう一方へ進む。新問が残っている間に、期限前の既習問題を優先しない。
- 保存済みの完了記録から初回回答を復元する。セッションを終えたり別端末へ移っても、比率をゼロから始めない。途中で終えた問題は枠を消費しない。
- 資格・科目・分野・問題集を指定した範囲の履歴で判断する。診断、直接指定、明示的な復習の回答は通常学習の混合枠へ数えない。履歴の初回判定には直接指定・復習の既習記録も使う。
- 明示的な復習は新問を混ぜない。問題集の番号順、手動指定、中断の再開、先送り、セッション内の重複回避、オフライン教材の制限を維持する。
- AP科目A、AB-730、FP学科など共通の選択問題エンジンに適用する。AP科目B・FP実技の大問推薦は既に未着手優先なので、この比率や選択問題の回答回数を持ち込まない。単語帳も別のキューを維持する。

## 復習日

別日に続けて自力正解し、かつ「自信なし」がない日を数える。

| 成功した日数 | 基準間隔 | 問題ごとの分散後 |
| --- | --- | --- |
| 1 | 3日 | 2〜4日 |
| 2 | 7日 | 5〜9日 |
| 3 | 21日 | 17〜25日 |
| 4 | 45日 | 36〜54日 |
| 5 | 90日 | 72〜108日 |
| 6以上 | 180日 | 150〜210日 |

- 不正解、ヒント付き正解、解答確認、自信なしの正解は翌日へ戻し、連続した成功日数をリセットする。答えを含むヒントは従来どおり解答確認扱いにする。
- 同じ日に何度正解しても段階は進まない。苦戦した日の解き直しを自力正解しても、その日は成功段階を進めず翌日を維持する。翌日以降の自力正解で最初の段階から再開する。
- 画面の「別の日に自力正解」の累計は保持し、間隔決定用の連続成功日数と区別する。記録の書換えや新しい習熟点数の保存は行わない。
- 問題ID・最後に完了した日・段階から安定した分散値を計算する。読み直すたびに乱数で期日を動かさず、同じ同期済み履歴と計画のタイムゾーンなら端末間で一致する。
- 診断や受験専用教材の記録で通常学習の復習を変更しない。復習一覧・回答後の日付・次問の選択には同じ判定を使う。
- 既存の記録も読み込み時にこの仕様で再計算するため、以前に表示した予定日が変わる。バックアップ形式、同期、Rules、回答結果を変更する移行は不要。

## 検証

`tests/review-spacing.mjs` は復習100問が滞留した30問の学習、800問を21日×20問解く合成履歴、200問の同日学習の分散、同日再回答、失敗後の回復、順序・再読込の安定性、資格・範囲・診断・手動操作の分離を検証する。個人の実測成績や学習効果の証明ではない。
