# FP2級の教材追加基盤

2026-10-24、Issue #34 をもとにユーザーが基盤実装を承認。実教材の作成は外注する。未確認の問題や空の資格を公開カタログへ追加しない。

- 共通の実技画面を科目IDで分離。教材・一覧・履歴・中断位置を分け、資格単位の計画・同期・全件バックアップは共有する。
- 単独○×は既存の2択。1問に○×4欄がある形式は1つのcase内に4つの選択欄を置く。回答欄数と問題・事例数を混ぜない。
- 数値欄は文字列による厳密な十進数比較。単位と必要桁・丸め指示を教材へ保存する。桁区切り・全角数字を受理し、単位換算や入力への自動丸めは行わない。不明な表記は自己評価へ。
- 原本の公表日・法令基準日・出典PDFハッシュと、現行法令の確認状況を別オブジェクトに保存。履歴・バックアップ・AIには開始時の情報を保持する。基準日不明や未確認を現行法令確認済みと表示しない。
- `content/fp2/` に非公開の資格設定と空の教材・確認台帳を置く。学科、日本FP協会実技、きんざい4科目を定義し、教材が揃った科目だけ公開可能にする。
- 外注用仕様・機械検証・合成サンプルを用意する。合成データは試験問題として公開しない。実問題の独立レビュー記録を捏造しない。

検証は数値・メタデータ契約、複数実技の入力／再開／履歴／計画／バックアップ／AI／オフライン、既存AP・AB-730・Rules・同期。既存教材のcanonicalと公開件数は維持する。Rulesを変えずに対応可能か実装時に確認する。

実装・ローカル検証済み。[受け入れ仕様](fp2-authoring.md)／[検証記録](fp2-foundation-verification.json)。実FP教材は未収録。作問・内容の独立レビューは外注後の別工程。
