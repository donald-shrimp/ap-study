いらない学習を。

ホームに3つの入口。今の環境に合うボタンを押すだけで、1問を始められます。

まず試すこと

  1. ホームの 身軽に1問 を押す。
  2. やっぱり書きたい問題なら、問題の下にある赤文字の「この問題は紙ペンが必要」を押す。続きは「書いて考える1問」で再開できます。回答とヒントは残ります。
身軽に1問 →書いて考える1問 →おまかせで1問 →

この図は配置例です。実際の分野は、計画・復習・保存済み問題によって変わります。

単語だけ確認したいとき

ホーム下側の 「単語帳 · 681枚」 から開けます。最初から意味は表示しません。

  1. 用語を見て、意味を思い出す。
  2. 「意味を見る」で裏を確認。
  3. 「思い出せた」か「もう一度」で次のカードへ。

裏面の「関連する過去問・出典」から、その用語を問う四択へ進めます。カードの途中と自己評価は保存します。

自己評価は、四択の正答率・復習予定・計画実績に加えません。「また確認したい」カードを次の周回で先に出します。

今回の範囲

紙なしの候補：651問。単語帳：681枚。

2021〜2025年春秋の全800原本を確認し、651問を紙なし、149問を机向けに分類しました。未分類は0問です。「書いて考える1問」は机向け149問、「おまかせで1問」は全800問。前回の入口を強調し、途中なら「続きから」になります。

どうやって問題を選ぶ？
  • 用語・仕組み・式の意味など、書き直さずに判断できる問題を候補にします。
  • 筆算、状態の追跡、表への書き起こしが必要な問題は机向けにします。表があるだけでは除外しません。
  • 紙なしで候補がない分野へ勝手に筆算問題を混ぜません。計画の重点に候補がなければ、その入口で利用できる問題から選びます。
  • 診断の出題・採点は変えません。分野のグラフも全学習記録を集計します。
  • 自分で机向けに指定した問題は、ホームの詳細から指定を解除できます。回答記録は残ります。

保存と同期

四択の回答・ヒント・中断は、これまでどおり同期対象です。

前回の入口・試行の開始入口・自分の机指定は、この端末の設定です。単語帳の自己評価は、この端末・アカウント・資格ごとに保存し、初期版ではクラウド同期しません。

単語帳画面の「記録を保存・取り込む」から、専用JSONを書き出して別の端末へ移せます。通常の学習記録のバックアップとは別ファイルです。アカウントが違えば記録も分かれます。ブラウザのデータ削除で消えるため、必要なら書き出してください。

一度開いた分類とカードは、PWAでオフラインでも利用できます。未取得の問題画像は、従来どおり勝手に開きません。

問題文の略語で止まるとき

全17分野に681枚。 CPU・OS・DNS・SQL・PKI・EVMなど、正式名だけでなく「何をするものか」を短い日本語で確認できます。

DNSとは？

Domain Name System。ドメイン名とIPアドレスなどを対応付ける仕組み。名前を使って通信相手を見つけます。

同じ略語でも意味が違うものは、CPUのCPIと費用管理のCPIのように見出しで区別します。分野を選ぶと、その分野のカードだけ確認できます。

既存20枚のIDと過去の自己評価を保持。説明を補足した8枚は新版として、改めて確認できます。
