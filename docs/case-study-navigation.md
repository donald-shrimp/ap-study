# 実技・科目Bの学習入口

ホームは「続きから」（中断記録があるとき）、「おすすめで1問／1題」「分野から選ぶ」「試験回から選ぶ」。独立したランダムモードは作らない。おすすめは未回答、再確認が必要な回答、過去の取り組みを参考にし、同順位の偏りを分散する。自己評価を点数・合否や習熟率へ読み替えない。

出題範囲（科目・分野・試験回）と順序（おすすめ・番号順）を分け、通常問題とcaseで共通のキュー処理を使う。番号順は試験回内の数値順。FP実技は1問題、AP科目Bは本文と小問を含む1大問を単位とし、小問を分断しない。全欄の回答・評価後、同じ範囲の次の問題へ進める。既存の中断回答は再開し、上書きしたり新しい解答として採点し直したりしない。

## 教材カタログ

資格設定の `caseCatalogSource` で `hitomon-case-catalog` / version 1 のJSONを指定する。`entries` の各行は `{caseId, packId, packLabel, number}`。公開caseを過不足なく1回ずつ参照し、科目・試験回内の問番号を重複させない。試験回のラベルと番号は原本の開催／公表情報に合わせて登録し、画面でタイトルやIDから推測しない。

公開manifestの `cases.index` に検証済みの一覧を出す。本文・正答・版・独立レビューのcanonical SHAは変更しない。既存のcase bankと図も保持する。カタログは出題を選ぶメタデータであり、内容承認の代わりにはならない。

## 保存と適用範囲

回答は従来のcase記録として保存・同期する。出題範囲と順序・その回で扱った問題の対応は、既存の端末内チェックポイントに所有者・資格・科目別で保存する。リロード・中断・タブ再開で保持し、他の所有者や科目の範囲へ混ぜない。範囲は `writtenBackup.studyContexts` にも保存・復元する。旧バックアップは同項目なしで読み込める。出題の選択設定自体は端末間で自動同期しない。

オフラインでは必要図が保存されたcaseだけを新規出題し、法令改正の除外設定も守る。番号順で未保存・除外の問題がある場合は、現在利用できる問題の番号順となる。本番形式の全問受験や時間制限・公式配点はこの入口に加えない。
