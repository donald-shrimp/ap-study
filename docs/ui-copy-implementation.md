## 保存と同期の確認

新しい保存フィールドやFirestoreルールは追加していない。学習記録・教材・同期キュー・出題ロジック・統計の分母を保持する。移した管理操作は同じ保存処理を呼び出し、設定ダイアログ内に結果や失敗を表示する。

同期成功の表示は対象となる全系統で判定する。未送信・未取得・通信中・オフライン・一部拒否・競合を成功扱いにしない。ルール不足が模試・履歴だけにある場合は、その対象を表示する。正常な状態へ戻ったら、各画面の警告を隠す。

ゲスト取り込みは本人の操作で実行する。元のゲスト記録を残し、既存アカウントのメモ・計画とカード削除を尊重する。候補判定を読めないときは取り込み入口を残し、手動の復旧を妨げない。
