02 / 使う流れ

1問の学習を、小さく区切る。

  1. 「身軽に1問」「書いて考える1問」「おまかせで1問」

    押すだけで開始。前回の入口を強調し、途中の問題があれば同じボタンで「続きから」。小さな補足説明は付けません。

  2. 手元の教科書を使う場合

    教科書は別に持っているものを読む。「分野別演習」で読んだ分野を選び、その分野だけ解く。章・ページのメモは任意です。

  3. 問題を読む

    問題文・図表・選択肢を表示。選択肢を選ぶだけでは採点しません。

  4. 必要ならヒントを開く

    1段ずつ読みます。ヒントを開くための待ち時間はありません。

  5. 回答して、解説を読む

    「回答する」で確定。「あなたの回答」と「正解」は選択肢の下にまとめます。答えだけでなく、考え方と誤答の理由を確認します。

  6. 終えるか、次の1問へ

    自動で次へ進みません。終了時の長い振り返り入力も不要です。

集中が切れたら

途中で終えても、選んだ答えと開いたヒントを保存します。

「中断」「ホーム」は、枠・背景・アイコンのあるボタンで表示します。

計画なしでも開始できます。オフラインでは保存済みの問題を選びます。

03 / ヒントの具体例

答えまでの道筋を、少しずつ。

ヒントは「注目点 → 手順 → この問題への当てはめ」が基本。現在の800問はすべて3段階です。

試せる説明用の例自作例です。IPAの過去問ではありません。

12 Mバイトのデータを、通信速度8 Mビット/秒、実効利用率75%の回線で転送します。何秒かかるでしょうか？

Mは10の6乗。その他のオーバーヘッドは考えません。

答えを選ぶ
ヒント1 · 注目点

データ量はバイト、速度はビットです。実効利用率も条件にあります。

ヒント2 · 手順

データ量をビットに直し、通信速度に利用率をかけます。時間＝データ量÷実際の速度です。

ヒント3 · 当てはめ

12×8＝96 Mビット。8×0.75＝6 Mビット/秒。96÷6を計算しましょう。

アプリに残す記録のイメージ

未回答 · 回答前のヒント：0段階

答え：16秒

96 Mビット ÷ 6 Mビット/秒 ＝ 16秒。

12秒という答えは、実効利用率75%を反映していません。次も「単位をそろえる → 実際の速度を求める → 割る」の順で考えます。

この例の回答は保存されません。再読み込みすると最初に戻ります。

ヒントと解説のルールを見る
  • その問題で使う条件、式や手順の理由、最初の具体的な操作を示します。「候補を比較する」だけで終わらせません。
  • ヒントは減点の対象にしません。前の段も読み返せます。
  • 正答を実質的に明かす内容は「解答閲覧」として記録します。
  • 回答後に追加で読んだヒントは、回答前の利用と分けます。
  • 解説は要点から表示し、他の選択肢の理由や詳細は展開できます。
  • 段階番号だけで、違う問題のヒントの強さが同じとは扱いません。

04 / 残す記録

正解でも、助けを使ったかを残す。

例えば「正解・ヒント2まで利用」。これが分かると、次に何を確かめるかを選びやすくなります。

回答ごとの結果と、その後の扱い
結果意味次にすること
自力正解回答前にヒントも答えも見ずに正解間隔をあけて確認
ヒント付き正解ヒントを使って正解後日、助けなしで再挑戦
不正解確定した答えが違った解説を読み、後日再挑戦
解答閲覧回答前に答えを見た理解の学習として残し、後日再挑戦
途中・あとでまだ回答を確定していない内容を残して再開。誤答にしない

進捗の伝え方

「別の日に自力正解：2回」のように、確認できた事実を示します。
同じ日の繰り返しや、別の問題での結果は分けて見ます。

保存する項目を詳しく見る
  • 問題：出典、年度、問題番号、図表、正答、ヒント、解説、分野、関連問題。
  • 解いた記録：日時、選んだ回答、正誤、回答前のヒント段階と閲覧履歴、答えを見た時点、任意の自信。
  • 途中の状態：選択中の回答、開いたヒント、問題内の位置。
  • 復習：前回の結果、次の候補日、延期、別の日の自力正解。

解き直しは新しい記録として追加し、前の履歴を上書きしません。「自力」はアプリ内での操作についての意味です。

教科書メモ・文字サイズは端末ごと。クラウド同期が失敗しても、学習と端末内保存を続けられます。最後のFirebase設定と試し方。通常のGoogleログインは利用者が成功を確認済みです。前回の計画・診断用Rulesは利用者が公開・同期済み表示を確認済み。今回の計画の前提と診断の出題情報に対応した最新版Rulesも、2026-10-07に利用者が公開を報告済みです。本番の前提の同期と別端末復元は未確認です。

診断名や服薬などの医療情報は収集しません。

データの保存先について読む

初期案 ログインなしでも、使っている端末へ資格別に保存します。書き出し・読み込み・削除を用意します。

ブラウザのデータ削除や端末の紛失で記録が失われることがあります。別タブで同時に解いた結果も保持します。Googleログインすると回答・ヒント・中断状態を同期します。元の端末内記録は選んで取り込めます。

保存に失敗したときは画面に表示します。書き出しと読み込みは同じ仕様での利用を対象にします。現在の既存記録も保持し、教材を更新しても過去の回答を採点し直しません。共通化と同期の進み具合を見る。

分野グラフの読み方

普段の学習：直近28日の同じ問題の最後の完了記録を数えます。自力正解、ヒント付き正解、不正解、解答閲覧を色と文字で表示。率だけでなく「2 / 5問」のように件数も添えます。

診断：最新の終了した診断1回を別表示。回答した問題だけを分母にし、未回答は不正解にしません。

0問は「未確認」、10問未満は「記録少なめ」。苦手や合格を断定しません。AI出力の全試行の率と、計画の取り組み回数は別の集計です。

05 / 解き直し

日をあけて、もう一度。

不正解、ヒント付き正解、答えを見た問題を復習候補にします。「正解したけど迷った」問題も、早めに確認できます。

復習の始まり方

前回の答えとヒントは、閉じた状態から。
必要になったら、またヒントを使えます。

間隔の初期案

翌日→3日後→7日後→14日後

次の確認で自力正解できたら、間隔を伸ばす案です。間違えたら短く戻します。日数は固定の最適値ではなく、使いながら調整します。

  • 今日取り組む量は、小さく

    問題数は決めず、1問ずつ続けられます。いつでも終えられます。たまった復習を全部今日のノルマにしません。

  • 苦戦が続いたら、基礎へ戻る

    再出題だけでなく、短い基礎説明や解法例を提案します。

  • 別の過去問でも確かめる

    同じ考え方を使う別問題を解き、答えの記憶だけになっていないか確認します。

出題順と回数のルールを見る
  1. 途中の問題があれば「続きから」を提案。別の問題も選べます。
  2. 予定日を過ぎた復習、今日の復習、新しい問題の順を基本にします。
  3. 同じ優先度なら古い候補を先にします。手動の選択・延期もできます。
  4. 同じ問題が同日に出続けることを抑えます。新しい分野へ進む入口も残します。

同日の解き直しはできますが、「別の日に自力正解」の回数には含めません。少ないヒントで解けたことだけで、完全な習熟や合格を断定しません。

06 / 過去問の準備

問題を集めて、学べる形にする。

過去問と公式解答を対応づけ、独自のヒントと解説を加えます。図表や条件を欠落させないことを大切にします。

  1. 過去問と公式解答を集める

    年度・出題区分・問題番号・出典を付け、重複を見分けます。

  2. 問題文・選択肢・図表を取り込む

    抽出が難しい図表は原資料の画像を保持。抜けや誤変換を確認します。

  3. ヒントと解説を追加・編集する

    次に何を考えるかが分かるヒントと、正誤の理由が分かる解説を作ります。

  4. 内容を確認して、演習に登録する

    公式解答との一致、計算・単位・用語を確認します。

教材は10問ずつ原本と照合します。作成者と別の確認担当が解き直し、修正した内容を再確認します。

教材作成の進み具合を見る

  • 2021年春：80問が完成。

教材の品質を守るルールを見る
  • 確認が終わっていない問題は、通常の演習セットに混ぜません。
  • 各選択肢の正しい理由・誤りの理由を確認します。
  • 少数の重要な考え方には、関連する別の過去問も対応づけます。
  • AIを下書きに使っても、内容確認を行います。
  • 第三者の解説をそのまま移しません。外部公開する場合は教材の利用条件を確認します。

F09 学習単位開始ボタンひとつ。1問ずつ自由に続行・終了。
F10 データ管理書き出し、読み込み、削除。保存先も説明。
F11 関連問題同じ考え方を使う別問題で確かめる。
F12 基礎説明短い説明や解法例へ戻れる。
F13 教材化過去問と解答の取り込み、ヒント・解説の追加と編集。
完成を確認する14項目を見る
  1. ヒント2を使って正解したら、「ヒント付き正解・段階2」と保存され、復習候補になる。
  2. 回答前に答えを見たら、後から正答しても自力正解にしない。
  3. 回答後の解説閲覧で、回答前のヒント記録は変わらない。
  4. 途中で閉じても、同じ試行の回答候補とヒントを復元できる。
  5. 再挑戦は新しい試行になり、前の履歴が残る。
  6. 同日の連続正解は、別の日の自力正解回数に含めない。回数だけで習熟を断定しない。
  7. 復習は答えを伏せ、ヒントを閉じて始まる。
  8. 1問で終了でき、タイマーなしで基本機能を使える。
  9. 保存失敗が分かり、書き出した記録を読み戻せる。
  10. スマホ、キーボード、文字拡大で問題・ヒント・回答・再開を操作できる。
  11. 「あとで」は誤答にならず、別の問題へ進め、あとから再開できる。
  12. ヒントに待ち時間がなく、正答を明かす支援は自力正解に含めない。
  13. 関連する別問題の結果を、同じ問題への再回答と分けられる。
  14. 過去問に解答・図表・出典が対応づき、ヒント・解説を追加・編集できる。

学習法の根拠と、まだ確かめること

研究から参考にしたこと：思い出して答える練習、間隔をあけた復習、解法例と演習の組合せ、間違いの理由が分かる解説。

設計指針から参考にしたこと：刺激を減らす、主要な操作を短くする、必要なときに支援を使える、現在地を示して再開しやすくする。

具体的なヒント数や復習日数は初期案です。一般の学習研究を参考にした部分もあり、このアプリのADHDの成人への効果は、実際に使って確かめる必要があります。

最初の1〜2週間は操作・着手・再開を見ます。保持と応用は数週間の利用で、後日の自力解答と別問題への適用を確認します。回答数と未実施数も分け、簡単な問題だけの正解率を全体の習熟にしません。
