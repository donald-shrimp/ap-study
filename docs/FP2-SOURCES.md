# FP2級の出典

日本FP協会「2級ファイナンシャル・プランニング技能検定 学科試験 2026年5月公表分」全60問を加工して作成。原本の法令基準は2025年4月1日。正答・解説はその基準で扱います。

- [公式問題・正答](https://www.jafp.or.jp/exam/mohan/files/g2_202605_qa.pdf)
- [日本FP協会の公表問題一覧](https://www.jafp.or.jp/exam/mohan/)
- [試験問題の利用条件](https://www.jafp.or.jp/exam/mohan/files/exam_riyou.pdf)

問題文と選択肢を文字起こしし、表を整形、親族関係図を切り出しました。学習用の解説と各選択肢の理由は「ひと問」が追加しています。問題の著作権は日本FP協会・金融財政事情研究会に帰属します。

原本PDFのSHA-256は `525d190bb489b4187d39d6782eac999fc4b14bfdd1f489842b96685465b804ef`。全問を作者とは別担当が原本・公式正答から照合し、指摘3件は修正後に再確認しています。
