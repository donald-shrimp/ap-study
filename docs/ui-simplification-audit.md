# ひと問の画面・機能の見直し候補

2026-11-18。ローカル版の応用情報（科目A・B）、FP2級（学科・実技）、AB730が対象。通常学習、分野、問題検索、記録、解き直し、試験回、診断・模試、計画、単語帳、AI、設定、オフラインを調べた。Chromeの新規学習環境で主要画面を確認し、既存データ・同期・通信失敗などの条件付き表示は実装を照合した。利用頻度の実測はないため、機能自体の廃止候補は最後にまとめた。

実画面では、未回答で終えた80問模試に80件の解説の開閉が並び、科目B・FP2級実技の4欄の小問には答え合わせに関わるボタンが9個並んだ。科目Aの新規ユーザーの記録画面にも、各分野の推移・メモの入口と、空の全体推移・達成・履歴が同時に表示された。

残す判断の基準は、学習者がその場で答える、振り返る、次へ進む、再開する、目的の問題を探すために使うかどうか。正常時の説明は必要な場面に寄せる。原問の条件、出典、法令基準日、記録の保護、読みやすさの設定に関わる表示は、必要な利用場面を保って整理する。[共通デザインルール](design-system.md) · [前回の表示整理](ui-copy-implementation.md)

[候補にチェックして依頼文を作る](ui-simplification-checklist.html) · 候補番号だけでも依頼できます。2026-11-19に対応した項目は「実装済み」、残りの対応がある項目は「一部実装」と表示しています。

今回の47項目は、ホーム・設定、答え合わせと科目B、記録と試験、計画、単語帳とAIの順に実装した。設定から教材の保存を管理でき、試験回を一つ選んだ画面からその回だけを保存できる。学習計画は「記録」から開ける。試験の再開・途中終了、教材の削除、旧診断バックアップの読み込みは各画面から引き続き使える。
