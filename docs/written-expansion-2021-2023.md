# 科目Bを2021年までの110大問へ拡充

既存2024・2025年春秋の44大問を保持し、2023・2022・2021年の春秋各11題、計66大問を追加する。目標は5年10回分・110大問。2023年、2022年、2021年の順に、各年22題の独立レビューが揃ってから統合・検証・公開する。

## 作成と独立レビュー

公式資料はIPAの[2023年](https://www.ipa.go.jp/shiken/mondai-kaiotu/2023r05.html)・[2022年](https://www.ipa.go.jp/shiken/mondai-kaiotu/2022r04.html)・[2021年](https://www.ipa.go.jp/shiken/mondai-kaiotu/2021r03.html)の問題・解答例・採点講評18PDF。取得した原本とURL/SHAは[資料一覧](../content/ap/written-drafts/2021-2023/sources/sources.json)に保存する。原本PDFを一度レンダリングした `assets/written/ap-r03a-source/` 等の画素を保持し、各題の本文図はその既存画像から切り出す。本文・条件・下線・表・全図・選択肢・全回答欄を省略しない。

6作成担当が各回11題を作成し、作者とは異なる確認担当が全原本・全完成本文・各解説と学習用確認ポイントを照合する。確認者は可能な範囲で草稿と公式例を先に見ずに原問から解答・検算を保存し、先に見えた箇所を正直に記録する。全問未見で解いたとの一括表記はしない。疑義は原本を拡大し、指摘撤回や訂正も保存する。最終教材のcanonical SHA-256、全PDF・全原本画像・クロップのSHAを保存して、承認済みだけを公開バンクへ登録する。

説明文・順不同の複数回答・図示は自己評価。図を文字で説明する場合は形・線・方向等も確認し、単語の一致で図が正しいと扱わない。短答の登録例一致は自動判定し、それ以外は自己評価へ。字数指定がない欄の2000字はアプリの入力上限であり、公式条件と区別する。公式の部分点採点や描画入力を実装したとは扱わない。

## 保持と検証

既存44題のID・版・本文・図・設問・解答例・解説・確認記録のcanonical SHAを[固定台帳](../content/ap/written-drafts/2021-2023/preserved-2024-2025.json)で保持する。開始済み記録の固定教材とIDを変更しない。A800問・681カード・180派生・固定模試2回、AB-730174問、保存形式v2・同期・Rules・個人記録は変更しない。本人の本番別端末での移行照合は別の未確認事項として保持する。個人ファイルを公開リポジトリへ追加しない。

各年の統合後に教材の全ハッシュ・全回答型の回答/評価・バンク生成・元44題不変、全収録題のブラウザ表示と各欄・本文図・回答と自己評価・AI・再読込・バックアップ往復・オフラインを検証する。320/390/1440pxで本文/小問を確認し、PWA更新とA/Bの入口・記録分離も確認する。main/ref整合を確認して非forceで反映し、Pages成功・公開ファイルのバイト一致・実サイトの新規題操作を確認する。

進捗・担当・未確認草稿・次の対象は [progress.json](../content/ap/written-drafts/2021-2023/progress.json)。作成と照合の根拠は同ディレクトリの各担当領域へ保存する。2021年まで完了した後の古い年度は今回の追加範囲に含めない。

統合は `python tools/integrate-written-cases.py --year 2023` で事前照合し、`--register` で反映する。2022年・2021年も同様。承認22件・作者最終版一致・全PDF/画像SHA・元44題不変と順序が揃わなければ停止する。反映後に `python tools/build-content.py` と各検証を行う。

担当の流れ：2021年の作成担当は最初の3題を保存後、2023年の独立レビューを先行してから2021年作成を再開する。2023年の作成担当は完成後に2022年を、2022年の作成担当は完成後に2021年を確認する。各題の作者と確認者は別であり、担当名を役割に合わせて偽らない。現状と次の対象は進捗の `activeAssignments` / `reviewAssignmentPlan` と各担当のevidenceに残す。


## 今回の区切りと再開位置（2026-10-16）

ユーザーの「キリのいいとこまで」に合わせ、2023年春秋22題を公開し、2023〜2025年6回分・66大問までを今回の区切りとする。目標110大問は継続し、残り2022年22題→2021年22題の順に進める。未レビュー草稿は公開教材へ登録しない。

2022年は春秋各11草稿を保存。秋はQ1〜6承認済み、Q7の原問38〜41頁を表示した位置から公式例・作者草稿・完成図と照合を再開。春はQ1〜5担当領域とQ6担当の独立所見から確認を再開（正式承認0）。2021年は秋11草稿、春Q1〜4草稿を保存、春Q1〜3のみ承認済み。春の作成はQ5（原問24〜27頁）から、Q4は別担当レビュー待ち。担当割当はprogressと各evidence/resumeに保持する。未公開の草稿・図・所見は作業ツリーと作業領域の圧縮バックアップに保存し、本人の個人記録を混ぜない。
