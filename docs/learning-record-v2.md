# 新しい学習記録と一回移行

2026-10-15。学習・同期・Exportは新形式だけを使用します。旧形式の読取はアプリに残しません。既存コードはGitタグ`subject-b-before-v2-20261015`、旧IndexedDB／localStorage／Firestore文書は元の領域へ保持します。

## 保存する形式

学習記録は`hitomon-learning-record` / version 2です。`qualificationId`＋`examPartId`、教材ID・版・固定教材、回答、評価、支援の閲覧、開始／更新日時を保持します。

- `kind: question`：`response.choiceIds`で単一・複数選択を同じ形に保存。教材の正答も`correctChoiceIds`。位置番号や単一用の正答IDを重複保存しません。`evaluation`は自動判定の結果・確定日時・回答前の支援数、`assistance`はヒントの履歴と正答開示、`progress`は途中状態・継続範囲等です。
- `kind: case`：共通本文は大問に1つ。小問・解答欄のIDで`responses`を持ち、入力途中、回答確定、評価確定を分けます。`evaluations`を回答とは別に持ち、各欄の`source`は`automatic`または`self`。説明文は学習用観点で自己評価し、公式の部分点を推測しません。短答の未登録表現も自己評価へ残します。初期契約は1大問20欄までです。
- 診断・模試は`hitomon-assessment` / version 2で固定した問題の`record`と、ID配列による回答を保存します。受験中にヒント・解説・AIを表示しません。
- 計画、計画履歴、学習設定、単語帳のExportもversion 2です。表示・内部計算のための一時的な投影オブジェクトは保存契約とは別です。旧ファイルの読取器を二重運用する意味ではありません。

端末保存領域・Firestoreの`attemptsV2 / resourcesV2 / learningV2 / personalV2 / cardsV2 / writtenV2`を旧領域と隔離します。ログイン前の記録も別管理し、明示した取り込みだけでアカウントへ追加します。同期で今開いている科目や入力欄を切り替えません。大問の本文位置・小問・部分回答を保存し、端末間で競合した場合は内容を選ぶか別の取り組みとして保管できます。

## 本人が保管するファイル

2026-10-15：本人から旧バックアップを受領し、非公開領域へ原本を保管して一回変換しました。記録・評価・日時・支援・計画・単語帳の照合と、公開アプリの隔離ブラウザでの取り込み／再書き出しを確認済みです。別添の診断は学習バックアップ内の診断と同一、教材の書き出しは公開教材と同内容なので重複追加しません。本人データ・変換ファイル・詳細報告は公開リポジトリに含めません。利用者が本番への再登録完了を報告しました。こちらが本人アカウントを操作したものではなく、別端末での復元は未確認です。

旧版で保存した、応用情報・AB-730の「学習記録」と応用情報の「単語帳記録」を使用します。原本は上書きしません。

```sh
node tools/convert-study-backup.mjs 元のAP.json AP-v2.json ap
node tools/convert-study-backup.mjs 元のAB730.json AB730-v2.json ab730
node tools/convert-study-backup.mjs 元の単語帳.json 単語帳-v2.json ap
```

出力済みファイルへの再変換／上書きは拒否します。旧計画の問数をBの題数へ読み替えず、Aの取り組み問数へ変換します。ID・件数・日時・正誤・ヒント利用とイベント・教材版・個別教材・計画履歴を照合し、SHA-256付き変換報告を別ファイルに保存します。曖昧な目標分配や不足した教材を現在教材で推測補完しません。

## 取り込み

利用者は新版Rulesを公開済みと報告しています。Googleログインし、「設定 → 記録・教材の管理 → 学習記録を読み込む」で資格に対応するv2ファイルを選びます。ログイン中は履歴を追加し、既存の記録・計画を保持します。同じIDの回答・評価・支援・教材などの違いは上書きしません。端末ごとのスクロール位置・表示メモだけが異なる場合は同じ記録として扱い、現在端末の表示状態を保持します。単語帳は個別の取り込みを使用します。ログアウト中の通常記録取り込みは端末の記録の置き換えなので、画面の確認内容に従います。

最後に「今すぐ同期」で完了を確認し、別端末で件数・回答・ヒント・計画・単語帳を照合してから移行完了とします。原本受領・変換・取り込みテストの完了と、本番アカウントへの移行完了は区別します。本人による本番への再登録は完了報告を受領済みですが、同期完了と別端末での確認が終わるまで、移行全体の完了とは扱いません。
