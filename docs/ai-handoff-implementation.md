# AIに聞く — 実装・レビュー記録（2026-10-12）

## UIと安全性

- 通常学習の導線を優先。問題回答後・解答閲覧後の解説下にだけ控えめな「AIに聞く」ボタンを表示する。ホーム、診断、模試、「もう1問」「今日はここまで」の動作は変更しない。
- ダイアログからChatGPT・Gemini・Claude、任意の追加入力を選ぶ。問題文、選択肢、正解、本人の回答、解答解説、選択肢理由、教材ヒントを質問文にまとめる。
- 文字起こしが確認済みの問題だけ本文を送る。画像だけの問題で検索用の未検証OCRを原文として渡さず、原本・図のURLを渡し、画像を開いて添付する導線を用意。
- Android実機で成功したモックの方式：コピー成功後に同じタブで外部AIへ移動。新規タブを先に開かず、コピー失敗なら移動せず、手動コピー欄とエラーを示す。
- AI APIを使わず、学習記録・Firebase・教材データを変更せず、ボタンを押さない限り外部サイトへ移動しない。AI側での自動貼付やChatGPTアプリの起動は保証しない。

## 確認済み

- V8上で実装の実コードを使い、質問文生成、原本画像URL、追加入力、コピー→遷移の順序、コピー権限拒否時の手動操作、回答前のブロックを確認。
- 共通HTMLテンプレートとindex.html・ap/index.htmlの整合性、PWAのリリース番号、オフラインキャッシュへ新規モジュール登録を確認。
- 既に実機で成功した検証モック（docs/ai-handoff-same-tab-mock.html）を基準に実装。
- PRブランチに限る変更であり、実アプリ全体のブラウザE2EテストとAndroid実機検証はまだ実施していない。
