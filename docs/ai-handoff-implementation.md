# AIに聞く — 実装・レビュー記録（2026-10-12）

回答後に理解できなかった問題を、ChatGPT・Gemini・Claudeへ相談するための質問文にまとめる。解説の下に控えめな「AIに聞く」を置き、通常学習の開始・継続を優先する。診断・模試の受験中には表示しない。

## 動作

- 採点・解答閲覧後の問題と教材スナップショットを使用し、本文・4択・正解・本人の回答・解説・選択肢理由・教材ヒント・任意の質問をまとめる。
- 文字起こし済みの本文を使用し、本文がない問題の検索用OCRは渡さない。原本・図のURLと画像を開く導線を提供し、同じURLは重複させない。画像の添付は利用者が行う。
- コピーが成功してから同じタブで外部AIへ移動する。コピー拒否・未対応時は移動せず、手動コピー欄を表示する。質問文だけをコピーすることもできる。
- コピー中は宛先・質問文を固定し、閉じる／Escapeでキャンセルした処理は後から遷移しない。開き直したダイアログへ旧処理の結果を反映しない。
- 学習記録・Firebase・教材・資格定義は変更しない。AI API・自動送信・Intentによるアプリ起動は使用しない。

## PR #1のレビュー

作者のPRを主担当/rootがコードレビューし、最新main（文字表示498問＋原本保持2問）を取り込んで検証した。元PRでコピー待ちに閉じても遅れてChatGPTへ移動する不具合を実ブラウザで再現し、キャンセル判定と処理中の入力固定で修正。原本URLの重複除去も追加した。

PRのE2Eテストは2枚目のタブが保存済み演習画面へ戻ることを考慮しておらず、ホームボタン待ちで停止していた。保存後の再開状態からも開始できるよう修正し、AIから戻った後の記録保持・3宛先・ネイティブクリップボード・キャンセル／再表示・キーボード操作を追加。既存E2Eの文字起こし後の折りたたみ原本参照と、PWAテストのチェックアウト名への依存も修正した。
