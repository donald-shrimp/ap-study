# AIに聞く — 実装・レビュー記録（2026-10-12）

回答後に理解できなかった問題を、ChatGPT・Gemini・Claudeへ相談するための質問文にまとめる。解説の下に控えめな「AIに聞く」を置き、通常学習の開始・継続を優先する。診断・模試の受験中には表示しない。

## 動作

- 採点・解答閲覧後の問題と教材スナップショットを使用し、本文・4択・正解・本人の回答・解説・選択肢理由・教材ヒント・任意の質問をまとめる。
- 文字起こし済みの本文を使用し、本文がない問題の検索用OCRは渡さない。原本・図のURLと画像を開く導線を提供し、同じURLは重複させない。画像の添付は利用者が行う。
- 主ボタン1回で質問文をコピーし、完了後に約500ms待って別タブで外部AIを直接開く。待機用タブは作らない。端末保存の成功も待つ。待ち時間はコピー成功時から始まり、保存と並行するので保存待ちが長いときは重ねて500ms追加しない。コピー拒否・未対応時は移動せず、手動コピー欄を表示する。質問文だけのコピーと手動リンクも維持。
- コピー中は宛先・質問文を固定し、閉じる／Escapeでキャンセルした処理は後から遷移しない。開き直したダイアログへ旧処理の結果を反映しない。
- 学習記録・Firebase・教材・資格定義は変更しない。AI API・自動送信・Intentによるアプリ起動は使用しない。

## 待機用タブなしで直接開く試用（2026-10-13）

利用者の希望で、タブの事前確保と「AIを開いています…」の待機画面を削除。コピー・記録保存・コピー後500msの待機が完了してから、`window.open`にAIのURLを直接渡す。開いたタブの`opener`を切り離し、元の学習画面を残す。キャンセル・コピー失敗・保存失敗ではタブを開かない。ブロックされた場合はコピー済みの質問文と手動リンクで再試行できる。同じタブへの移動や、待機用タブを使う方式への自動切替は行わない。

`tests/ai-handoff-e2e.py`はChromiumの既定起動引数`--disable-popup-blocking`を外して実行。通常の500ms待機、実クリップボード、3宛先、AIのURLを直接1回だけ開くこと、コピー／待機中のキャンセル、ブロック後の手動再試行、元画面の再読込後の回答・ヒント保持を確認。`tests/ai-handoff-saving.py`で保存前にタブを開かないこと、失敗／キャンセル／再試行、手動リンクの保存待ちを確認。コピー時から6.5秒保存を遅らせるケースでは実際のポップアップブロックと元画面保持・手動回復を確認した。待機中に自動テストの評価処理でユーザー操作の有効期間を延ばさないよう、タイマーだけで保存を再開する。PWA更新・オフライン再開、教材整合、AI／通常学習11ドメインテストも成功。実Androidでの試用結果は未確認。リリース`20261013-ai-direct-tab1`。

## 旧方式：別タブを先に確保（2026-10-13）

利用者の希望に合わせ、ChatGPT・Gemini・Claudeを別タブで開く方式に変更。コピー成功後、クリックのユーザー操作が有効なうちに待機用タブを確保し、そのタブの`opener`を切り離す。コピー前にはタブを開かない。記録保存とコピー後500msの待機が完了したら、確保したタブだけをAIへ移動する。元の学習画面と回答・ヒントはそのまま残す。

コピー失敗時はタブを開かず、キャンセル・保存失敗時は確保したタブを閉じる。利用者が待機用タブを閉じた場合も、新たなタブを勝手に開かない。ブラウザがタブをブロックした場合はコピー済みの質問文と手動リンクを表示し、元画面を同じタブで置き換えない。手動リンクも別タブと保存完了待ちを使用する。

以前の同じタブ方式は初期モックから引き継いだ仕様で、コピー前に`window.open`を呼ばない意図がコードに記載されていた。Androidの古い貼付内容の報告を受け、2操作を試した後、利用者の希望で1操作と500ms待機へ変更した経緯は下記に残す。今回もコピー成功からの待機を維持する。実AndroidやAI側キーボードの貼付候補はこの環境で検証できておらず、ChromiumのAndroid UA・タッチ・モバイル画面による確認と区別する。

確認：`tests/ai-handoff-e2e.py`の実クリップボード→別タブ、3宛先、`opener`なし、480ms以上の待機、元画面の再読込後の記録保持、コピー失敗、キャンセル、タブブロックと手動再試行、待機用タブの手動閉鎖。`tests/ai-handoff-saving.py`では6秒の保存待ち、保存失敗・再試行・キャンセル・手動リンクも確認。`tests/ai-handoff-content.py`の画像保持問題の固定IDを最新の未文字起こし問題から選ぶよう更新し、実教材・オフライン・支援なし診断を検証。通常E2E・PWA更新・教材整合と11ドメインテストも対象。教材・保存形式・Firestore Rulesは変更しない。リリース`20261013-ai-new-tab1`。
