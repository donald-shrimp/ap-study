# 教材ごとの事前ダウンロード

リリース `20261022-offline-materials`。ユーザーが承認した保存範囲は、問題文・解説・必須の図・選択肢画像。補助的な原本画像や外部参考資料はオンライン参照とし、原本追加オプションは設けない。[検証記録](offline-download-verification.json)。

## 操作

「学習」タブ最下部の「オフライン学習用に保存」から教材を選ぶ。

- 科目A：年度・春秋ごとに80問。全800問も一括保存可能。単語帳681枚も選べる。
- 科目B：年度・春秋ごとに11大問。現在公開済みの全88大問も保存可能。
- AB-730：7教材を選択し、全174問も保存可能。

追加保存量・進捗・未保存／途中まで保存／保存済み／更新ありを表示する。中止後は完了したファイルを再利用し、残りから再開。教材削除は学習記録や他教材の共通ファイルを消さない。保存は端末単位で、別端末へ画像一式を同期しない。利用前に「保存できました」と表示されることを確認する。

## 保存範囲と容量

問題・解説・必要画像の合計は、AB-730約0.5MB、科目A全800問約9.84MB、科目B全88大問約27.84MB。共通の起動用データが約2〜4MB必要だが、教材ごとに重複しない。表示容量は既存キャッシュを確認した追加分であり、通信圧縮やブラウザ管理領域とは異なる。

本文が文字表示の問題は補助原本を保存せず、本文が画像表示の `r04h-q16` と `r03a-q52` だけはその画像を必須として保存。図の中に選択肢がまとまっている形式、個々の選択肢画像も保持する。原本画像だけを別途約75MB／約190MB保存することはない。

新しい実力診断・模試の準備や公式PDF・外部参考サイトは、この教材保存の対象外。既に準備した診断・模試のオフライン再開は従来どおり。補助原本は明示的に開いたときだけオンライン取得し、オフラインでは参照に接続が必要と表示する。

## 実装と整合性

- `tools/offline_content.py` が公開用の生成済み教材から範囲・容量・SHA256を作る。資格manifestからハッシュ付き一覧を参照する。草稿・未公開教材・個人記録は列挙しない。元の問題・解説・正答・画像・独立レビューは変更しない。
- `src/domain/offline-assets.js` で通常学習・オフライン可否判定・診断画像準備の必須画像を揃える。
- 保存管理はボタンを押したときだけ遅延読み込み。起動時に保存一覧の取得や全ファイル検査を待たない。
- `src/features/offline-store.js` は本文と画像を既存CacheStorageへ保存する。完全SHA・バイト数の一致を確認し、異常・容量不足・通信断で完了扱いにしない。保存開始・完了・一覧を開いたときに実体を調べる。
- 選択した教材の不足分だけ最大3並列で取得する。共通の起動データは教材削除時も維持。削除した教材の学習記録はIndexedDBに残る。
- 科目Bは必須図が揃っていない大問をオフラインで新規開始させない。保存済み大問を上部の開始候補にする。既存の回答は保持する。
- 新SWの準備が済む前に保存完了としない。旧SWの場合は設定から更新するよう案内する。公開教材の保存情報をFirebaseの個人記録やバックアップに混ぜない。
- 起動中に通信失敗の通知が来た場合、その後のキャッシュ読み込みでオンライン判定に上書きしない。

## 検証

`tests/offline-content.py` で全教材の範囲・SHA・サイズ、必須画像、補助原本除外を確認。`tests/offline-store.mjs` で切断・中止・再開・不正SHA・破損・容量不足・共有ファイル削除を確認。

`tests/offline-download.py` は隔離したゲスト環境で、学習記録を増やさずに科目A全800問とAB-730全174問を保存し、未着手問題・必須本文画像・図・解説を完全オフラインで利用。科目Bの図・記述入力・公式例・自己評価・再読み込み、未保存大問の開始防止、教材削除後の記録保持、320/390/1440pxを確認。本人の個人記録は使っていない。

PWA更新・オフライン再開、既存A/B分離、AB-730複数選択17題・30問診断、実Authエミュレータでの所有者と中断画面の復元も検証。科目B88大問のレビュー・正答・原本・画像のcanonicalとAP800問を保持する。
