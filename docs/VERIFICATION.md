# モックの動作確認

2026-10-05、Chromiumのブラウザ操作で確認。

- 初回ホーム表示、問題データの読み込み
- 選択肢と閲覧済みヒントをリロード後に復元
- 不正解の保存、解答後の追加ヒントを解答前の数に含めない
- 解き直し時に新しい履歴を作成し、以前の不正解を保持
- 自力正解とヒント利用での正解を区別
- 図と4選択肢の画像を読み込み
- 「あとで解く」を未解答として保存
- 解答を先に見た記録を正解に数えない
- 正解でも自信なしの問題を復習候補に入れる
- 答えを含む編集ヒントの閲覧を、解答確認として扱う
- 学習記録の書き出しと有効な記録の読み込み
- 不正な記録ファイル・想定外の教材フィールドを拒否
- 以前の学習記録にその時点の教材を保持
- スマートフォン幅390pxと大きな文字で、横にはみ出さない
- JavaScriptの実行エラーがない

問題の正解はIPA公式解答PDFと照合（問1＝エ、問10＝エ、問21＝ウ、問36＝ウ、問37＝ア）。画像の切り出しとPC・スマートフォンの画面を目視確認。

既知の範囲：localStorageによる1ブラウザ・1タブのモック。端末間同期、大量教材の収集画面、復習日の手動変更は未実装。実利用での学習効果はまだ評価していない。
