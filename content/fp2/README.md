# FP2級の作成元

日本FP協会の2026年5月公表・学科60問を収録。原本の法令基準は2025-04-01。実技は未収録。

公開作成元は `questions.json`、実際の独立確認と原本・完成教材のハッシュは `question-reviews.json`。元の草稿と確認経緯は `delivery/` に保持する。公開範囲・出典は [FP2級の出典](../../docs/FP2-SOURCES.md) を参照。

作成・納品形式は [外注用手順](../../docs/fp2-authoring.md)。科目ID・分野IDは `qualification.json` を使う。
