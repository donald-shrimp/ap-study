Agent Builder に組み込まれたエージェントの共有と管理
フィードバック
Agent Builderで構築したエージェントをorganization内のユーザーと共有できます。 エージェントは複数の所有者をサポートするため、チーム全体で所有権を共有できます。 すべての所有者がエージェントを編集、管理、保守できます。 エージェントを共有すると、指定したユーザー セットがエージェントに直接アクセスできるようになります。 チーム コラボレーションには理想的ですが、エージェントを共有すると、organization 全体でのデプロイや他のチャネルとの統合は許可されません。
この記事では、Agent Builderで構築したエージェントを共有および管理する方法について説明します。 複数のチャネルでエージェントを公開するには、Copilot Studio を使用する必要があります。 詳細については、「 エージェントの公開と展開」を参照してください。
エージェントを共有する
Microsoft 365 Copilot でエージェントを構築してテストしたら、[作成] を選択します。 エージェントが作成されると、エージェントがプライベートであり、自分だけが使用できることを示す確認メッセージが表示されます。 エージェントを他のユーザーと共有するには、[ 共有] を選択して共有ダイアログを開きます。
共有ダイアログには、アクセス権を持つすべてのユーザー、その役割、組織全体の共有トグル、およびいつでもコピーできるリンクが一覧表示されます。
注:
管理者は、特定のエージェント共有オプションを制限するポリシーを適用する場合があります。 このガバナンスの変更は実装時に適用され、既存のエージェント アクセス許可は取り消されません。 共有オプションが organization 内で制限されている場合、管理者はエージェントを承認して展開し、organization内の他のユーザーが利用できるようにする必要があります。 ガバナンス ポリシーが変更された場合は、エージェントを更新する前に、必ずエージェントの共有オプションを準拠するように更新してください。

所有者とチャット ユーザーを追加する
共有するエージェントを開き、[ 共有] を選択します。
共有ダイアログ ボックスで、[ 名前、グループ、またはメールの追加 ] ボックスに名前、グループ、またはメールを入力します。
[ ユーザーの追加 ] パネルで、追加するユーザーのロールを設定します。
[ 編集可能] を選択して、完全な編集権限と管理権限を持つ所有者として追加します。
[ チャット可能] を選択して、エージェントとのみ対話できるチャット ユーザーとして追加します。
新しいユーザーにメールを送信する場合は、[ 通知を送信する ] チェック ボックスをオンのままにして、アクセス権があることを通知します。 メールを送信しない場合は、チェック ボックスをオフにします。
[追加] を選択します。
共有が完了すると、確認が表示され、チャット リンクをコピーして直接共有できます。
注:
エージェントの機能は、ユーザーのライセンスによって異なります。 ユーザーは、そのエージェントで構成された機能にアクセスするために必要な Microsoft 365 Copilot ライセンスの種類を持っている場合にのみ、共有されているエージェントを追加できます。 ユーザーがエージェントの機能に対する適切なライセンスを持っていない場合、エージェントを使用しようとするとエラーが発生する可能性があります。 詳細については、「 Microsoft 365 ユーザー向けのエージェント機能」を参照してください。
ユーザーの役割を切り替える
所有者は、共有ユーザーのロールをいつでも変更できます。
[ 共有] ダイアログを開きます。
ユーザーの横にあるロールのドロップダウンを選択します。
新しいオプションを選択します。
編集可能 - ユーザーを完全な権利を持つ所有者に昇格させます。
チャット可能 - ユーザーをチャット ユーザーに変更します。
削除 - ユーザーのアクセス権を取り消します。
変更は直ちに有効になります。
リンクのコピー、編集、チャット
共有ダイアログにはリンクが表示されるため、移動しなくてもアクセスを共有できます。
Chat link - エージェントとのみ対話する必要があるチャット ユーザー向け。
[リンクの編集] - エージェントを作成および管理する必要がある所有者向け。
[ チャット リンクのコピー ] を選択するか、[ 編集] リンクを選択して、メール、チャット、またはドキュメントに貼り付けます。
組織全体の共有を有効にする
テナント内のすべてのユーザーがエージェントを使用できるようにするには、チャット アクセスの組織全体の共有をオンにします。
[ 共有] ダイアログを開きます。
[ チャット アクセスの組織全体で共有 する] トグルをオンにします。
トグルをオンにすると、同じテナント内の他のユーザーはエージェント ストアでエージェントを確認できるため、エージェントを見つけてチャットを開始できます。
ガバナンスと管理者の制御
テナント管理者は、組織レベルでエージェントを共有できるユーザーを管理できます。 これらの制御は、コンプライアンスを維持し、過剰共有を防ぐのに役立ちます。
管理者は、Microsoft 365 管理センターで次のいずれかのオプションを構成できます。
すべてのユーザー (既定):Everyone can share agents with the organization.
特定のユーザーまたはグループ: 共有アクセス許可を選択したユーザーまたはグループに制限します。
ユーザーなし: 組織全体の共有を完全に無効にします。
注:
管理者コントロールへの変更は、新しい共有操作にのみ適用されます。 共有設定を手動で更新しない限り、既存の共有エージェントには引き続きアクセスできます。
組織全体の共有が無効になっている場合、[ チャット アクセスの組織全体の共有 ] トグルがグレー表示され、制限を説明するツールヒントが表示されます。
ZIP パッケージをダウンロードしてエージェントをサイドロードする
Microsoft 365 Copilot には、手動サイドローディング用に ZIP パッケージをダウンロードするオプションが用意されています。 この ZIP パッケージには、 エージェントを Microsoft Teams にサイドロードするために必要なファイルが含まれています。
ZIP パッケージをダウンロードしてエージェントを手動でサイドロードするには:
Microsoft 365 Copilot の左側のウィンドウで、 [新しいエージェント] を選択します。
[New agent] ページの [ My agents] で、[ View all agents] を選択します。
ダウンロードするエージェントを選択し、省略記号 (...) を選択します。
[ Download .zip file (ファイルのダウンロード)] を選択します。 .zip ファイルには、エージェント マニフェストとアプリ アイコンが含まれています。
エージェントを Microsoft Teams にサイドロードします。
注:
ZIP パッケージには埋め込みファイルを含めることはできません。 ZIP パッケージから埋め込みファイルのコンテンツを削除します。
Teams でのエージェントのサイドローディングは、macOS ではサポートされていません。
SharePoint ファイルとフォルダーを自動的に共有する
エージェントを共有すると、Copilot ユーザーが基になるすべてのナレッジ ソースにアクセスできない可能性があります。 他のユーザーをチャット ユーザーまたは所有者として追加すると、SharePoint のナレッジ ソースを共有できます。 ただし、エージェントはエンド ユーザーの情報と秘密度の特権を尊重します。 したがって、ユーザーがナレッジ ソースにアクセスできない場合、エージェントは応答を生成するときにナレッジ ソースに含まれるコンテンツを含めません。
共有する SharePoint フォルダーとファイルを選択できます。 共有は、エージェントの所有者が共有または共有アクセス許可を更新するアクセス許可をすでに持っている場合にのみ機能します。 SharePoint または OneDrive のファイルに適用されるファイルの秘密度ラベルが尊重されます。 ファイルまたはフォルダーでの共有が失敗した場合でも、エージェントはユーザーと共有されます。 所有者は、ファイルの所有者または SharePoint サイト管理者に連絡して、SharePoint から直接ファイルまたはフォルダーへのアクセス許可を付与する必要があります。
注:
エージェントに明示的に追加したファイルとフォルダーのみ、自動的に共有できます。 エージェントを共有するユーザーは、SharePoint サイトへのフル アクセスを自動的に利用できるわけではありません。 サイト管理者は、サイト設定を介してユーザーにアクセス許可を付与する必要があります。
エージェントへのユーザーのアクセス権が削除された場合、共有ファイルまたはフォルダーへのアクセスには影響しません。 SharePoint 経由でファイルとフォルダーに直接アクセスするためのユーザー アクセス許可を管理します。
エージェントの [バージョン情報] 情報を更新する

ダイアログを開くには、エージェント作成ヘッダーの その他の省略 記号 (...) を選択し、[ このエージェントについて] を選択します。

組織カタログにエージェントを送信する
エージェントの共有バージョンとエージェントストアバージョンは別々に管理されます。 共有バージョンを管理し、いつでもその反復処理を続行したり、共有相手を変更したり、テスト用に非公開にしたりすることができます。 エージェントを発行した後、管理者がエージェント ストアのバージョンを管理します。
エージェントを organization 内で広く検出できるようにするには、エージェントを組織カタログに発行します。 管理者は Microsoft 365 管理センター でエージェントを確認し、承認された場合は、エージェント ストアの [組織によってビルド] セクションにエージェントを展開します。
送信手順、必須フィールド、承認ステータスの追跡、承認後の更新については、「 エージェント ビルダーから組織カタログにエージェントを送信する」を参照してください。
エージェントの管理
Microsoft 365 Copilot のエージェント管理機能にアクセスできます。
最近アクセスしたエージェントを管理するには、左側のウィンドウで、管理するエージェントの名前の横にある その他の 省略記号 (...) を選択します。
最近アクセスしていないエージェントを管理するには、次のいずれかを実行します。
左側のウィンドウで [ すべてのエージェント] を選択します。
エージェントストアの [エージェント] で、[詳細を表示] を選択し、管理するエージェントの名前の横にある省略記号 (...) を選択します。
または
左側のペインで [ 新しいエージェント ] を選択し、[ すべてのエージェントを表示] を選択します。
管理するエージェントの名前の横にある その他の 省略記号 (...) を選択します。
注:
エージェントビルダーの[ マイエージェント ]リストには、所有するエージェントまたは[ 編集可能] アクセス権を持つエージェントのみが表示されます。 チャット ユーザーとして共有されているエージェントは、このリストには表示されません。
エージェントを編集する
共有後に変更が必要な場合は、エージェントの所有者が編集できます。
エージェントの 管理で説明されている方法のいずれかを使用して、エージェントのリストにアクセスします。
[その他の省略記号 (...)] メニューから [編集] (鉛筆アイコン) を選びます。
そこから、自然言語を使用して変更を記述できます。 [ 構成] タブを使用して、エージェントの機能とナレッジ ソースをより細かく制御することもできます。
エージェントに加えられた変更は自動的に保存されます。 ただし、変更はユーザーが使用可能にするまで表示されません。 既存のエージェントに変更を使用できるようにするには、右上隅の [ Update ] を選択します。 エンド ユーザーが変更内容を利用できるようになるまでに数分かかる場合があります。
注:
SharePoint ファイルとフォルダーのナレッジ ソースを持つ以前に共有したエージェントを更新する場合は、同じユーザーと再共有します。 これにより、ファイルとフォルダーがユーザーと自動的に共有され、一貫したエージェント エクスペリエンスが確保されます。
エージェントを削除する
エージェントの所有者は誰でも削除できます。 エージェントを削除すると、そのエージェントを使用できなくなり、他の所有者や共有したユーザーはエージェントを使用できなくなります。
重要
エージェントの削除は永続的であり、元に戻すことはできません。
エージェントを削除するには:
エージェントの 管理で説明されている方法のいずれかを使用して、エージェントのリストにアクセスします。
[その他の省略記号 (...)] メニューを選択し、[削除] (ごみ箱アイコン) を選択します。
エージェントの所有権を再割り当てする
共有ダイアログで [ 編集可能 ] ロールを持つユーザーを追加することで、エージェントの所有権を直接共有できます。 すべての所有者は、エージェントを編集、共有、管理する平等な権限を持ちます。 詳細については、「 所有者とチャット ユーザーの追加」を参照してください。
管理者は、organization内の共有エージェントの所有者を更新することもできます。 詳細については、「 共有エージェントの所有権の再割り当て」を参照してください。
PowerShell を使用して所有権を再割り当てするには、「 PowerShell を使用してエージェントの所有者を再割り当てする」を参照してください。
