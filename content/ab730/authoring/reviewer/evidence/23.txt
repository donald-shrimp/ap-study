Microsoft Copilot でのエージェントのインストール
フィードバック
Microsoft Copilot は、エージェントをインストールすることで拡張できます。
エージェントは、固有のビジネス ニーズに対応し、Microsoft Copilot 内のワークフローを強化するための追加の知識、スキル、自動化されたワークフローを提供します。 さらに、Microsoft Copilot は高度なスキルを持つ専門知識をオンデマンドで提供できます。
注:
Microsoft は、Microsoft Copilot ライセンスを持つ既存のユーザーにリサーチ ツールとアナリストをデプロイしました。
Microsoft Copilot にエージェントをインストールするには、さまざまな方法が使用されます。
エージェントのインストールとガバナンス方法
Microsoft Copilot は現在、エージェントに対して次のデプロイとガバナンス方法を提供しています。
Microsoft がインストールしたエージェントと機能
管理がインストールしたエージェント
ユーザーがインストールしたエージェント
Microsoft がインストールしたエージェントと機能
Microsoft は、非常に価値のあるスキルで Microsoft Copilot を強化する少数のエージェントと機能をインストールする場合があります。 これらのエージェントと機能は Microsoft によって構築され、すべてのライセンスを持つユーザー向けに Microsoft Copilot にプレインストールまたは事前にピン留めされています。 現在、この方法ではリサーチ ツールとアナリストのみがデプロイされます。
組織は Microsoft 365 管理センターでエージェントを管理できます。 そこでは、管理者はテナント内のエージェントをブロックして、すべてのユーザーがアクセスできないようにすることができます。 したがって、これらのエージェントを特定のユーザーおよびグループに割り当てることができるきめ細かい制御はグレー表示されます。または、管理者は organization の Copilot の拡張性を無効または制限することもできますが、これは Microsoft 以外に展開されたエージェントと、Microsoft が展開したエージェントに適用されます。 個々のユーザーは、これらのエージェントを共有およびピン留め解除することもできます。
管理がインストールしたエージェント
管理者は、独自のカスタムビルド、Microsoft ビルド、またはパートナーがビルドしたエージェントをインストールして、Microsoft Copilot を強化できます。 管理者は、制限された数のエージェントを Copilot レールにインストールすることも、Microsoft Copilot のエージェント ストアを通じてユーザーが利用できるようにすることもできます。
組織は Microsoft 365 管理センターでこれらのエージェントを管理できます。 管理者は、これらのエージェント用のライフサイクル管理ツールのフルセットを用意しています。 Microsoft では、管理者がテナント内の一部またはすべてのユーザーに対してこれらのエージェントをインストール、ブロック、および削除できる詳細な制御を提供しています。
注:
管理者が削除できるのは、共有エージェントとカスタム LOB エージェントのみです。
詳細については、「Microsoft 365 管理センターで Microsoft Copilot のエージェントを管理する」を参照してください。
ユーザーがインストールしたエージェント
ユーザーは、テナント管理者によって設定されたポリシーに基づいて、エージェント ストアで使用可能なエージェントをインストールできます。 ユーザーは、独自のカスタムビルドエージェントをインストールすることもできます。 たとえば、これらのカスタムビルド エージェントは、Microsoft SharePoint、Microsoft Copilot のエージェント ビルダー、または Copilot Studio を使用して構築され、Microsoft Copilot を拡張できます。 これらのエージェントは個人によって使用され、オプションでユーザーのorganization内で共有できます。
組織は Microsoft 365 管理センターでこれらのエージェントを管理できます。 管理者は、これらのエージェント用のライフサイクル管理ツールのフルセットを用意しています。 Microsoft では、管理者がエージェントをインストールしてブロックできる詳細な制御を提供しています。 さらに、管理者はテナント内の一部またはすべてのユーザーの共有エージェントとカスタム エージェントを削除できます。
Microsoft ビルド エージェント ライセンス
リサーチ ツールやアナリストなど、Microsoft によって構築された一部のエージェントには、Microsoft 365 製品条件を参照した補足サービス利用規約が適用され、参照することにより、データ保護補遺 (DPA) が含まれています。 同じ製品条項と DPA が Microsoft Copilot サービスにも適用されます。
