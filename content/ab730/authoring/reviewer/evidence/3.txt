注
この記事のリンクは、現在表示している Foundry (クラシック) ドキュメントではなく、新しい Microsoft Foundry ドキュメントのコンテンツを開く場合があります。
生成 AI モデルからのコンテンツ品質が向上するにつれ、AI が生成したコンテンツの情報源に関する透明性の必要も高まります。 Microsoft Foundry モデルの Azure OpenAI から生成されたすべての AI 生成イメージには、コンテンツの配信元と履歴を開示するための改ざん防止の方法であるコンテンツ資格情報が含まれています。 コンテンツ資格情報は、共同開発基盤projectであるコンテンツの実証と信頼性 (C2PA) のオープンな技術仕様に基づいています。
コンテンツ資格情報の概要
Azure OpenAI のコンテンツ資格情報は、イメージ生成モデルによって生成されたイメージの配信元に関する情報を顧客に提供します。 この情報は、画像の添付されたマニフェストによって表されます。 マニフェストは、Azure OpenAI にトレースバックする証明書によって暗号によって署名されます。
マニフェストには、次のような重要な情報が含まれます。
フィールド名
フィールド コンテンツ
"description"
このフィールドには、生成されたすべての画像に対して "AI Generated Image" の値があり、画像の AI によって生成された性質を証明します。
"softwareAgent"
このフィールドの値は、Azure OpenAI 内の DALL-E シリーズモデルまたは GPT-image-1 シリーズモデルによって生成されるすべてのイメージに対して、"Azure OpenAI DALL-E" または "Azure OpenAI ImageGen" です。
"when"
コンテンツ資格情報が作成された日時のタイムスタンプ。
Azure OpenAI のコンテンツ資格情報は、ビジュアル コンテンツが AI によって生成されるタイミングを理解するのに役立ちます。 Azure OpenAI イメージ生成モデルを使用して責任を持ってソリューションを構築する方法の詳細については、Azure OpenAI 透過性に関するメモを参照してください。
ソリューションでコンテンツ資格情報を使用する
お客様は、次の方法でコンテンツ資格情報を使用できます。
AI によって生成されたイメージにコンテンツ資格情報が含まれていることを確認します。
追加のセットアップは必要ありません。 コンテンツ資格情報は、Azure OpenAI の DALL·E および GPT-image-1 シリーズ モデルから生成されたすべてのイメージに自動的に適用されます。
イメージにコンテンツ資格情報があることを確認します。
現在、Azure OpenAI モデルによって生成されたイメージの資格情報を確認するには、次の 2 つの方法をお勧めします。
コンテンツ資格情報の検証 Web ページ (contentcredentials.org/verify): これは、ユーザーがコンテンツのコンテンツ資格情報を検査できるようにするツールです。 Azure OpenAI イメージ生成モデルによってイメージが生成された場合、発行日時と共に、Microsoft Corporation によって発行されたコンテンツ資格情報がツールに表示されます。
このページでは、Azure OpenAI DALL-E によって生成されたイメージに、Microsoftによって発行されたコンテンツ資格情報があることを示します。
Content Authenticity Initiative (CAI) オープンソース ツール: CAI には、C2PA コンテンツ資格情報を検証して表示する複数のオープンソース ツールが用意されています。 あなたのアプリケーションに適したツールを見つけて、こちらから始めましょう。
