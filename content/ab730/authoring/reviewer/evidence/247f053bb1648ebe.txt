Microsoft Copilot ノートブックのしくみ
Copilot ノートブックは、コンテンツとソースをまとめることができる AI 搭載のワークスペースであり、Copilot が全体像を理解し、より関連性の高いコンテキスト認識された応答を提供できるようにします。 
               Microsoft Copilot ノートブックの使用を開始する 方法の詳細について説明します。
注
Copilot ノートブックは、Microsoft Copilot および Copilot Chat のライセンスを持つユーザーが利用できます。 ノートブックを作成するには、アカウントに SharePoint または OneDrive ライセンス (サービス プラン) が必要です。 Copilot ノートブックは、Microsoft 365 Personal、Family、Premium、Pro のサブスクライバーも利用できます。 
               Microsoft Copilot ライセンス と  Microsoft Copilot プラン の詳細をご確認ください。
Copilot ノートブックのしくみ
Copilot ノートブックは、スコープが設定されたインテリジェントなワークスペースとして動作します。 ノートブックを作成すると、Word ドキュメント、PowerPoint デッキ、Excel シート、Copilot ページなどの参照を追加できます。 Copilot は、このキュレーションされたコンテンツのみを使用して、次のことを支援します:
ノートブックのコンテンツに合わせた焦点を絞った回答を受け取ります。
プロジェクトの進行に合わせてリアルタイムで更新される参照を追加し続けられます。
プロンプトの指示を設定して、Copilot の応答をカスタマイズします。
オーディオの概要を聞いて、外出先でも素材を効率的に把握できます。
Copilot アプリを離れることなく、小さなタスクから大規模なプロジェクトまで実行できます。
Copilot ノートブックのワークフローの概要:
新しいノートブックを作成します。
Microsoft 365 ファイル、Copilot ページ、その他の種類の参照を追加します。
ノートブック内のコンテンツについて Copilot に質問します。
ノートブックに追加した参照のみに基づいて、Copilot から焦点を絞った回答を得られます。
また、 指示 (トーンやフォーマットなど) を設定して Copilot の動作をカスタマイズ し、 外出先で素材を把握するためにオーディオの概要を利用 できます。

Copilot ノートブックの現在の制限は何ですか?
画像生成やデータの視覚化は不可 : ノートブック内でチャート、グラフ、画像を直接作成できません。
ファイルの利用制限 : Copilot はノートブック内の最大 300 ファイルを使用して回答を生成します。 SharePoint のフォルダーやサイトなどの共有場所を追加すると、Copilot はその場所でアクセスできるファイルを考慮し、プロンプトに最も関連性の高い最大 300 個のファイルを選択して使用します。 特定のファイルを確実に含めるには、ノートブックに直接追加します。
ノートブックの削除 : Copilot ページまたはノートブックの削除は現在、永久的で元に戻せません。 ノートブックの復元機能は開発中のごみ箱とともに提供予定で、Copilot ページのごみ箱はより早く利用可能になり、削除したページの復元が可能になります。
Copilot ノートブックは何にアクセスできますか?
Copilot は OneDrive、メール、Teams チャット、Web 全体にはアクセスせず、ノートブックに追加した参照のみを使って応答を生成します。 これにより、すべての出力が定義した特定のコンテキストに基づき、それ以上でもそれ以下でもありません。 Copilot が参照し使用する内容は完全に制御できます。

どの言語がサポートされていますか?
Copilot ノートブックは、Microsoft Copilot と同じ言語で利用できます。 
               Microsoft Copilot でサポートされている言語 の詳細について説明します。
オーディオの概要 機能は、入力および出力の両方で、現在、英語、スペイン語、日本語、フランス語、ドイツ語、ポルトガル語、イタリア語、中国語に限定されています。
