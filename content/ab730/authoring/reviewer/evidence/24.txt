Microsoft Copilot でエージェント ストアを設定する
フィードバック
エージェント ストアは、エージェントを簡単に検出してインストールできる Microsoft Copilot の中心的なハブです。 Agent Store は、Microsoft、信頼できるパートナー、および自分の organization のエージェントをまとめることで、チームを厳選されたエージェントのエコシステムに接続します。
エージェント ストア環境にエージェントを含めるには、次の 4 つの方法があります。
事前構築済みエージェントをエージェント ストアにデプロイする
Copilot Studio を使用してエージェントを作成し、エージェント ストアに公開する
外部プラットフォームからエージェント ストアにエージェントを移動する
エージェントと Agent 365 SDK の統合
前提条件
開始する前に、次のものがあるかを確認します。
organization に割り当てられている Microsoft Copilot ライセンス
グローバル管理または Teams の管理アクセス許可を持つ Microsoft 365 管理センターへのアクセス
Copilot Studio へのアクセス (Copilot Studio を使用してエージェントを作成し、エージェント ストアに発行する予定がある場合)
Azure サブスクリプションと開発者アクセス (organization によって構築されたエージェントをエージェント ストアに公開する予定がある場合)

事前構築済みエージェントのデプロイ
事前構築済みエージェントは、Microsoft および信頼できるパートナーから入手できます。 このメソッドを使用して、既に構築および検証されている Microsoft 365 管理センターのエージェントを参照して有効にします。 開発作業は必要ありません。
手順 1: エージェント カタログを参照する (管理)
Microsoft 365 管理センターに戻ります。
エージェント>すべてのエージェントを選択して、エージェントカタログを開きます。
Microsoft、検証済みのサードパーティ プロバイダー、およびお客様の organization から利用可能なエージェントを確認します。
手順 2: エージェントの詳細を確認し、アクセスを構成する (管理)
エージェント テーブルで、エージェントを選択して詳細ウィンドウを開きます。
可用性と機能に基づいてエージェントの情報を確認します。
[ 概要 ] を選択すると、 発行元、 チャネル、 最終更新日などの詳細が表示されます。
ユーザーへの割り当てと展開、またはユーザーのインストールを許可する ユーザー を選択します。
[機能]、[ナレッジ]、[アクション] を表示するには、[データ & ツール] を選択します。
セキュリティ & コンプライアンス を選択して、エージェントのリスクと保護を表示します。
[ 認定] を選択して、エージェントが利用できる認定または発行元の構成証明情報を表示します。
以前にエージェントをデプロイし、使用状況データを確認する場合は、 [ アクティビティ ] を選択します。
手順 3: エージェントの割り当てと可用性を構成する (管理)
エージェントを選択したら、[ ユーザー>デプロイ先] を選択します。 [自分のみ]、[organization全体]、または[特定のユーザー/グループ] を選択して、エージェントが割り当てられているユーザーを選択します。
エージェントへのアクセスを制限するには、エージェントの詳細ページから [ブロック ] または [削除 ] を選択します。
手順 4: エージェント ストアでエージェントを使用できるようにする (管理)
Microsoft 365 管理センターからエージェントを利用できるようにすると、Microsoft Copilot 内のエージェント ストアで利用できるようになります。
ユーザーは、Teams、Outlook、Word、Excel、PowerPoint などの Microsoft 365 アプリ全体でアクセスできるエージェント ストアからエージェントを見つけてインストールできます。
Copilot Studio エージェントを作成して発行する organization によって構築された
このメソッドは、Microsoft Copilot のネイティブ エージェント開発プラットフォームである Copilot Studio を使用してカスタム エージェントを作成するために使用します。 organization の作成者は、Microsoft 365 管理センターでレビューするためにエージェントを構築して送信します。 管理者は、Microsoft Copilot のユーザーが利用できるようにする前に、Microsoft 365 管理センター でこれらのエージェントを確認して承認します。
注:
Microsoft Azure AI Foundry、カスタム コード、またはサード パーティの AI プラットフォームを使用してエージェントを構築するだけでなく、Microsoft Copilot 内のエージェント ビルダーを使用してエージェントを構築して共有することもできます。
手順 1: Copilot Studio (Maker) でエージェントを構築する
Copilot Studio で、左側のメニューから [エージェント] を選択します。 [Copilot Studio で空のエージェントを作成する] を選択し、プロンプトに従って自然言語の指示、記事、アクションを使用してエージェントを定義します。
手順、ナレッジ、検索、ツール、記事、および必要な統合を追加して構成します。
発行する前に、組み込みのテスト パネルでエージェントをテストします。 発行すると、Microsoft 365 管理センター内の管理者がエージェントを利用できるようになります。
手順 2: 管理者の承認のためにエージェントを送信する (Maker)
Copilot Studio で、エージェントの [チャネル] タブを選択します。
発行チャネルとして [Microsoft Copilot] と [Microsoft Teams] を選択します。 関連ウィンドウには、チャネル固有の設定が表示されます。
[Microsoft Copilot でエージェントを利用可能にする] が選択されていることを確認します。
[ 詳細の編集 ] を選択して、エージェントの表示方法を構成します。 完了したら、[ 保存] を選択してチャネル固有の設定に戻ります。
[ 保存 ] を選択して、エージェントを管理者レビューのために送信します。 エージェントがレビューされ、Microsoft 365 管理センターで公開されると、エージェント ストアでエージェントを表示できるようになります。
注:
エージェントは、管理が要求を承認するまでユーザーには表示されません。 承認後、エージェントは [エージェント ストア] の [エージェント>すべてのエージェント>組織によって構築された] の下に表示されます。
手順 3: エージェント要求を確認して承認する (管理)
Microsoft 365 管理センターで、[エージェント>すべてのエージェント]>要求 を選択します。
保留中の要求エージェントを選択して、機能、データ アクセス、メーカー情報などのエージェントの詳細を確認します。
[ 発行] を選択して、エージェント ストアの [組織によって構築] コレクションでエージェントを使用できるようにするか、[ 拒否 ] を選択して要求を拒否します。
要求が拒否された場合、Copilot Studio は作成者に通知し、変更を加えて再送信できるようにします。
外部プラットフォームからエージェントを導入する
この方法を使用して、Copilot Studio の外部に構築されたエージェント (Microsoft Azure AI Foundry、カスタム コード、またはサード パーティの AI プラットフォーム上のエージェントを含む) を Microsoft Copilot およびエージェント ストアに取り込む場合に使用します。
手順 1: Microsoft 365 Agent Toolkit を使用してエージェントをパッケージ化する (開発者)
Microsoft 365 エージェント ツールキットと Microsoft 365 エージェント SDK をインストールします。
Azure で Bot Service リソースを作成して構成します。
Microsoft Copilot との対話を処理するようにエージェント イベント リスナーを構成します。
ツールキットの要件に従ってエージェント マニフェスト パッケージを準備します。
ヒント
完全なセットアップ手順については、「エージェントを Microsoft Copilot に取り込む」を参照してください。
手順 2: パッケージ化されたエージェントを組織カタログに送信する (開発者)
Microsoft 365 エージェント ツールキットを使用してエージェントがパッケージ化されたら、ツールキットから直接 organization のエージェント カタログに送信します。
エージェントが Microsoft 365 管理センターで保留中の要求として表示されることを確認します。
手順 3: エージェント要求を確認して承認する (管理)
Microsoft 365 管理センターで、[エージェント>すべてのエージェント]>要求 を選択します。
保留中の要求があるエージェントを選択して、エージェントの詳細を確認します。
エージェントをエージェント ストアに公開するには [ 承認 ] を選択し、要求を拒否するには [ 拒否 ] を選択します。
承認後、Microsoft Copilot 内のエージェント ストアでユーザーがエージェントを使用できるようになります。
エージェントを Agent 365 SDK と統合する
Copilot Studio、Azure AI Foundry、OpenAI Agents SDK、カスタム コードなど、他の SDK またはプラットフォームにエージェントを既に構築している組織の場合、Microsoft Agent 365 SDK は完全なリビルドなしでエンタープライズ機能を追加できます。
Agent 365 SDK は、Entra に裏付けられた ID、管理された MCP サーバーを介した Microsoft 365 データへの管理されたアクセス、完全なオブザーバビリティ、および人間の参加者と同じように Teams、Outlook、Word 全体で通知を受信して応答する機能をエージェントに装備します。 エージェントは、IT 承認のブループリント システム内で動作するため、各エージェント インスタンスは、organization によって定義されたコンプライアンス、ガバナンス、およびセキュリティ ポリシーを継承します。
完了すると、これらの Agent 365 対応エージェントが、エージェント ストアの「チームのエージェント」コレクションに表示されます。 この経路は、カタログ内の他のエージェントと同じエンタープライズ標準を満たしていることを確認しながら、エージェントを Copilot とエージェント ストアに導入したい組織に最適です。
