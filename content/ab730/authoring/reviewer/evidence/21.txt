Microsoft 365 Copilot 用の宣言型エージェント
フィードバック
宣言型エージェントは、Microsoft 365 Copilot を利用した目標指向型の会話エクスペリエンスを提供します。 ビジネス シナリオに対処するために、エージェントの目的、指示、知識、およびサポートされているアクションを定義します。 プラグインには、スキル、Copilot コネクタ、MCP ベースのツールなど、サポートされている他の機能を持つエージェントを追加または参照できます。
ユーザーが特定の結果に合わせた動作と機能を備えた専用の会話エクスペリエンスを必要としている場合は、宣言型エージェントを選択します。 既存の Microsoft エクスペリエンスまたは承認済みエージェントが選択したスキル、コネクタ、またはツールを使用できる場合は、エージェントを作成する必要はありません。
注:
Microsoft 365 Copilot のエージェントを構築する 2 つのアプローチについては、「Microsoft 365 Copilot のエージェント」を参照してください。
宣言型エージェントが必要かどうかを決定する
ソリューションで次の要件が必要な場合は、宣言型エージェントを検討してください。
定義された対象ユーザーと結果の名前付き会話エクスペリエンス。
会話全体で一貫して適用される指示と制約。
グラウンディング用のキュレーションされたナレッジ ソース。
シナリオ用に選択されたアクション、スキル、コネクタ、または MCP ベースの機能。
ユーザーがエージェントの動作を理解するのに役立つ会話のきっかけとメタデータ。
たとえば、従業員サポート エージェントは、承認された組織の知識を使用して、一般的な質問に回答できます。 カスタマー サポート エージェントは、指示と知識を、現在の注文情報を取得する外部機能と組み合わせることができます。
次の場合、エージェントが適切なコンポーネントではない可能性があります。
ユーザーは、必要な機能を直接使用できるサポートされたエクスペリエンスで既に作業しています。
既存の承認済みエージェントは結果を満たしており、構成または拡張できます。
このソリューションでは、オーケストレーション、モデル、ホスティング、またはユーザー インターフェイスを完全に制御する必要があります。 その場合は、 宣言型エンジン エージェントとカスタム エンジン エージェントを比較します。
適合と制限の詳細なガイダンスについては、 宣言型エージェントのアーキテクチャを参照してください。
エージェントの貢献内容を理解する
宣言型エージェントは、以下を記述する構成によって定義されます。
ID と動作: エージェントの名前、目的、指示、会話のきっかけ、制約、視覚的表現。
知識: 応答の基礎となる承認された情報源。
機能: エージェントが使用できるアクション、スキル、コネクタ、またはツール。
ホストと配布のメタデータ: サポートされている Microsoft エクスペリエンスでエージェントを表示するために必要な情報。
ユーザーは、Microsoft 365 Copilot およびサポートされている Microsoft 365 アプリの宣言型エージェントと連携します。
構築するか再利用するかを決定する
エージェントをビルドする前に:
ターゲット ユーザーとエクスペリエンスに対して既に承認されているエージェントを確認します。
既存のエージェントを再利用、コピー、構成、または拡張できるかどうかを判断します。
エージェントの指示、知識、接続、およびサポートの所有者を確認します。
新しいエージェントを必要とするギャップを特定します。
エージェントを再利用する場合は、その所有者が対象のユーザー、データ、機能、共有範囲、およびライフサイクルをサポートしていることを確認します。
エージェントの依存関係を記録する
エージェントを構築するか再利用するかを決定するときに、次の点に注意してください。
ターゲット ユーザー、結果、および Microsoft エクスペリエンス。
指示、ナレッジ ソース、および会話要件。
必要なスキル、コネクタ、アクション、または MCP ベースの機能。
ID、アクセス許可、同意、およびデータ境界。
可用性、言語、ライセンス、および環境の要件。
所有者、サポート連絡先、およびサクセス測定。
エージェントを構築するか再利用するかを決定したら、 開発ツールを選択します。
全国クラウドのサポート
Microsoft 365 Government テナントの宣言型エージェントのサポートは、クラウドによって異なります。
Government Community Cloud (GCC): 完全な宣言型エージェント サポートを利用できます。
Government Community Cloud High (GCCH): Microsoft 365 Agents Toolkit で構築されたプロコード エージェントがサポートされています。 エージェント ビルダーは GCCH でも使用できるようになりました。
米国国防総省 (DoD): 制限付きサポート - Microsoft 365 Agents Toolkit で構築されたプロコード エージェントのみがサポートされます。 エージェント ビルダーは、DoD の宣言型エージェントでは使用できません。
