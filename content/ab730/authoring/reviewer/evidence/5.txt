Microsoft 365 Copilot ChatとMicrosoft 365 Copilotはどのように違いますか?
Microsoft 365 Copilot Chatは、Web に基づいている大規模な言語モデル (LLM) を利用する AI プロンプトと応答エクスペリエンスです。 Copilot Chatは自動的に含まれ、Microsoft 365 サブスクリプションを持つ組織で使用できます。
対照的に、Microsoft 365 Copilotは作業organizationによってライセンスされます。 これには、エンド ユーザーと管理者が、Web ベース (インターネット) データと仕事ベース (Microsoft Graph) データの両方を推論するなどの作業タスクでさらに多くのことを行うのに役立つ機能が含まれています。
Microsoft 365 Copilot ChatとMicrosoft 365 Copilotの違いについて詳しくは、こちらをご覧ください。
Microsoft 365 Copilot ChatとMicrosoft 365 CopilotとMicrosoft Copilotはどのように異なりますか?
Microsoft 365 Copilot Chat (Web に固定) とMicrosoft 365 Copilot (Web と仕事のデータに固定) は、仕事と教育を目的としています。 ユーザーは、Entra アカウントでサインインした後、Microsoft 365 Copilot アプリまたは Web からアクセスします。
Microsoft Copilotは個人的な使用を目的とします。 ユーザーは、個人用アカウント (MSA) を使用してアクセスします。 organizationのユーザーが職場または教育用のCopilot Chatに確実にアクセスできるようにする方法について詳しくは、こちらをご覧ください。
Microsoft Graph データCopilot Chatアクセスできますか?
ユーザーがMicrosoft 365 Copilot ライセンスを持っていない場合、Copilot Chatは、Microsoft Graph コネクタを介してインデックスが作成されたユーザーの共有エンタープライズ データ、個々のデータ、または外部データにアクセスできません。 ただし、ユーザーはCopilot Chatで直接ファイルをアップロードできます。 さらに、organizationでCopilot Studioによる測定が可能な場合、ユーザーは、特定の SharePoint サイト、共有テナント ファイル、またはサード パーティのデータに焦点を当てた基盤を提供するCopilot Chatのエージェントにアクセスできます。
Copilot Studioでは、SharePoint ファイルなどの共有 Microsoft 365 データなど、特定のソースからの知識を基にしたエージェントを簡単に作成できます。
Copilot Chat ユーザーのエージェント
エージェントは既定でオンになっていますか?
SharePoint または Graph コネクタのコンテンツにアクセスするエージェントは、 従量制課金に基づいて課金されます。 従量制課金を利用するエージェントは、既定ではオフになっています。 管理者は、これらのエージェントを使用する前に、Copilot Studio サブスクリプションを設定する必要があります。 これらのエージェントは、Copilot と Power Platform の構成を通じて管理されます。
命令とパブリック Web サイトに根付いた宣言型エージェントは、追加料金なしで利用できます。 これらのエージェントはテナント データにアクセスできません。 これらのエージェントの可用性は、エージェントの管理時に以前の構成に従います。
Copilot Chatユーザーは、Teams および Microsoft 365 アプリの既存のストア設定に基づいて、ストア内のエージェントにアクセスできます。 これらの設定に基づいて、追加コストなしで利用できるエージェントは、既定でオンにして使用できます。

エンタープライズ データ保護 (EDP)
エンタープライズ データ保護 (EDP) とは
Microsoft Entra アカウントでサインインしたユーザーの場合、Microsoft 365 Copilot Chatはエンタープライズ データ保護 (EDP) を提供します。
エンタープライズ データ保護 (EDP) とは、データ保護補遺 (DPA) と製品条件の下で、Microsoft 365 CopilotおよびMicrosoft 365 Copilot Chatのユーザーの顧客データに適用される制御とコミットメントを指します。 EDP​​ という用語の使用は、DPA および製品条件に基づいて提供される利点を制限することを意図したものではありません。
エンタープライズ データ保護の詳細については、「https://aka.ms/EDPLearn」を参照してください。

Copilot Chatでエンタープライズ データ保護 (EDP) にアクセスするために、IT 管理者はどのようなアクションを実行する必要がありますか?
Microsoft 365 Copilot Chatは、Microsoft Entra アカウントでサインインするユーザーにエンタープライズ データ保護 (EDP) を提供します。IT 管理者の操作は必要ありません。
organization全体のユーザーがCopilot Chatに簡単にアクセスできるようにし、セキュリティとエクスペリエンスの更新プログラムを利用できるようにするには、ユーザーがナビゲーション バーにピン留めMicrosoft 365 Copilot Chatすることをお勧めします。
Microsoft 365 Copilot アプリを Windows タスク バーにピン留めすることもできます。 Microsoft 365 Copilot Chatがピン留めされている場合は、Microsoft 365 Copilot アプリ、Microsoft Teams、Outlook に表示されます。 Copilot Chatのピン留め設定を変更するオプションは、Microsoft 365 管理センターの [Copilot コントロール システム] ページの [設定] にあります。 (グローバル 管理または AI 管理アクセス許可が必要)。
Microsoft 365 Copilot Chatは、Microsoft 365 Copilot アプリ、Teams、Outlook のナビゲーション バーに既定で固定されています。Web、モバイル、デスクトップ全体でCopilot Chatの対象となるほとんどのユーザーに対してです。

プライバシー、保護、コンプライアンス
Copilot Chatのプロンプトと応答はログに記録されますか?
エンタープライズ データ保護 (EDP) では、プロンプトと応答がログに記録され、保持され、監査、電子情報開示、Microsoft Purview の高度な機能で使用できます。 特定のコントロールは、基になるサブスクリプション プランによって異なります。 EDP の詳細については、 プロンプトと応答のエンタープライズ データ保護に関するページを参照してください。
Copilot Chatでのプロンプトと応答は、基盤モデルのトレーニングに使用されますか?
いいえ。プロンプトと応答は、エンタープライズ データ保護の下で 基盤モデルをトレーニングするために使用されません 。
Microsoft 365 Copilot Chatは OpenAI の ChatGPT モデル上に構築されているため、Copilot Chatは OpenAI と情報を共有しますか?
いいえ。データは OpenAI では使用できません。また、OpenAI モデルのトレーニングに使用することもできます。
Microsoft がユーザーと組織のデータを保護する方法について詳しくは、こちらをご覧ください。

Copilot Chatによって生成された素材を使用して、著作権侵害の危険にさらされる可能性はありますか?
Microsoft のCopilot 著作権コミットメントは、お客様が Microsoft の Copilot サービスによって生成された出力コンテンツの使用と配布に起因する第三者の知的財産請求から顧客を保護します。 コンテンツの著作権に関する懸念事項については、 お客様の著作権コミットメントに関するページを参照してください。
Copilot Chatは EU データ境界 (EUDB) コンプライアンスを提供していますか?
はい、できます。 詳細については、 EUDB コミットメントの詳細を参照してください。
Copilot Chatは HIPAA コンプライアンスをサポートしていますか?
Microsoft 365 Copilot Chatは、適切に構成された実装のプロンプトと応答に対する BAA と HIPAA のコンプライアンスをサポートします。 HIPAA コンプライアンスは、DPA と BAA の対象外であるため、Web 検索クエリには適用されません。
Copilot Chatは、教育のための FERPA コンプライアンスをサポートしていますか?
Microsoft 365 Copilot Chatでは、適切に構成された実装に対するプロンプトと応答に対する FERPA コンプライアンスがサポートされます。 FERPA コンプライアンスは、DPA の対象外であるため、Web 検索クエリには適用されません。
懸念事項を報告する
有害なコンテンツや行為からユーザーを保護するために勤勉に取り組みますが、単独では行えません。
ここで懸念事項を報告できます。 お客様のレポートは、オンライン コンテンツまたはユーザーの行動が Microsoft サービスのポリシーまたは条件に違反している場所を特定するのに役立ちます。
お客様が Microsoft にコンテンツを報告したり、Microsoft に対する行為を行ったりする場合、Microsoft はコンテンツをレビューし、ポリシーまたは条件に違反した場合はそれに対して行動します。
テクニカル サポートに関する懸念がある場合は、Microsoft サポートにアクセスしてください。 プライバシーに関する懸念がある場合は、 プライバシーに関する懸念を報告できます。
また、Copilot Chat応答の下部にある [サムアップ] ボタンまたは [サムダウン] ボタンをクリックすることもできます。 これらのボタンをクリックすると、一般的に満足していたか、Copilot Chatの応答に不満があったかが示されます。 クリックすると、エクスペリエンスの詳細を共有できるウィンドウが開きます。
機能
Copilot Chatで利用できる機能は何ですか?
Microsoft 365 Copilot Chatでは、定期的に新機能が導入されます。 次の機能は、示されている場合を除き、Web、モバイル、デスクトップ全体のCopilot Chatで使用できます。
Copilot ページ: Copilot Chat生成されたコンテンツを受け取り、動的で永続的なキャンバスに配置します。このキャンバスでは、ユーザーが編集、追加、共有、リアルタイムで他のユーザーと作業できます。
Copilot ページ の詳細については、こちらをご覧ください。 SharePoint ライセンスが必要です。
ファイルのアップロード: ユーザーがドキュメント、Excel ファイル、PDF などのファイルWordアップロードして、応答の一部としてCopilot Chatの推論を求められます。
Standardアクセスとファイルのアップロードの制限が適用されます。
画像の生成: AI によって生成されたイメージを記述して作成します。
Standardアクセスとイメージ生成の制限が適用されます。
以前のチャット: ユーザーが以前のチャットにアクセスして参照したり、チャットを続行したりできます。
エージェント: エージェントは AI を使用して、ビジネス プロセスを自動化および実行し、人、チーム、またはorganizationと一緒に、または代理で作業します。 エージェントの範囲は、単純なプロンプトおよび応答エージェントから、より高度で完全に自律的なエージェントまでです。 さらに、Word、PowerPoint、Excel エージェントを使用すると、ユーザーはアイデアを洗練されたドキュメント、スプレッドシート、プレゼンテーションにCopilot Chatで直接変換できます。
コンテキスト プロンプトの提案 (Edge でCopilot Chat): Microsoft Edge 内で開いているページを参照して、ユーザーがより関連性の高いプロンプトを作成できるようにします。
ページの要約 (Edge でCopilot Chat): ユーザーが Edge で開いている Web ページまたは PDF を要約できます。
コード インタープリター: Copilot Chatでは、Python プログラミング言語を使用して、ユーザーがコーディング、視覚化、数学などの複雑なデータ分析を実行するのに役立ちます。
画像のアップロード: ユーザーが写真を撮影したり、画像をアップロードしたり、画像をコピーしてCopilot Chatに貼り付けてプロンプトで使用したりできます。
ディクテーション: ユーザーがマイクを使用してプロンプトを入力できるようにします。
音声読み上げ: ユーザーがプロンプトに対するCopilot Chatの応答を聞くことができます。
リアルタイム音声: ユーザーが自分の音声をリアルタイムで使用して Copilot と会話できるようにします。 リアルタイム音声は、ライセンスMicrosoft 365 Copilotユーザーにのみ使用できます。

Word、Excel、PowerPointでのChatエクスペリエンスは、テナントの構成とライセンスによって異なります。 詳細については、「Microsoft 365 Copilotの概要」を参照してください。

書き換え (Edge でCopilot Chat、TBD をリリースする): ユーザーが Microsoft Edge で開いているページ内で、トーン、書式、長さの入力されたテキストを編集できます。 書き換えの前のポリシー設定は、この機能が再び使用できるようになるまで削除されます。

Copilot Chatはアップロードされたファイルをどのように処理しますか?
Microsoft 365 Copilot Chatは、チャット ボックスにアップロードしたファイルの内容を分析できます。 つまり、Copilot Chatは、プレゼンテーション、PDF、Excel スプレッドシートなどをPowerPoint操作するときに新しい分析情報を提供できます。 ファイルをアップロードするには、チャット ボックスで [(+) コンテンツの追加] ボタンを選択するか、ファイルをチャット ボックスにドラッグ アンド ドロップします。 アップロードしたファイルについてCopilot Chat質問したり、PDF やドキュメントなどのファイルを要約したり、データ分析や視覚化を実行したりWordできます。
Standardアクセスとファイルのアップロードの制限が適用されます。
アップロードされたファイルは、ユーザーのOneDrive for Businessに格納されます。 ユーザーはいつでもアップロードしたファイルを削除できます。
エンタープライズ データ保護の保証ごとに、アップロードされたファイルはモデルのトレーニングに使用されません。
