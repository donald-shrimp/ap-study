イメージ ジェネレーター機能をエージェントに追加する
フィードバック
画像ジェネレーター機能を使用すると、Microsoft 365 Copilot の宣言型エージェントがユーザー プロンプトに基づいて画像を生成できます。 画像ジェネレーターは、既存の Designer 機能を使用して、視覚的に魅力的でコンテキストに関連するグラフィックを作成し、次の機能を備えています。
複数の画像生成: ユーザープロンプトごとに、エージェントは 4 つの画像を生成します。
インタラクティブな画像オプション: ユーザーは生成された各画像を選択して、フルサイズで表示できます。 フルサイズ イメージのコンテンツ資格情報をダウンロード、コピー、または表示できます。 サイド矢印を選択して、4 つの画像をスクロールすることもできます。
画像の変更: ユーザーは後続のプロンプトに従って、コンテキストを失うことなく元の画像を変更できます。 たとえば、最初のプロンプトは "庭を走り回っている幸せな子犬の写真を作成してください" です。2 番目のプロンプト: "テニス ボールを含める。"
フィードバック メカニズム: ユーザーは、生成された画像について、親指を上または下にすることでフィードバックを提供できます。 このフィードバックは、将来のイメージ生成の品質を向上させるのに役立ちます。
クリップボードと共有: ユーザーは、生成された画像をクリップボードにコピーして他のアプリケーションに貼り付けたり、生成された画像をインターフェイスから直接共有したりできます。
画像生成機能は、従量制課金制の使用量または Microsoft 365 Copilot ライセンスをお持ちでない Copilot Chat ユーザーが利用できます。
イメージ ジェネレーター機能を使用できるかどうかは、ユーザーのライセンスとテナント構成によって異なります。 詳しくは、「 エージェント機能とライセンスモデル」を参照してください。

画像ジェネレーターを有効にする
エージェント ツールキット
Microsoft 365 Agents Toolkit を使用してエージェントを作成している場合は、エージェントで画像ジェネレーターを有効にするには、次の例に示すように、マニフェスト ファイルの capabilities プロパティにGraphicArt値を追加します。
注:
GraphicArt 機能を追加するには、宣言型エージェント マニフェスト スキーマのバージョン 1.2 以降を使用する必要があります。
{
"capabilities": [
{
"name": "GraphicArt"
}
]
}
エージェント ビルダー
画像ジェネレーターは、Agent Builderで常に有効になっています。 この機能は、すべてのエージェントに自動的に含まれています。
注:
画像生成機能は現在、Agent Builder の [試してみる ] テスト ウィンドウでは機能しません。 エージェントを公開した後、イメージ生成をテストします。
