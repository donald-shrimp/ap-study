Copilot の個人用設定とメモリを管理する
フィードバック
重要
Copilot の個人用設定とメモリはプレビュー段階であり、変更される可能性があります。 Frontier プログラムの詳細については、「 Frontier とは」を参照してください。Copilot メモリは、Microsoft Copilot ライセンスの有無にかかわらず、Copilot Chat ユーザーが利用できます。 詳細については、「どの Copilot が私または私の organization に適していますか?」を参照してください。
保存されたメモリ、チャット履歴から推測された詳細、カスタム指示などのメモリは、ユーザーの Exchange メールボックスの隠しフォルダーに保存されます。 したがって、メモリは、 カスタマー ロックボックス や 保存時の暗号化など、他のメールボックス データと同じセキュリティおよびコンプライアンス ポリシーに従います。
Copilot の個人用設定とメモリにおける Copilot のデータ、プライバシー、セキュリティの詳細については、「Microsoft Copilot のデータ、プライバシー、セキュリティ」を参照してください。
高度な個人用設定コントロールを管理する
注:
Copilot メモリをオンにするためにアクションは必要ありません。必要に応じて、エンド ユーザーまたはテナントの Copilot メモリをオフにするだけで済みます。
拡張個人用設定は、エンド ユーザーが Copilot メモリを使用できるようにするコントロールです。 既定では、[拡張個人用設定] が オンになっています。 詳細については、「Microsoft Copilot の強化された個人用設定制御」を参照してください。 Microsoft Graph を使用してプログラムでコントロールを構成するために、テナント管理者は Microsoft Graph を使用してスクリプトを記述できます。 詳細については、「 Microsoft Graph の enhancedPersonalizationSetting リソースの種類」を参照してください。
拡張個人用設定コントロールがオフになっているエンドユーザーには、[設定] > [個人用設定] でカスタム命令、保存されたメモリ、Chat履歴のユーザー レベルのコントロールがオフとして表示されます。 これらの設定をオンにすることはできません。 エンドユーザー コントロールの詳細については、「Microsoft Copilot が記憶するもののカスタマイズの概要」を参照してください。
Copilot のメモリ保持期間の管理
メモリのアイテム保持ポリシー
organization 管理者によって Purview で構成された保持ポリシーと保持ラベルは、Copilot メモリには適用されません。 たとえば、管理者が Copilot Chat のやり取りに対して "3 か月後に削除" ポリシーを設定した場合、ユーザーのメモリは 3 か月後に削除されません。 Copilot メモリ専用の保持ルールを適用するための管理者コントロールはありません。
カスタム指示
拡張個人用設定コントロールが管理者レベルでオフになっている場合、またはカスタム命令コントロールがエンドユーザー レベルでオフになっている場合、Copilot はカスタム命令の適用を停止しますが、それらのカスタム命令は削除しません。 詳細については、「Microsoft Copilot が記憶するもののカスタマイズの概要」と「Microsoft Copilot の応答方法をカスタマイズする」を参照してください。
保存されたメモリー
保存されたメモリは、エンドユーザーが [設定] > [個人用設定] で保存されたメモリを明示的に削除するまで保持されます。 チャットを削除しても、そのチャットから生成された保存されたメモリは削除されません。 拡張個人用設定コントロールが管理者レベルでオフになっている場合、または [保存されたメモリ] コントロールがエンドユーザー レベルでオフになっている場合、Copilot は保存されたメモリをチャットに適用することは停止されますが、保存されたメモリは削除されません。 保存したメモリを削除する方法の詳細については、「Microsoft Copilot で Copilot メモリを管理する」 および 「Microsoft Copilot に記憶される内容のカスタマイズの概要」を参照してください。
Chat 履歴
チャット履歴の詳細は動的です。 Copilot は、保持する方が最も役立つ内容を学習したため、古い詳細を更新または破棄する場合があります。 ユーザーが、特定の情報が最初に共有または参照されていたすべてのチャットを削除すると、その情報のすべてのトレースが 7 日以内に Chat 履歴の詳細から削除されます。
[拡張個人用設定] コントロールが管理者レベルでオフになっている場合、または [Chat 履歴] コントロールがエンドユーザー レベルでオフになっている場合、チャット履歴のすべての詳細が 30 日後に削除されます。 詳細については、「記憶する内容のカスタマイズの概要」および「Microsoft Copilot Chat Microsoft Copilot履歴を再確認する」を参照してください。
テナント管理者は、Copilot メモリに関連するデータ主体の要求にどのように対応できますか?
管理者は、電子情報開示と Microsoft Graph エクスプローラーを使用して、ユーザーのメモリ データを検索、エクスポート、削除できます。 詳細については、「 電子情報開示での AI アプリケーション データの検索と削除 」と「 <IPM.Contact>の検索」を参照してください。
注:
ユーザーの連絡先にはアイテム クラス <IPM.Contact>もあります。 ユーザーのこのアイテム クラス <IPM.Contact> のすべてのアイテムをエクスポートすると、そのユーザーの Copilot メモリは <'CopilotMemory'> フォルダーに配置されます。
Copilot メモリの場合は、項目クラスを検索する必要があります <IPM.Contact>。
保存されたメモリとチャット履歴から推測されたメモリは、電子情報開示と Microsoft Graph エクスプローラーを使用して検出できます。
カスタム指示にアクセスできませんが、[ 設定] > [個人用設定] を使用してユーザーが手動でエクスポートできます。
管理者はユーザーのメモリを検出して削除できますか?
管理者は、Microsoft Purview eDiscovery またはコンテンツ検索を介して、Microsoft Copilot でユーザーのメモリを検索できます。 カスタム命令は、これらのソリューションではまだ検出できません。 管理者は、Purview と組み合わせて Microsoft Graph エクスプローラーを使用してメモリ データを削除することもできます。 詳細については、「 電子情報開示での AI アプリケーション データの検索と削除」を参照してください。
Copilot メモリの監査ログはありますか?
メモリと個人用設定のアクションでは、Purview に監査ログ エントリは生成されません。
テナント管理者は、メモリに追加される情報を制限できますか?
いいえ。管理者は、Copilot メモリに追加される情報の種類を制限できません。
管理者は一時チャットを検出できますか?
はい。管理者は、通常のチャットと同様に Purview の一時チャットにアクセスできます。
