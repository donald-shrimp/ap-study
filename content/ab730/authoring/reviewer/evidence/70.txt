OutlookでCopilotとチャットする方法は？
Microsoft 365 全体で Copilot Chat を使用する方法は？
Outlook で Copilot とチャットするためのチェックリストを作成します。
Microsoft Copilot Chat はアプリに深く統合されているため、Outlook をチャットと並べて使用しながら、コンテキストに応じて情報を取得してアクションを実行できます。 organization のデータ、Web からの情報、受信トレイや予定表に関する質問に関する会話がサポートされており、Outlook で直接アクションを実行することもできます。
チャットにアクセスするには、職場または学校アカウントで Outlook にサインインし、Outlook アプリの上部領域にある [Copilot] ボタンを選択します。
Outlook の Copilot Chat で実行できる操作は、管理者が職場または学校アカウントに Microsoft Copilot アドオン ライセンスを割り当てたかどうかによって異なります。
アドオン ライセンスなしの Outlook の Copilot Chat
職場または学校アカウントに Microsoft Copilot アドオン ライセンスをお持ちでない場合は、Outlook の Copilot Chat を使用して、受信トレイ、予定表、会議、その他の限られたデータについて質問し、Outlook で直接アクションを実行できます。 使用できるプロンプトの種類の例を次に示します。
"[プロジェクトまたは顧客名] に関連する先週のメールを要約してください。"
"/name との次の 1:1 会議はいつですか?"
"今週からのお客様のエスカレーションを要約した更新通知メールの下書きを作成してください。"
「上司との会議をスケジュールしてください。」
"上司からの未読メールをすべてフラグを設定してください。"
"来週の金曜日の自動応答を設定してください。"
アドオン ライセンスを使用した Outlook の Copilot Chat
職場または学校アカウントで Microsoft Copilot アドオン ライセンスをお持ちの場合は、アドオン ライセンスを持たないユーザーと同じプロンプトを使用できるだけでなく、Outlook で Copilot Chat を使用して、次のようなプロンプトを使用して受信トレイ、予定表、会議、チャット、エンタープライズ データを操作することもできます。
"どの未読メールが最も重要ですか? それらを要約し、チャットやドキュメントから関連するコンテキストを合成し、応答する順序に優先順位を付けます。」
"スキップレベル マネージャーとの次の会議のスケジュールを教えてください。現在のプロジェクトに基づいて議題の下書きを手伝ってください。事前読み物の最初の下書きを作成してください。"
"新入社員へのウェルカム メールを作成します。これには、最初の 4 週間で何をすべきかの詳細、各人の役割と現在のプロジェクトの詳細を含むチームの組織図、確認する必要がある関連ドキュメントが含まれます。"
"[プロジェクトまたは顧客名] について話し合うために、/name との会議をスケジュールします。"
