責任ある AI とは?
この記事の内容
適用対象: Azure CLI ml extension v2 (現行) Python SDK azure-ai-ml v2 (現行)
責任ある人工知能 (責任ある AI) は、AI システムを安全に、倫理的に、信頼して開発、評価、デプロイするためのアプローチです。 AI システムは、作成者が行った多くの決定に起因します。 責任ある AI は、システムの目的の定義からユーザーの操作まで、より有益で公平な結果を得るために、これらの決定を導くのに役立ちます。 人とその目標をデザインの中心に保ち、公平性、信頼性、透明性などの価値を尊重します。
Microsoft は、公平性、信頼性と安全性、プライバシーとセキュリティ、包括性、透明性、アカウンタビリティという 6 つの原則に基づいて AI システムを構築するためのフレームワークである  責任ある AI Standard を 作成しました。 これらの原則は、AI に対する責任ある信頼できるアプローチの基礎です。特に、インテリジェントなテクノロジが日常的な製品やサービスでより一般的になるにつれてです。
この記事では、開発者とデータ サイエンティストがこれらの 6 つの原則を実装して運用化するのに役立つツールが Azure Machine Learning によって提供される方法について説明します。
公平性と包括性
AI システムでは、すべてのユーザーを公平に扱い、同様のグループに異なる影響を与えないようにする必要があります。 たとえば、AI システムが医療、ローンの申請、雇用に関するガイダンスを提供する場合、同様の症状、財務状況、または資格を持つユーザーにも同じ推奨事項を作成する必要があります。
Azure Machine Learning の公平性と包括性 :  責任ある AI ダッシュボード の 公平性評価 コンポーネントは、性別、民族性、年齢、その他の特性など、機密性の高いグループ間でモデルの公平性を評価するのに役立ちます。
信頼性と安全性
信頼を構築するには、AI システムは確実かつ安全に、一貫して動作する必要があります。 設計どおりに機能し、予期しない状況に安全に対応し、有害な操作に抵抗する必要があります。 その動作とさまざまな条件を処理する能力は、設計とテスト中に開発者が予想する状況の範囲を反映しています。
Azure Machine Learning の信頼性と安全性 :  責任ある AI ダッシュボード の エラー分析 コンポーネントは、次の場合に役立ちます。
モデルに対するエラーの分散について詳しく理解する。
全体的なベンチマークよりもエラー率が高いデータのコーホート (サブセット) を特定する。
これらの不一致は、システムまたはモデルが特定の人口統計グループまたはトレーニング データでほとんど観察されない入力条件に対してパフォーマンスが低い場合に発生する可能性があります。
透明性
AI システムが、人々の生活に影響を与える意思決定を通知する場合、それらの意思決定がどのように行われるかを人々が理解することが重要です。 たとえば、銀行は AI システムを使用して、個人が信用できるかどうかを判断したり、企業が AI システムを使用して求職者を選択したりする場合があります。
透明性の重要な部分は  、解釈可能性 です。AI システムの動作に関する有用な説明を提供します。 解釈可能性の向上は、AI システムが機能する方法と理由を利害関係者が理解するのに役立ちます。これにより、パフォーマンスの問題、公平性の懸念、除外プラクティス、または意図しない結果を特定できます。
Azure Machine Learning の透明性 :  責任ある AI ダッシュボード の モデルの解釈可能性 と 反解的な what-if  コンポーネントは、モデル予測の人間が理解できる説明を生成するのに役立ちます。
モデルの解釈可能性コンポーネントは、モデルの動作にいくつかのビューを提供します。
"グローバルな説明"。  たとえば、ローン配賦モデルの全体的な動作に影響する特徴は何ですか?
"局所的な説明"。  たとえば、顧客のローン申請が承認または却下されたのはなぜですか?
選択したデータポイントのコホートに対するモデルの説明 . たとえば、低所得の申請者に対するローン配賦モデルの全体的な動作に影響する特徴は何ですか?
反実仮想の What-If コンポーネントは、特徴量の変化や摂動に対してモデルがどのように反応するかを示すことで、機械学習モデルを理解し、デバッグするのに役立ちます。
Azure Machine Learning では、 責任ある AI のスコアカード もサポートされています。 スコアカードはカスタマイズ可能な PDF レポートであり、開発者は技術的および非技術的な利害関係者と構成、生成、ダウンロード、共有できます。 データセットとモデルの正常性に関する利害関係者の教育、コンプライアンスの実現、信頼の構築に役立ちます。 スコアカードでは、機械学習モデルの特性を明らかにすることで、監査レビューをサポートすることもできます。
プライバシーとセキュリティ
AI がより一般的になるにつれて、プライバシーを保護し、個人情報とビジネス情報をセキュリティで保護することは、より重要で複雑になります。 AI システムでは正確な予測と意思決定を行うためにデータが必要であるため、プライバシーとデータのセキュリティには細心の注意が必要です。 AI システムは、次のプライバシー法を遵守する必要があります。
データの収集、使用、および保存に関する透明性を義務付ける。
利用者に自分のデータの使用方法を選択するための適切な制御を持たせることを義務付ける。
Azure Machine Learning のプライバシーとセキュリティ : Azure Machine Learning を使用すると、管理者と開発者は、会社のポリシーに準拠する  セキュリティで保護された構成を作成  できます。 Azure Machine Learning と Azure プラットフォームを使用すると、次のことができます。
ユーザー アカウントまたはグループでリソースと操作へのアクセスを制限する。
受信および送信のネットワーク通信を制限する。
転送中および保存中のデータを暗号化する。
脆弱性をスキャンする。
構成ポリシーを適用および監査する。
Microsoft では、プライバシーとセキュリティの原則を実装するために、次の 2 つのオープンソース パッケージも作成しました。
SmartNoise SDK : 差分プライバシーは、個人のデータを安全かつプライベートに保つのに役立つ一連のシステムとプラクティスです。 機械学習ソリューションでは、規制遵守のために差分プライバシーが必要になる場合があります。 SmartNoise は、グローバルな差分プライバシー システムを構築するためのコンポーネントを含んだ、(Microsoft が共同開発している) オープンソース プロジェクトです。
SmartNoise SDK : 差分プライバシーは、個人のデータを安全かつプライベートに保つのに役立つ一連のシステムとプラクティスです。 機械学習ソリューションでは、規制遵守のために差分プライバシーが必要になる場合があります。 SmartNoise は、グローバルな差分プライバシー システムを構築するためのコンポーネントを含んだ、(Microsoft が共同開発している) オープンソース プロジェクトです。
Counterfit : Counterfit は、コマンドライン ツールと汎用自動化レイヤーで構成された、オープンソース プロジェクトであり、開発者は AI システムに対するサイバー攻撃をシミュレートできます。 誰でもこのツールをダウンロードし、Azure Cloud Shell を使用して Azure クラウドにデプロイし、ブラウザー内で実行するか、Anaconda Python 環境にローカルにデプロイできます。 さまざまなクラウド環境、オンプレミス、またはエッジにホストされている AI モデルを評価できます。 このツールは AI モデルにとらわれず、テキスト、画像、一般的な入力など、さまざまなデータ型をサポートします。

アカウンタビリティ
AI システムを設計してデプロイするユーザーは、それらのシステムの動作について責任を負う必要があります。 組織では、業界標準を使用してアカウンタビリティ規範を策定する必要があります。 これらの規範は、AI システムが人々の生活に影響を与える意思決定の最終的な権限ではなく、人間が高度に自律的なシステムに対して意味のある制御を維持するのに役立ちます。
Azure Machine Learning のアカウンタビリティ :  機械学習操作 (MLOps)  は、AI ワークフローの効率を向上させる DevOps の原則とプラクティスに基づいています。 Azure Machine Learning には、説明責任を向上するための次の MLOps 機能が用意されています。
どこからでもモデルの登録、パッケージ化、デプロイを行う。 モデルの使用に必要な関連メタデータを追跡することもできます。
エンドツーエンドの機械学習ライフサイクルのためのガバナンス データを取得します。 ログに記録される系列情報には、モデルを公開しているユーザー、変更が行われた理由、モデルが運用環境にいつデプロイされたか、または使用されたかを含めることができます。
機械学習ライフサイクルにおけるイベントについて通知とアラートを行います。 例として、実験の完了、モデルの登録、モデル デプロイ、データ ドリフト検知などがあります。
運用上の問題や機械学習に関連する問題についてアプリケーションを監視します。 トレーニングと推論の間でのモデル入力の比較、モデル固有のメトリックの調査、および機械学習インフラストラクチャに対する監視とアラートの提供を行います。
さらに、Azure Machine Learning の  責任ある AI スコアカード  は、利害関係者間のコミュニケーションを可能にすることでアカウンタビリティを生み出します。 スコアカードを使用すると、開発者は、モデルの正常性に関する分析情報を構成、ダウンロード、および共有し、技術的および非技術的な利害関係者の両方と共有できます。 これらの分析情報を共有すると、信頼を築くのに役立ちます。
Azure Machine Learning では、次の方法でビジネス上の意思決定を通知することで意思決定もサポートされます。
データドリブンの分析情報。関係者は、履歴データのみを使用して結果に対する因果処理の影響を理解するのに役立ちます。 たとえば、"薬は患者の血圧にどのように影響しますか?これらの分析情報は、 責任ある AI ダッシュボード の 因果関係推論 コンポーネントから得られます。
モデル駆動型の分析情報。ユーザーがアクションを実行できるように、ユーザーの質問 ("次に AI から異なる結果を得るために何ができるか" など) に回答します。 これらの分析情報は、 Responsible AI ダッシュボード の 反事実的 What-If コンポーネントを通じて提供されます。
