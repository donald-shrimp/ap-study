適用対象: ✅ Microsoft Copilot

注:
Microsoft 365 Copilot アプリが Microsoft Copilot と呼ばれるようになりました。 更新された Copilot アプリにアクセスするためのプライマリ URL が copilot.cloud.microsoft に変更されます。 ユーザーの接続がブロックされないようにするには、次のことを確認してください。
許可 *.cloud.microsoft。
Microsoft Copilot エンドポイントを許可します。
プロキシ、ファイアウォール、条件付きアクセス、テナント制限、アプリ制御ポリシーによって Copilot アプリがブロックされていないことを確認します。
個人用アカウントにアクセスできないようにするために、 copilot.cloud.microsoft をブロックしないでください。 代わりに、 テナントの制限 を使用して、個人の Microsoft アカウントのサインインを制御します。
詳細については、「 Microsoft Copilot のネットワーク要件」を参照してください。
セキュリティは、Microsoft Copilot に対する Microsoft のアプローチの基礎です。 この記事では、Microsoft が Copilot をどのようにセキュリティで保護しているか、また、Microsoft 365 のセキュリティ、コンプライアンス、プライバシー保護をどのように継承するかについて説明します。
注:
この記事では、Microsoft Copilot に対する Microsoft のセキュリティ アプローチについて説明します。 これには、展開やデータの準備手順は含まれません。
ロールアウトの計画と準備のガイダンスについては、「 Microsoft Copilot 用に安全で管理されたデータ基盤を構成する」を参照してください。

Microsoft の多層防御アプローチ
Microsoft は、企業のセキュリティ、プライバシー、コンプライアンス標準に基づいて、多層的な多層防御戦略を適用して、あらゆるレベルで Microsoft Copilot をセキュリティで保護します。 この階層化されたアプローチは、1 つのコントロールが侵害された場合でも、他の保護を有効にします。
詳細については、「 Microsoft Copilot プロンプト防御の詳細な情報」を参照してください。
ID およびアクセス保護
Microsoft Copilot は、Microsoft 365 の ID とアクセス制御に基づいて構築されており、強力な ID 検証、最小特権アクセス、継続的評価などのゼロ トラスト原則に準拠しています。
詳細については、「 ゼロ トラストの原則を Microsoft Copilot に適用する」を参照してください。
データ保護とコンプライアンス
Microsoft Copilot は、組織の既存のセキュリティとデータ保護の制御を優先します。 Copilot は、ユーザーがアクセスを許可されているデータにのみアクセスし、Microsoft 365 コンプライアンス、プライバシー、データ所在地のコミットメントを尊重します。
詳細については、「 Microsoft 365 と Microsoft Copilot でデータを保護および監査する方法」を参照してください。
エンタープライズ データ保護
エンタープライズ データ保護 (EDP) では、Microsoft 製品条件およびデータ保護補遺に基づいて Microsoft Copilot および Microsoft Copilot Chat の顧客データに適用される契約上および技術的コミットメントについて説明します。

過剰共有の防止
Microsoft Copilot は、既存のアクセス許可とアクセス制御の範囲内で動作します。 コンテンツが共有されすぎたり、管理が不十分だったりすると、Copilot の結果に影響を与え、リスクが高まる可能性があります。

セキュリティ ダッシュボード
Microsoft Copilot には、 Microsoft Purview のセキュリティ制御が組み込まれています。 AI 関連のリスクの監視、調査、対処を支援するために、Microsoft では 2 つの補完的なダッシュボードを提供しています。
Microsoft 365 管理センターの Copilot セキュリティ ダッシュボードは、Microsoft Copilot のデータ保護、過剰共有、コンプライアンスの分析情報に重点を置いています。
AI 用の Microsoft セキュリティ ダッシュボードは、Microsoft Copilot、Copilot Studio エージェント、Microsoft Foundry アプリとエージェント、サード パーティの AI アプリとエージェントにまたがる AI リスクの製品間ビューを提供します。
Microsoft 365 管理センター ダッシュボードは日々の Copilot データ ガバナンスに使用し、Microsoft Defender、Microsoft Entra、Microsoft Purview 全体の AI セキュリティ態勢の組織全体にわたる統合ビューが必要な場合は AI 用セキュリティ ダッシュボードを使用します。
Microsoft 365 管理センターの Copilot セキュリティ ダッシュボード
Copilot セキュリティ ダッシュボードには、次に役立つ分析情報と制御機能が備わっています。
データ損失防止 (DLP) ポリシーを使用してデータ漏洩を防ぎます。
データのオーバー共有を管理します。
データ コンプライアンスを強化します。
Microsoft 365 管理センターでダッシュボードを表示するには、[Copilot>概要>セキュリティ] を選択します。
[ セキュリティ ] セクションを表示するには、 グローバル閲覧者 ロールが必要です。 変更を加えるには、 AI 管理者 ロールが必要です。
AI 用 Microsoft セキュリティ ダッシュボード
Microsoft Security Dashboard for AI は、CISO と AI リスク リーダーが企業全体の AI リスクを理解して対処するのに役立つ統合ダッシュボードです。
Microsoft Defender、Microsoft Entra、Microsoft Purview からの姿勢とリアルタイムのリスク シグナルを 1 つの対話型エクスペリエンスに集約します。 セキュリティ リーダーは、セキュリティ チームがすでに使用しているツールで作業を続けながら、ガバナンスとコラボレーションを行うことができます。
ダッシュボードでは、次の機能が提供されます。
リアルタイムの AI リスク可視化。 [概要] タブの AI リスク スコアカードは、リスクが存在する場所を強調表示し、組織による Microsoft の security-for-AI 機能の実装を評価します。
包括的な AI インベントリ。 以下を含む AI 資産の幅広いカバレッジ:
Microsoft Copilot
Microsoft Copilot Studio エージェント
Microsoft Foundry アプリケーションとエージェント
サードパーティの AI モデル、アプリケーション、Google Gemini、OpenAI ChatGPT、MCP サーバーなどのエージェント
環境内で検出されたアンマネージド AI エージェントとシャドウ AI エージェント
Security Copilot を使用した AI を活用した分析情報。 推奨されるプロンプトは、リスク評価のドリルダウン、ID、データ、セキュリティ シグナルの関連付け、Microsoft Copilot および関連するエージェント ワークロードにとって最も重要なインシデントの優先順位付けを行うのに役立ちます。
カスタマイズされた推奨事項と修復パス。 ダッシュボードには、優先される推奨事項が表示され、 タスクの委任がサポートされ、 Microsoft Teams と統合されて、Copilot やその他の AI エージェントでの過剰共有とデータ漏洩のリスクの修正が調整されます。
エグゼクティブ レポート。 リーダーシップのレビューのための取締役会向けの分析とコンプライアンスの洞察。
アクセスとアクセス許可
ai.security.microsoft.com で AI のセキュリティ ダッシュボードを開くか、Microsoft Defender、Microsoft Entra、または Microsoft Purview ポータルから入力します。
ダッシュボードでは 、既存の Defender、Entra、Purview のアクセス許可 が使用されます。個別のロールは必要ありません。 対象となる Defender、Entra、Purview のお客様は、 追加のライセンス費用なしで AI のセキュリティ ダッシュボードにアクセスできます。
サポートされている製品の完全な一覧、アクセス許可の詳細、セキュリティに関する推奨事項を確認して割り当てる方法については、「 Microsoft Security Dashboard for AI を使用して組織の AI リスクを評価する」を参照してください。
