    Microsoft Copilot が記憶する内容をカスタマイズする

    Microsoft Copilot は、Copilot メモリを使用してMicrosoft Copilot Chatとの会話から重要な詳細や好みを記憶することで、カスタマイズされたエクスペリエンスを提供します。 時間が経つにつれて、コミュニケーション スタイル、お気に入りのトピック、仕事の目標、定期的なタスクなどの有用な情報を呼び出して、会話をより簡単で関連性の高いものにすることができます。 ユーザーが Copilot メモリを有効にしている場合、Copilot は Copilot Chat 会話と使用状況データ、Microsoft 365 作業データ、使用状況シグナル、プロファイル情報を使用して、パーソナライズされた推奨事項を提供できます。

    Copilot Chat が記憶する内容をカスタマイズする

    Copilot は、次の方法でチャット エクスペリエンスとその応答をパーソナライズします:

    • Copilot メモリにメモリを保存する
    • チャット履歴から推論を行う
    • 作業コンテンツからの分析情報を使用する
    • Copilot のカスタム指示を使用する
    • 一時的なチャットで話し合った内容を忘れる

    Copilot Chat を使用してメモリを保存する

    Copilot メモリがオンになっている場合、Copilot は Copilot Chat の会話から重要な情報を自動的にメモリに保存します。

    Copilot Chat で保存されたメモリを管理する方法については、「Microsoft Copilot で Copilot メモリを管理する」を参照してください。

    チャット履歴を再表示する

    Copilot は、Copilot Chat との以前の会話の履歴を保持します。 Copilot は、以前の会話を使用して、その後の会話に応答することで、何が重要かを推論できます。

    チャット履歴を再表示する方法については、「Microsoft Copilot Chat履歴を再確認する」を参照してください。

    作業コンテンツからの分析情報を使用する

    注

    Work insights は、職場または学校アカウントでサインインしている場合にのみ利用できます。また、organization が使用している Microsoft Copilot プランによって異なります。

    作業インサイトは、メール、チーム チャット、会議のトランスクリプトなど、Microsoft 365 の作業コンテンツから学習した詳細です。 Copilot はこの情報を使用して、よりパーソナライズされた応答を提供します。

    Copilot があなたについて知っていることを知るには、「私について何を知っていますか」と尋ねてください。これにより、Copilot が応答をパーソナライズするために使用する、仕事の分析情報を含む重要な情報の概要が提供されます。 削除してほしい作業の分析情報が表示された場合は、その詳細を忘れるように Copilot に依頼できます。Copilot はそれを使用して今後の応答をカスタマイズすることはありません。

    仕事の分析情報を管理する方法については、「Copilot が自分について知っている情報を完全に削除する操作方法」セクションを参照してください。

    Copilot 設定にカスタム指示を追加する

    Copilot の応答方法をさらにパーソナライズするには、コミュニケーションの設定など、覚えておくべき重要な情報を Copilot に伝えるカスタム指示を作成します。

    Copilot のカスタム指示を管理する方法については、「Microsoft Copilot の応答方法をカスタマイズする」を参照してください。

    一時チャットを使用して Copilot Chat が記憶する内容を制限する

    メモリを使用または更新せずにチャットする場合は、 一時チャットを開始できます。 これらの会話では、パーソナライズされた情報にアクセスしたり、保存したりすることはありません。 また、会話はチャット履歴に表示されず、後であなたや Copilot が参照したりアクセスしたりすることはできません。

    ただし、organization のデータ保持ポリシーによっては、一時的なチャット データの保持が必要になる場合があります。 保持期間中は、IT 管理者がこのデータにアクセスできる場合があります。

    一時チャットを開始するには、次の手順を実行します。

    1. Copilot Chat に移動し、Microsoft 365 アカウントでサインインします。
    2. Copilot Chat ページの右上にある [Copilot Chat] のを選択します [新しい一時チャットの開始] ボタン。
    3. 通常と同じように Copilot を使用してChatします。

    Microsoft は Copilot メモリ データをどのように処理しますか?

    Microsoft は、Microsoft Copilot の他の作業データと同様に注意して Copilot メモリを処理します。

    Copilot Chat データ処理標準の詳細については、「Microsoft Copilot Chatについてよく寄せられる質問」を参照してください。

    Copilot が自分について知っている情報を完全に削除する操作方法

    Copilot メモリがオンになっていて、Copilot が記憶しているものを完全に削除する場合は、次の 2 つの手順を実行する必要があります。

    1. 保存したメモリを Chat 設定から削除します。 そうすることで、Copilot は、以前に記憶するように要求した特定の詳細を保持しなくなります。 保存したメモリを削除する方法については、「 Copilot メモリから情報を削除する」を参照してください。

    2. [チャット履歴] トグルをオフにして、チャット履歴から思い出を削除するには、Chat 履歴から思い出を削除します。 これにより、Copilot が以前の Copilot Chat の会話から行った推論が削除されます。 organization の IT 管理者に問い合わせることもできます。 チャット履歴データを削除する方法については、「チャット履歴に基づいて Copilot の個人用設定をオフにする操作方法」をご覧ください。

      • 職場または学校アカウントでサインインしている場合、トグルで履歴 & 仕事の分析情報Chat表示される場合があります。 その場合、Copilot が作業内容に基づいて作成した思い出も、チャット履歴の思い出と共に削除されます。
      • 削除後 30 日以内に Chat 履歴トグルが再びオンになった場合、Copilot は削除されたメモリをチャット履歴 (および作業インサイトが利用可能な場合は作業コンテンツから) 追加します。
      • Chat 履歴の切り替えをオンのままにして、Copilot がチャット履歴 (および仕事のインサイトが利用可能な場合は仕事のコンテンツから) から学習した情報を使用しないようにする場合は、チャットでその情報をカスタマイズに使用しないように依頼できます。
