Microsoft Copilot アクティビティ履歴を削除する
注
Microsoft 365 Copilot の名前が Microsoft Copilot になり、Microsoft 365 Copilot Chat の名前が Microsoft Copilot Chat になりました。 一部のユーザー インターフェイス (UI) では、移行期間中も Microsoft 365 Copilot および Microsoft 365 Copilot Chat を参照する場合があります。 Microsoft Copilot アクティビティ履歴の削除方法に変更はありません。
注
この記事の情報は、職場または学校アカウントでサインインしている場合にのみ適用されます。
個人用 Microsoft アカウントでサインインしているときに Copilot アクティビティ履歴を削除する方法については、「 プライバシー ダッシュボードで Copilot アクティビティ履歴を管理する」を参照してください。
Microsoft Copilot は、アプリ内のさまざまなタスクやアクティビティを支援するように設計された、AI 搭載のデジタル アシスタントです。
Copilot アクティビティ履歴は、Microsoft Copilot でのプロンプトと応答の記録です。 Copilot アクティビティの例としては、Word 文書内の段落を書き直すよう Copilot に依頼したり、OneNote のノートから To Do リストを生成するよう Copilot に依頼したりすることなどがあります。
Microsoft Copilot アクティビティ履歴を削除する方法
Microsoft Copilot アクティビティ履歴を削除するには:
職場または学校アカウントで マイ アカウント ポータル にサインインします。
[マイ アカウント]>データとプライバシー>データ オプションに移動し、[Copilot アクティビティ履歴] セクションを開きます。
[削除] を選択します。
[Copilot アクティビティ履歴の削除] ダイアログで、[Microsoft Copilot] チェックボックスをオンにします。
[ 削除] を選択して、削除要求を Microsoft に送信します。
Microsoft Copilot アクティビティ履歴を削除するとどうなりますか
[Copilot アクティビティ履歴の削除] ダイアログで [削除] を選択すると、削除要求が Microsoft に送信されます。 Microsoft Copilot アクティビティ履歴が完全に削除されるまでに時間がかかる場合があります。
[ 削除] を選択したときにアプリが開いている場合は、アプリを閉じるまで以前のアクティビティ履歴が引き続き表示される場合があります。 次にそのアプリを再度開き、Copilot を再び使用し始めると、アクティビティ履歴が消去されます。 つまり、Copilot とのやりとりは最初からやり直すことになります。 Copilot では、以前のアクティビティは表示されません。
Copilot が役立ったコンテンツや、ファイルに保存したコンテンツは、[ 削除] を選択しても削除されません。 たとえば、Copilot が PowerPoint スライドの変更に役立ち、それらの変更を保存した場合、それらの変更は削除されません。
Copilot アクティビティ履歴を使用した Microsoft 365 アプリ
次の Microsoft 365 アプリでは、Copilot アクティビティ履歴が保存されます。
Excel
フォーム
Loop
OneNote
Outlook
Planner
PowerPoint
Teams
Whiteboard
Word
Microsoft Copilot Chat
Microsoft Copilot を選択すると、Copilot アクティビティ履歴がこれらすべてのアプリから削除されます。 この選択では、Word や PowerPoint など、一部のアプリからのみアクティビティ履歴を削除することはできません。
