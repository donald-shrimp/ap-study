Microsoft 365 のエージェント管理ガイド
フィードバック
Microsoft Copilot を対象となる一般法人向け Microsoft 365 サブスクリプションに追加すると、組織に生成 AI 機能が提供されます。 これらの機能を使用すると、組織の生産性を向上させ、精度を向上させ、パーソナライズされた支援を提供できます。
Microsoft Copilot が提供する生成 AI 機能に加えて、AI の実装を拡張してエージェントを含めることができます。 エージェントを使用すると、Copilot エクスペリエンスをカスタマイズできます。 エージェントを組織のナレッジおよびデータ ソースに接続して、組織のメンバーが質問に回答し、タスクを自動化し、ビジネス プロセスを実行できるように支援できます。 これらの AI 主導のエージェントはさまざまなタスクを実行し、あなたと協力して提案を提供し、反復的なタスクを自動化し、あなたとあなたの組織がより多くの情報に基づいた意思決定を行うのに役立つ洞察を提供します。
このガイドの手順は以下のとおりです。
組織が必要とする Copilot エージェントの機能を判断するのに役立ちます
組織のメンバーがエージェントを表示している場所を理解するのに役立ちます
エージェントの作成方法と、各開発環境がエージェントに提供するさまざまな機能を理解するのに役立つガイダンスを提供します
組織全体のエージェント アクセスおよび共有ポリシーのオプションを推奨します
エージェントの管理、割り当て、展開の方法を理解するのに役立ちます
Copilot とエージェントのセキュリティ、コンプライアンス、プライバシーに関するリソースを提供します
注:
Microsoft 365 管理センター内の Copilot コントロールでエージェントを構成、管理、割り当て、展開するには、テナントに特定のアクセス許可が必要です。 詳細については、「 管理者権限」を参照してください。
Copilot ライセンス シナリオを特定する
組織は通常、Microsoft Copilot Chat と Microsoft Copilot を組み合わせて展開します。 開始する前に、エージェントのデプロイと使用に関して、これら 2 つのオファリングの違いを理解することが重要です。
Microsoft Copilot Chat は、Microsoft 365 または Office 365 サブスクリプションを持つすべての Microsoft Entra アカウント ユーザーが追加料金なしで利用できます。 組織のメンバーは、エージェント ストアから追加料金なしで利用できるエージェントを使用できます。 組織の管理者は、これらのエージェントも有効にする必要があります。 組織で組織のデータが組み込まれたエージェントが必要な場合は、従量制課金制の消費に基づいて請求される エージェント へのアクセスを提供できます。 Microsoft Copilot Chat の詳細については、「 Microsoft Copilot の要件」を参照してください。
Microsoft Copilot Chat を含む Microsoft Copilot には、Microsoft 365 Business または Enterprise プランが必要です。 これには、Web ベースと仕事ベースのデータの両方に基づいた AI 搭載のチャットと、Microsoft Copilot Chat の機能が含まれます。 さらに、Microsoft Copilot は、Word、Excel、Outlook、Teams に埋め込まれた Copilot 機能のロックを解除します。 さらに、 組織ではカスタム エージェントを使用できます。 詳細については、「 Microsoft Copilot の要件」を参照してください。
各 Copilot オプションは、異なる機能を提供します。 これらの機能の一覧については、「 Microsoft 365 ユーザー向けのエージェントの機能」を参照してください。
重要
重要: 既に Copilot を使用している場合は、 ライセンス プラン を表示して、組織が Microsoft Copilot Chat または Microsoft Copilot のどちらを使用しているかを確認してください。 Microsoft Copilot を初めて使用する場合は、「 IT 管理者向け Microsoft Copilot 導入ガイドと概要」を参照してください。
利用可能なエージェント オプションを理解する
Copilot デプロイ全体を最もよく理解するには、エージェントで使用できるオプションを理解する必要があります。 使用量課金なしで Microsoft Copilot Chat を展開するか、使用量課金なしで Microsoft Copilot Chat を展開するか、Microsoft Copilot を展開するかに応じて、さまざまなエージェントの機能を使用できます。
注:
SharePoint や Graph Connector コンテンツなどの共有テナント データにアクセスするエージェントは、従量制課金制の消費に基づいて請求されます。 従量制課金制消費を利用しているエージェントは、Microsoft Copilot Chat のユーザーに対して既定でオフになっています。

オプション 1 - Microsoft Copilot Chat を使用するエージェント (使用量請求なし)
Microsoft Copilot Chat は、Microsoft 365 サブスクリプションを持つすべての Microsoft Entra アカウント ユーザーに追加料金なしで Microsoft 365 サブスクリプションに含まれています。 パブリック Web ベースの Copilot Chat へのアクセスを提供します。 このオプションにより、追加費用なしで、指示とパブリック Web サイトに基づいた 宣言型エージェントへのアクセスも提供されます。 これらのエージェントは、Teams および Microsoft 365 アプリの組織のストア設定に基づいて、 Microsoft Copilot のエージェント ストア で利用できます。 このオプションは、Copilot とエージェントを時折使用するユーザーに最適です。
オプション 2 - Microsoft Copilot Chat を使用するエージェント (使用量課金)
Microsoft Copilot Chat は、組織が Copilot サービスにアクセスするための柔軟なプランと併用することもできます。 オプションで、仕事ベースのチャットへの従 量課金制アクセス を選択し、宣言型エージェントとカスタム エージェントをデプロイできます。 カスタム エージェントは、Microsoft Graph のグラウンディング (テナント データ) を使用できます。 Copilot Chat のユーザーに対して従量制課金制消費を利用するエージェントを有効にするには、管理者は既存の Copilot Studio サブスクリプションを設定または使用する必要があります。 詳細については、「 Microsoft Copilot Chat でのエージェントの使用」を参照してください。
このオプションは、ユーザーとあなたの組織が組織の使用パターンを理解するための手段を提供します。 組織で Microsoft Copilot Chat の機能、従量課金制の職場ベースのチャット、高度なエージェントがどのように使用されているかを理解することで、プリペイド ライセンスがビジネスにとって経済的に理にかなっているかどうかを判断できます。
オプション 3 - Microsoft Copilot (ライセンス) を持つエージェント
Microsoft Copilot は、Web ベースと仕事ベースのデータの両方に基づいたチャットと、Microsoft Copilot Chat の機能を提供します。 さらに、Microsoft Copilot は、Word、Excel、Outlook、Teams に埋め込まれた Copilot 機能のロックを解除します。 また、Microsoft 365 Copilot ライセンスを使用すると、 組織でカスタム エージェントを使用できます。 Microsoft Copilot を使用すると、エージェントを作成、展開、使用、共有して Microsoft Copilot の機能を拡張できます。 これには、単純なプロンプトベースのエージェントから、より高度な自律エージェントまで、すべてのエージェントが含まれます。 さらに、Microsoft Copilot のライセンスを購入すると、組織は リサーチ ツール や アナリストなどの追加機能を使用できるようになります。
注:
Microsoft Copilot を購入するには、組織が対象の Microsoft 365 エンタープライズまたはビジネス向けプランを持っている必要があります。 Microsoft Copilot は、 アドオン プランとして利用できます。 組織は、組織の要件に最も適したライセンスを選択できます。 組織のアカウントに適切なプランがない場合は、新しいプランを購入するか、 既存のプランをアップグレードする可能性があります。
利用可能なエージェントを表示する
既定では、Microsoft と Microsoft パートナーは、Microsoft Copilot Chat および Microsoft Copilot とすばやく統合および展開できるすぐに使用できるエージェントを提供します。 さらに、組織のメンバーによって作成されたエージェントを統合して展開できます。
エージェントは、Microsoft Copilot アプリで直接表示できます。 Microsoft Copilot アプリの使用の詳細については、「 Microsoft Copilot アプリとは 」を参照してください。エージェントの詳細については、「 Microsoft Copilot アプリでエージェントの使用を開始する」を参照してください。

Microsoft Copilot でエージェントを表示する
追加料金なしで利用でき、Microsoft Copilot Chat に含まれている Microsoft エージェントの例としては、ライティング コーチ、アイデア コーチ、プロンプト コーチ、キャリア コーチ、ラーニング コーチなどがあります。 その他の例を表示するには、 Microsoft Copilot Chat エージェントのデモ ビデオを参照してください。
Microsoft Copilot Chat で事前構築済みのエージェントを表示するには:
タスク バーから Microsoft Copilot アプリを選択して、Microsoft Copilot を開きます。 または、ブラウザーで [ https://m365.cloud.microsoft ] に移動します。
Microsoft Copilot アプリで、[ エージェント>すべてのエージェント ] を選択して、 エージェント ストアを表示します。 または、ブラウザの [エージェント] で [ すべてのエージェント ] を選択して、 エージェント ストアを表示します。
エージェント ストアでは、利用可能なエージェントを表示できます。 Microsoft によって構築されたエージェント、組織によって構築されたエージェント、および組織内で人気のあるエージェントを表示できます。
注:
組織のメンバーにエージェントを表示するオプションが表示されず、その職場または学校のアカウントに対象となる Microsoft 365 サブスクリプションがある場合、テナントにデプロイされているエージェントがない可能性があります。 さらに、Copilot 機能のすべてまたは一部がオフになっているか、お住まいの市場で Copilot が利用できない可能性があります。
Microsoft Teams でエージェントを表示する
Microsoft Teams で事前構築済みのエージェントを表示するには:
Microsoft Teams アプリを開き、[ Copilot] を選択します。
[ すべてのエージェント ] を選択して 、エージェント ストアを表示します。
エージェントの作成
管理者は、新しいエージェントを作成して公開することなく、すぐに使用できるエージェントを構成および展開できます。 ただし、組織で Copilot 機能をカスタマイズする必要がある場合 (Copilot の知識の拡張、ワークフローの自動化、カスタマイズされたユーザー エクスペリエンスの提供など)、組織のユーザーと開発者は、管理と展開が可能なエージェントを構築できます。
✅
タスク: 組織がエージェントを作成する機能を必要としているかどうかを判断します。組織で作成、共有、展開できるさまざまな種類のエージェントについて理解します。
Microsoft Copilot のエージェントを構築するには、2 種類のアプローチがあります。 組織のユーザーと開発者は、 宣言型 アプローチまたは カスタム エンジン エージェントを使用できます。 どちらのアプローチも Copilot の AI インフラストラクチャ、モデル、オーケストレーターを使用するため、Microsoft 365 のセキュリティ、コンプライアンス、責任ある AI (RAI) 要件に準拠しています。
宣言型エージェントを使用すると、組織のメンバーは特定のシナリオに合わせて Copilot を構成できます。 これらのエージェントは、個人が使用するように設計されています。 また、これらのエージェントは、Copilot のオーケストレーターとモデルに限定されており、ユーザーの指示を使用します。 宣言型エージェントは、ユーザーが開始する対話に依存しています。 組織のメンバーは、Microsoft SharePoint と Agent Builder を使用して宣言型エージェントを作成できます。 また、作成者は、Agent Builder で作成された宣言型エージェントと同等の Copilot エージェント を Copilot Studio で作成できます。 ただし、Copilot Studio は、エージェント ビルダーで作成できるエージェントよりも優れた機能を備えたエージェントを作成するために使用されます。 詳しくは、 宣言型エージェントを参照してください。
カスタム エンジン エージェントは、完全にカスタマイズされた AI アシスタントです。 組織のメンバーがカスタム エンジン エージェントを構築すると、グループとコラボレーションしたり、これらの種類のエージェントを自分で作成したりできます。 AI モデルとオーケストレーションも選択できます。 カスタム エンジン エージェントを使用すると、組織のメンバーは、ユーザーが直接入力しなくても、アクションを自動的にトリガー有効にすることもできます。 カスタム エンジン エージェントは、組織で使用できるようになる前に、管理者などの組織によって発行され、承認される必要があります。 組織のメンバーは、 Copilot Studio と Microsoft 365 Agents Toolkit を使用してカスタム エンジン エージェントを作成できます。 詳細については、「 カスタム エンジン エージェント」を参照してください。
✅
タスク: エージェントを作成するときに使用できる環境とツール、およびそれぞれが組織に提供する機能を理解します。これらの環境を理解することで、さまざまなエージェントを管理および展開する方法をより深く理解できます。
前提条件
組織で新しいエージェントを作成する前に、まず組織の目標、技術要件、コスト、責任ある AI (RAI) に関する考慮事項、コンプライアンス要因を考慮してください。 詳細については、「 Microsoft Copilot 拡張性計画ガイド」を参照してください。
Copilot 自体が組織の要件にすぐに対応できない場合は、エージェントの構築を検討してください。 エージェントを使用すると、あなたとエンド ユーザーは Copilot の知識を広げ、複雑なワークフローを自動化し、カスタマイズされたユーザー エクスペリエンスを提供できます。
組織では、ツールと環境を含むいくつかの異なる方法を使用して、Microsoft Copilot のエージェントを作成できます。

Microsoft SharePoint
組織のメンバー (エンド ユーザー) は、Microsoft SharePoint を使用してエージェントを作成できます。 SharePoint で作成されたエージェントは、SharePoint または Teams チャット内の特定のサイト、フォルダー、またはファイルからコンテンツを照会するための簡単なオプションを提供します。 組織のメンバーは、SharePoint にアクセスでき、テナントが SharePoint の従量課金制として有効になっている場合、または Microsoft 365 Copilot ライセンスを持っている場合、SharePoint エージェントを構築できます。
組織のメンバーが SharePoint で作成したエージェントには、SharePoint と Teams チャットを使用してアクセスできます。 これらのエージェントは、既存のユーザーのアクセス許可とセキュリティ設定に基づいて共有できます。
詳細については、「SharePoint エージェントの使用を開始する」 および 「SharePoint エージェントへのアクセスを管理する」を参照してください。
Microsoft Copilot のエージェント ビルダー
組織内のユーザーは、Microsoft Copilot の Agent Builder 機能を使用して 宣言型エージェントを作成できます。 ユーザーは、Copilot を調整し、SharePoint、Teams、Outlook などのエンタープライズ データから ナレッジ ソース を追加するためのエージェントを作成できます。パブリック Web サイト;Microsoft 365 Copilot コネクタを介してインデックスが付けられた外部データ。 Agent Builderには、ユーザーがすばやく開始するのに役立つ テンプレート も用意されています。 ユーザーは、Agent Builderで作成されたエージェントを組織内の他のユーザーと共有できます。
Agent Builder は、Microsoft 365 Copilot ライセンスを持つユーザー、または Copilot Studio で従量課金が有効になっているテナントで利用できます。 エージェントの機能は、組織の課金モデルによって異なります。 エージェントビルダーのネットワーク要件については、「 ネットワーク要件」を参照してください。
エージェントビルダーの詳細については、「 エージェントビルダー」を参照してください。
Copilot Studio
Copilot Studio を使用すると、ローコード開発者 ("作成者") は宣言型エージェントまたはカスタム エンジン エージェントを構築できます。 Copilot Studio で作成された宣言型エージェントは Copilot エージェント と呼ばれ、Copilot Studio 内の特定の開発パスに従います。
カスタム エンジン エージェント (カスタム エージェントとも呼ばれます) は、カスタム データ、他のエージェント、意思決定パス、データ ソース コネクタ、 および自動化と統合されます。 これらのエージェントは、内部または外部にデプロイでき、Microsoft 365 Copilot ライセンスまたは従量課金制モデルで使用できます。 Microsoft Graph コネクタを活用して共有された組織データを公開すると、Copilot エージェントは企業全体の情報を推論し、より深い分析情報を解き放ち、変革的な生産性の成果を推進できます。 さらに、これらのエージェントは、生成オーケストレーションと生成回答を使用するように設計できます。 Copilot Studio を使用して作成されたエージェントは、Microsoft 365 Copilot ライセンスに基づく Microsoft Copilot Chat と Microsoft Copilot 内で使用できます。また、従量課金制のシナリオも可能です。
注:
Microsoft Copilot Studio は、Power Platform 製品セットの一部です。
Power Platform 管理センターを使用すると、管理者は組織のカスタム エンジン エージェントのエージェント開発設定とエージェント ガバナンス制御を管理できます。 関連情報については、「 Power Platform での Copilot 導入の追跡、管理、スケーリング 」および「 主要な Copilot 構成設定」を参照してください。
すぐに開始するには、 最初のエージェントを作成して公開 するチュートリアル ビデオをご覧ください。
詳細については、「 Copilot Studio の概要」、「 Copilot Studio のドキュメント」、および「 Microsoft Copilot Studio」を参照してください。
Microsoft 365 Agents Toolkit
Microsoft 365 Agents Toolkit は、組織内の開発者がエンタープライズ対応のエージェントとアプリを構築するために使用できるツールのスイートです。 Toolkitを使用して開発されたエージェントは、より優れた共有 機能と公開を行います。 これらのエージェントは、Microsoft Copilot、Teams、Office、Web、その他のサードパーティのメッセージング チャネル全体で動作します。 組み込みのプロジェクト スキャフォールディング、テスト、デプロイ、Microsoft 365 エージェント SDK、Azure AI Foundry、TypeSpec for Copilot などの AI ツールとの統合により、運用 AI エージェントとアプリの開発を効率化します。
エージェントの開発の詳細については、「 Microsoft 365 Agents Toolkit」を参照してください。
エージェント ポリシーの設定
エージェント ポリシーとは、管理者として Microsoft 365 管理センター内の Copilot コントロールで行うことができるテナント設定を指します。 エージェント ポリシーは、テナント内のすべてのエージェントで使用可能な設定に関連しています。 さらに、これらのポリシーには、エージェントアクセス、エージェント共有、およびエージェント公開設定が含まれます。 テナントの Copilot エージェント設定にアクセスするには、適切な 管理者アクセス許可 が必要です。
エージェント ポリシーの設定、エージェント インベントリの管理、組織のメンバーへのエージェントの割り当てと展開はすべて、Copilot エージェント ガバナンスに該当します。
注:
Microsoft 365 管理センターで使用できるエージェント設定に加えて、 Power Platform 管理センターの Copilot Studio で作成されたエージェント用の特定の設定があります。
エージェント ガバナンスを理解する
Copilot エージェント ガバナンスとは、ポリシー、設定、アクションを使用して組織全体でエージェントを管理することを指します。 エージェントへの適切なアクセスをグローバルに維持するポリシーを作成し、管理設定と制御を使用して、組織のエージェントを承認、公開、展開、削除、ブロックできます。 Copilot エージェントを効果的に管理することで、責任ある準拠したアプローチで組織が使用するエージェントとデータを保護およびセキュリティ保護できます。

個人使用のためのエージェントのサイドロード
組織のメンバーは、組織のカタログやマーケットプレースに公開せずに、組織内でエージェントを構築して共有できます。 エージェントをデプロイするためのこのアプローチは、サイドローディングと呼ばれます。 組織のメンバーが Teams アプリでエージェントまたはカスタム アプリ パッケージをアップロードすることを組織で許可するかどうかを決定できます。 Teams 経由でエージェントをアップロードすると、Teams 内および Microsoft Copilot アプリ内でエージェントを使用できるようになります。
注:
SharePoint で構築された宣言型エージェントをサイドロードすることはできません。
サイドローディングを有効にすると、カスタム エージェントを Teams アプリ ストアに送信しなくても、個人または組織全体で使用できます。 その後、組織のメンバーは、より広範に配布する前に、1 人のユーザーやユーザー グループなど、限定された対象ユーザーでカスタム エージェントをアップロードしてテストできます。
✅

組織のサイドローディングを有効にすると、組織のメンバーはエージェントの zip ファイルをアップロードできるようになります。 詳細については、「 ZIP パッケージを介したエージェントの展開」を参照してください。
エージェントを他のユーザーと共有する
組織のメンバーは、作成したエージェントを組織内の他のユーザーと共有できます。 ただし、エージェントを共有する方法は、エージェントの作成方法によって異なります。
次の表に、エージェントを共有するために使用できるさまざまな方法を示します。
エージェントの共有方法
詳細
SharePoint からエージェントを共有する
組織のメンバーは、SharePoint で作成した宣言型エージェントを共有できます。 これらのエージェントは、Microsoft Teams でのみ共有できます。
エージェント ビルダーからエージェントを共有する
組織のメンバーは、Agent Builderで作成した宣言型エージェントを共有できます。 これらのエージェントは、Microsoft Teams と Microsoft Copilot アプリで共有できます。
Copilot Studio から Copilot エージェントとカスタム エンジン エージェントを共有する
組織のメンバーは、Copilot Studio で作成した Copilot エージェントとカスタム エンジン エージェントを共有できます。 これらのエージェントは、組織内の限られたグループとのみ共有できます。 Copilot Studio の共有エージェントは、共同作業テストの目的で使用されます。 エージェント作成者の準備ができたら、管理者の承認のためにこれらのエージェントを公開できます。 これにより、これらのエージェントは、組織カタログからより幅広い内部対象ユーザーにリーチできます。
Microsoft 365 Agents Toolkit で作成したエージェントを共有する
開発環境から組織のメンバーと共有し、共同作業を行うこともできます。 詳細については、「 Microsoft Teams アプリを公開する」を参照してください。
組織カタログへの発行
組織のメンバーは、エージェントを作成して組織カタログに公開できます。 管理者は、これらの要求されたエージェントを組織カタログに追加する前に、Copilot コントロールで承認する必要があります。 組織のメンバーは、作成者または開発者が展開チャネル用に選択したチャネルに基づいて、これらのエージェントを検索してインストールできます。
エージェントを組織カタログに発行できるかどうかは、エージェントがどのように作成されたかによって異なります。
エージェントの公開方法
詳細
Copilot Studio から Copilot エージェントを発行する
組織のメンバーは、 Copilot エージェント を作成して組織カタログに発行できます。 管理者は、これらの要求されたエージェントを組織カタログに追加する前に、Copilot コントロールで承認する必要があります。 組織のメンバーは、Microsoft Teams と Microsoft Copilot アプリで Copilot エージェントを見つけてインストールできます。
Copilot Studio からカスタム エンジン エージェントを発行する
組織のメンバーは、 カスタム エンジン エージェント を作成して組織カタログに発行できます。 これらの要求されたエージェントは、組織カタログに追加する前に、Copilot コントロールで承認する必要があります。 組織のメンバーは、カスタム エンジン エージェントをさまざまなチャネルで見つけてインストールできます。 これらのチャネルには、Microsoft Teams、Microsoft Copilot、Facebook、WhatsApp、Twilio などが含まれます。 さらに、カスタム エンジン エージェントを Web アプリおよびネイティブ アプリとしてデプロイできます。 これらのエージェントは、Customer Engagement アプリにも接続できます。
Microsoft 365 Agents Toolkit で作成したエージェントを共有する
開発環境から組織のメンバーと共有し、共同作業を行うこともできます。 詳細については、「 Microsoft Teams アプリを公開する」を参照してください。
注:
SharePoint で構築された宣言型エージェントは、組織カタログに発行できません。
Microsoft コマーシャル マーケットプレースに提出する
エージェントを公開するには、Microsoft Teams 内の Microsoft Teams ストアに送信できます。 Teams ストアに公開されたアプリは、 Microsoft コマーシャル マーケットプレースに自動的に一覧表示されます。
Microsoft 365 Agents Toolkit のツール スイートを使用して、エージェントを作成します。 エージェントは、責任ある AI (RAI) の原則を満たし、価値のあるエンド ユーザー エクスペリエンスを提供し、企業のニーズを満たす必要があります。 RAI には、透明性、説明責任、信頼性、安全性が含まれます。 バリューのあるエクスペリエンスは、機能的に生産的で質の高いエンドユーザー エクスペリエンスを含むエージェントを提供します。 エンタープライズのニーズは、管理者の信頼基準を満たし、生産性とコラボレーションの全体的な目標を満たしています。
注:
Microsoft 365 Agents Toolkit のツール スイートで構築された宣言型エージェントとカスタム エージェントのみをコマーシャル マーケットプレースに送信できます。
エージェントを Microsoft コマーシャル マーケットプレースに送信する方法の詳細については、「 Teams ストアにアプリを公開する」を参照してください。

✅
タスク: Microsoft 365 管理センターで組織のエージェント インベントリを確認して確認します。組織のエージェントの可用性を変更して、不要な機能を無効にします。
次の手順を使用して、組織のエージェント インベントリを表示します。
ブラウザーで Microsoft 365 管理センター を開きます。
[エージェント>すべてのエージェント] を選択します。
エージェント インベントリをフィルター処理します:
[フィルター] の横にある [空き時間情報>すべてのユーザー] を選択します。
組織のメンバーがエージェントを使用できる場所を認識するには、[ サポート場所] 列 をメモします。
一覧を確認した後、すべてのフィルターをクリアします。
[エージェント インベントリ] の下にある [所有者が見つからない] を選択します。
所有者がなくなったエージェントの削除を検討してください。
一覧を確認した後、すべてのフィルターをクリアします。
[フィルター] の横にある [可用性] > [ユーザーなし] を選択します。
組織のメンバーが利用できないエージェントをメモします。 組織が必要とするエージェントを具体的にデプロイし、不要なエージェントをブロックすることを検討してください。
エージェントのピン留め
管理者は、展開されたエージェントを Microsoft Copilot 内の エージェント リストにピン留めすることを選択できます。 Microsoft Copilot にエージェントをピン留めすると、組織のすべてのメンバー、または特定のユーザーまたはグループでのみエージェントが表示されてアクセスできるようにすることができます。 エージェントのピン留めとピン留め解除を選択できます。 また、ピン留めされたエージェントのリストをランク付けすることもできます。
✅
タスク: Microsoft 365 管理センターに表示される組織の固定エージェントを確認して確認します。
Microsoft Copilot には、Microsoft、管理者、ユーザーによってピン留めされたエージェントが含まれています。 Microsoft の固定エージェントは、すべてのユーザーに対して既定でピン留めされている特定のエージェントです。 管理者のピン留めされたエージェントは、Microsoft 365 管理センターの Copilot コントロールを使用して、あなたまたはあなたの組織によってピン留めされます。 ユーザーがピン留めしたエージェントは、各自の Microsoft Copilot Chat または Microsoft Copilot エクスペリエンスで個々のユーザーによってピン留めされます。
組織のピン留めされたエージェントを設定、表示、または管理するには、「 エージェントのピン留めの管理」を参照してください。
カスタム エージェントをアップロードする
Microsoft 365 管理センターの Copilot コントロールでは、カスタム エージェントをアップロードする方法が提供され、組織のエージェント インベントリから管理できます。
✅
タスク: カスタム エージェントを Microsoft 365 管理センターの Copilot コントロールに直接アップロードします。作成者に Copilot Studio からエージェントを公開することを要求する代わりに、このオプションを選択します。
エージェントをアップロードするには、エージェントを ZIP パケット ファイルに含める必要があります。 ZIP ファイルには、マニフェスト ファイル、構成ファイル、アイコン、ブランド化、埋め込みナレッジ ファイルなどのリソースが含まれています。
Copilot エージェントの ZIP ファイルは、[エージェント>エージェントの名前>チャネル] を選択することで、Copilot Studio からダウンロードできます。
Teams や Microsoft Copilot など、公開に使用するチャネルを選択します。 [ 可用性オプション>ダウンロード .zip] を選択します。
注:
ZIP パケット ファイル (.zip) を使用してエージェントを共有することもできます。 詳細については、「 個人使用のためのエージェントのサイドロード」を参照してください。
エージェントを ZIP パケット ファイルとして Microsoft 365 管理センターにアップロードするには:
ブラウザーで Microsoft 365 管理センター で Copilot コントロールを開きます。
[エージェント]>すべてのエージェント>カスタム エージェントのアップロード] を選択します。
[ ファイルの選択 ] を選択して、エージェントの ZIP ファイルを検索して選択します。
ZIP ファイルが検証されます。
エージェントの名前、アイコン、およびホスト製品を確認します。 さらに [次へ] を選択します。
割り当てられているユーザーを選択します。 さらに [次へ] を選択します。
注:
テスト目的で少人数のオーディエンスを選択できます。 たとえば、[ 自分だけ] を選択するか、単一のテスト グループを選択して、エージェントの可用性を絞り込みます。
エージェントのアクセス許可と機能を確認します。 さらに [次へ] を選択します。
[デプロイの完了] を選択して、エージェントのデプロイを確認して終了します。
エージェントを管理、割り当て、および公開するには、「 エージェントの割り当てと展開」を参照してください。
エージェントの割り当てと展開
管理者は、アクションを使用して、テナントで利用可能な各エージェントのライフサイクルを管理できます。 これらのエージェント アクションには、発行、展開、削除、ブロックが含まれます。 さらに、エージェントの割り当てとエージェントの展開を個別のアクションとして行うことができます。 また、組織のメンバーが組織カタログへの公開を要求するエージェントを管理することもできます。
✅
タスク: Microsoft 365 管理センターで組織のエージェントを管理します。具体的には、組織内のユーザーとグループに対して個々のエージェントを 公開、 展開、 削除、 またはブロック します。エージェントの詳細と機能に基づいて、エージェント アクセスを過剰共有する可能性を考慮してください。
エージェントのインストールについて
Microsoft がプレインストールしている特定の Copilot エージェントがありますが、ほとんどのエージェントは組織のメンバー、または適切な権限を持つ管理者がインストールできます。
Microsoft がインストールしたエージェント
リサーチ ツールやアナリストなどの特定の Microsoft エージェントは、Microsoft Copilot 内でプレインストールされ、右側のライトにピン留めされています。
固定されたエージェントにより 、それらのエージェントは、組織のメンバーがそれらのエージェントを表示およびアクセスできるようになります。 さらに、Microsoft 365 管理センターの Copilot コントロールを使用して、これらのエージェントの 管理、 割り当て、 展開 方法を決定することができます。 関連情報については、「 Microsoft がインストールしたエージェントと機能」を参照してください。
管理者がインストールしたエージェント
管理者は、組織で利用可能にするエージェントのライフサイクルを管理します。 Microsoft 365 管理センターの Copilot コントロールを使用してエージェントをインストールできます。 カスタム エージェントをアップロードしたり、既存のエージェントを割り当てたり、エージェントをデプロイしたりすることもできます。 また、組織で不要なエージェントを削除してブロックすることで、過剰共有を防ぐこともできます。 関連情報については、「 管理者がインストールしたエージェント」を参照してください。
ユーザーがインストールしたエージェント
組織のメンバーは、 エージェント ストアからエージェントをインストールできます。 ツールと機能を使用すれば、Copilot Studio、Agent Builder、SharePoint を使用してエージェントを作成することもできます。 関連情報については、「 ユーザーがインストールしたエージェント」および 「エージェントの共有と公開の設定」を参照してください。
エージェントを発行する
組織のメンバーは、Copilot Studio を使用してエージェントを作成および発行できます。 ライブ Web サイト、モバイル アプリ、Microsoft Copilot、Teams や Facebook などのメッセージング プラットフォームなど、複数のチャネルにエージェントを公開できます。
✅
タスク: 組織のメンバーが Copilot Studio を使用してエージェントを作成した場合は、あなたの助けを借りて組織にエージェントを公開できます。Microsoft 365 管理センターの Copilot コントロールで要求されたエージェントを確認します。エージェントを公開するか、組織で使用できないように拒否します。
組織のメンバーが Microsoft Teams と Microsoft Copilot チャネルを使用して組織にエージェントを発行すると、そのエージェントは Microsoft 365 管理センターの Copilot コントロールで要求されたエージェントとして利用できるようになります。 その後、エージェントを承認して、組織内のユーザーまたはグループがエージェントを使用できるようにします。 エージェントを確認して発行したら、Teams アプリ ストアに表示して、ユーザーが検索してインストールできるようにします。
詳細については、「Teams と Microsoft 365 のエージェントを接続して構成する」、「要求されたエージェントを管理する」、「エージェントを発行する」を参照してください。
利用可能なエージェントを確認する
エージェントはエージェント インベントリにリストされます。 エージェント インベントリでは、各エージェントに関するさまざまな詳細を表示できます。 たとえば、エージェントの可用性の表示、組織内でエージェントがサポートされているアプリの表示、エージェントの発行元の表示などを行うことができます。 エージェント リストから個々のエージェントを選択すると、追加の詳細を表示および設定できます。 詳細については、「 エージェント インベントリ」を参照してください。
✅
タスク: エージェントが呼び出すことができる機能、データ ソース、およびカスタム アクションを確認します。
個々のエージェントに関する詳細を表示するには:
ブラウザーで Microsoft 365 管理センター 内で Copilot コントロールを開きます。
[エージェント>すべてのエージェント] を選択します。
[ エージェント インベントリ ] タブが選択されていることがわかります。
一覧からエージェントを選択します。
事前にエージェントの詳細、セキュリティ、コンプライアンスを確認して、エージェントを組織内のユーザーに割り当てる必要があるか、組織内のユーザーが利用できるようにする必要があるかどうかを判断します。
a. [ データ & ツール ] タブを選択して、[ 機能]、[ ナレッジ]、[ アクション] を確認します。
b. [ セキュリティ & コンプライアンス ] タブを選択して、エージェントの全体的な認定を確認します。
エージェントを割り当てる
個々のエージェントを組織内のユーザーとグループに割り当てたり、割り当て解除したりできます。 ただし、エージェントを割り当てる前に、使用可能なユーザーとグループがテナント内で利用可能である必要があります。
組織のメンバーにエージェントを割り当てるには、次の 2 つの異なるアクションがあります。
使用できる対象: エージェントを検索してインストールできる組織のメンバーを選択できます。
展開先: 組織のメンバーまたは自分だけにエージェントを展開できます。
注:
エージェントをユーザーまたはグループに割り当てる前に、エージェントの機能、知識、およびアクションを確認します。 また、エージェントのセキュリティとコンプライアンスも考慮してください。 詳細については、「 利用可能なエージェントの確認」を参照してください。
✅
タスク: Microsoft 365 管理センターで組織の個人およびグループの割り当てに基づいてエージェント アクセスを制御します。エージェントの詳細と機能に基づいて、組織内での過剰共有の可能性を防ぐために必要のないエージェント アクセスを検討します。
個々のエージェントに関する詳細を表示するには:
ブラウザーで Microsoft 365 管理センター 内で Copilot コントロールを開きます。
[エージェント>すべてのエージェント] を選択します。
[ エージェント インベントリ ] タブが選択されていることがわかります。
一覧からエージェントを選択します。
[ ユーザー ] タブを選択し、[ 割り当て先] を選択します。
次のいずれかのオプションに基づいてエージェントの割り当てを選択します: a. 私だけ b. 組織全体 c. 特定のユーザーまたはグループ
[ 使用可能] を選択して、組織内の誰がエージェントをインストールできるかを確認します。
[更新] を選択します。
割り当てられたユーザーは、エージェントを見つけてインストールできるようになります。
エージェントの展開
個々のエージェントを選択して、組織のメンバーに展開できます。
エージェントをデプロイすると、ユーザーの Microsoft Entra アクセス許可を受け入れることで、ユーザーに代わってエージェントを効果的にインストールします。 このアクションにより、エージェントがアクティブになり、選択したユーザーまたはグループで使用できるようになります。
✅
タスク: ユーザーがエージェントを自分でインストールできるようにするのではなく、組織のメンバーにエージェントをデプロイしてインストールします。
個々のエージェントをデプロイするには、次の手順に従います。
ブラウザーで Microsoft 365 管理センター内で Copilot コントロールを開きます。
[エージェント>すべてのエージェント] を選択します。
[ エージェント インベントリ ] タブが選択されていることがわかります。
一覧からエージェントを選択します。
[展開] を選択します。
エージェント ホスト製品を確認し、[ 次へ] を選択します。
ユーザーを割り当てる
次のいずれかのオプションに基づいてエージェントの割り当てを選択します: a. 私だけ b. 組織全体 c. 特定のユーザーまたはグループ [ 次へ] を選択します。
エージェントのアクセス許可と機能を確認し、[ 次へ] を選択します。
デプロイを確認し、[ デプロイの完了] を選択します。
デプロイが完了したら、[ 完了] を選択します。
エージェントの削除
組織のインベントリからエージェントを削除できます。 このアクションは、ファーストパーティまたは外部エージェントにのみ適用されます。 エージェントは、ストアから取得することでインベントリに再追加できます。
エージェントを削除すると、Copilot や、Teams や Outlook などの他のホスト製品では使用できなくなります。 詳細については、「 エージェントの削除」を参照してください。
ブロック エージェント
エージェントをブロックすると、テナント内のすべてのユーザーがエージェントにアクセスできなくなります。 このアクションにより、組織内の誰もエージェントを使用できなくなります。 詳細については、「 エージェントのブロックまたはブロック解除」を参照してください。
要求されたエージェントを管理する
組織では、Copilot Studio を使用して、より高度なエージェントを作成できます。 これらのエージェントは、Microsoft Copilot や Microsoft Teams など、組織内のさまざまなチャネルに公開できます。 エージェントが Copilot Studio から発行されると、そのエージェントは Microsoft 365 管理センターの [要求されたエージェント] タブに表示されます。
✅
タスク: 組織によって作成された要求されたエージェントと、Microsoft 365 管理センターで各エージェントのメタデータを確認します。
エージェントが管理者の承認のために送信されると、エージェントの定義に関するすべてのメタデータが Microsoft 365 管理センターで提供されます。 エージェントの [詳細] タブを選択して、エージェントの機能、データ ソース、およびカスタム アクションをよりよく理解してから、エージェントを組織に公開できるようにします。
保留中のエージェント要求を表示し、それらの要求を処理するには、次の手順を使用します。
ブラウザーで Microsoft 365 管理センター で Copilot コントロールを開きます。
[ エージェント>すべてのエージェント>リクエスト] を選択します。
要求されたエージェントを選択し、エージェントの詳細を表示します。
エージェントが呼び出すことができる機能、データ ソース、カスタム アクションを確認します。
エージェントの名前の横にあるアクションを選択して、エージェントを 発行 または 拒否 します。
要求されたエージェントの公開の詳細については、「 エージェントの公開」を参照してください。
エージェントのセキュリティ、プライバシー、コンプライアンスについて
Microsoft は、企業のセキュリティ、プライバシー、コンプライアンス標準に基づいて、多層的な多層防御戦略を適用して、あらゆるレベルで Microsoft Copilot をセキュリティで保護します。 この基盤の各側面は、あなたとあなたの組織が自信を持って AI の機能とツールを採用するための、より安全なデジタル エコシステムを形成します。
