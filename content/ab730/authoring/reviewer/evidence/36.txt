Microsoft 365 Copilot (プレミアム) は、完全なアドオン ライセンス エクスペリエンスであり、Microsoft 365 Copilot (基本) のすべてと次の機能が含まれます。
パフォーマンスと可用性を向上するための優先アクセス。 優先アクセスは、ピーク使用期間でも、より迅速な応答時間とより一貫した可用性を提供します。
Microsoft 365 アプリおよびサービスとの緊密な統合と高度な AI 機能。
Microsoft Graph、Work IQ、Copilot 検索、セマンティック インデックス作成を通じて、組織データ (メール、ファイル、会議、予定表、チーム、または組織関係) に基づいた応答。
Microsoft Graph は、ユーザーのメール、ファイル、会議、予定表、チーム、組織関係からの情報など、パーソナライズされた組織データ コンテキストをプロンプトに取り込みます。
Work IQ は、エージェントが組織のデータ、コンテンツ、ツールを推論できるようにするインテリジェンス層です。
Work IQ のオンとオフを切り替えることができます。
Work IQ が オンの場合、Copilot の応答は Web、 Microsoft Graph 、 および Work IQ に基づいています。 応答には、メール、ファイル、会議、予定表、チーム、組織関係など、仕事固有のコンテキストが充実しています。
Work IQ が オフの場合、Copilot の応答は Microsoft Graph と Work IQ に基づいていません。 ユーザーは引き続き応答を受け取ることができますが、それらの応答は、メール、ファイル、会議、予定表、チーム、組織関係など、仕事固有のコンテキストで強化されません。
どちらも Work IQ プラットフォームを使用していますが、Work IQ は Microsoft 365 Copilot (Premium) に含まれていますが、Work IQ API は、カスタム アプリ、エージェント、統合用に個別に購入および使用できる、独自の使用量ベースの課金サービスです。
Copilot 検索 は、すべての Microsoft 365 アプリケーションと接続されている Microsoft 以外のデータ ソースにわたる AI を活用したユニバーサル検索エクスペリエンスです。 これは Microsoft Copilot と統合されているため、ユーザーは検索を使用して必要な結果を見つけ、チャットにシームレスに移行してより深い調査やフォローアップ タスクの完了を行うことができます。
セマンティック インデックス作成 は、Microsoft Graph データの高度な語彙的およびセマンティック理解を利用することで検索の関連性と精度を高め、より文脈的に正確な情報取得を実現します。 Copilot は、セキュリティ、コンプライアンス、プライバシーを維持し、シームレスなユーザー エクスペリエンスを提供しながら組織の境界が尊重されるようにします。
SharePoint 高度な管理 (SAM): 過剰共有を減らし、非アクティブなサイトをクリーンアップするのに役立ちます。 これらのタスクにより、Copilot のデータ ソースが整理され、応答の品質が向上します。
制限付きコンテンツの検出: レビューが行われている間、organization全体の検索結果や Microsoft Copilot の応答で、最近操作したファイルを含む特定の SharePoint サイトからのコンテンツの検出を制限するのに役立ちます。
Microsoft Purview: コンテンツの秘密度に基づいてデータを分類し、ラベル付けできます。 また、不正な共有や漏洩を防止し、Copilot のプロンプトと応答を確認するのにも役立ちます。
Microsoft エージェント: エージェントは、AI アシスタントとして機能し、ビジネス プロセスを自動化できる Microsoft Copilot のスコープ付きまたはフォーカスされたバージョンです。 これらのエージェントは、Web と作業のデータ (Microsoft Graph および Work IQ) を使用します。
使用状況レポート: ユーザーが Copilot とどのように関わっているかを理解するのに役立ち、時間の経過と共に Microsoft 365 アプリでの導入を追跡するのに役立ちます。
組織のメッセージ機能を使用して、確認されている導入傾向に対処します。 この機能を使用すると、ターゲットを絞った実用的なガイダンスとともに、日常業務の流れの中でユーザーにリーチできます。
Microsoft Copilot Cowork: 使用量ベースの課金でCoworkにアクセスできます。 Cowork は、ユーザーに代わって Microsoft 365 環境全体でタスクを実行します。

Web データに基づいた応答
Copilot Chat (基本) と Microsoft 365 Copilot (基本) の応答は、パブリック Web からのデータに基づいています。 Copilot Chat (基本) と Microsoft 365 Copilot (基本) は、Copilot Chat と対話するときに Microsoft Graph 経由で組織データを使用できません。 プロンプトを使用してコンテンツをアップロードするか、オープン コンテンツ (Teams と Outlook) を操作するか、組織データにアクセスできる従量課金制エージェントを使用する必要があります。
Microsoft 365 Copilot (Premium) は、Microsoft Graph と Work IQ を介して Web データと組織データの両方を使用し、情報を自動的にプルします。 フォーカスするファイルを指定できますが、手動でアップロードする必要はありません。
組織データに基づいた対応
Copilot Chat (Basic) と Microsoft 365 Copilot (Basic) ユーザーは、手動で直接ファイルをアップロードするか、組織のコンテンツにアクセスできる従量課金制エージェントを使用して、プロンプトの一部として組織のコンテンツを提供できます。 ただし、Copilot Chat (Basic) および Microsoft 365 Copilot (Basic) のユーザーは Microsoft Graph にアクセスできません。 詳細については、「組織データと Copilot Chat」を参照してください。
Microsoft 365 Copilot (Premium) は、Microsoft Graph を介して Web データと組織データの両方を使用し、情報を自動的にプルします。 フォーカスするファイルを指定できますが、手動でアップロードする必要はありません。
欧州連合データ境界 (EUDB)
Copilot Chat (Basic)、Microsoft 365 Copilot (Basic)、Microsoft 365 Copilot (Premium) は、LLM への呼び出しをリージョン内の最も近いデータ センターにルーティングしますが、使用率が特に高い場合は、より大きな容量を使用できる他のリージョンに呼び出すこともできます。 欧州連合 (EU) ユーザーの場合、Microsoft Copilot には EU データ境界に準拠するための追加の安全対策があります。 EU のトラフィックは EU データ境界内にとどまりますが、世界中のトラフィックは LLM 処理のために EU やその他の国や地域に送信できます。
責任ある AI
Microsoft Copilot は、Microsoft の責任ある AI 原則に従います。 詳細については、「Microsoft Copilot の責任ある AI に関する FAQ」、および「Microsoft の責任ある AI」を参照してください。
モデルの選択
Microsoft Copilot は、セキュリティ、コンプライアンス、プライバシーの設定を変更することなく、ビジネス ニーズに合わせた最新モデルを提供します。 UI のモデル セレクターを使用して、さまざまなモデルを選択できます。 既定では、Copilot はリアルタイム ルーターを使用して、プロンプトに基づいて使用する基になるモデルを調整します。

一般的または日常的な質問の場合、Copilot は速度を優先し、高スループット モデルを使用して、簡単な質問に対する迅速かつ簡潔な回答を作成します。
深く考える
複雑な質問や自由形式の質問の場合、Copilot はプロンプトに高度な推論が必要であると検出する場合があります。 このような場合、Copilot はより深い推論モデルを使用し、時間をかけて計画を作成し、関連するすべてのコンテキストを収集して理解し、徹底的な応答を提供する前にその作業をチェックします。
これらのオプションは、新しいモデルが利用可能になると更新されます。
Copilot コントロール
管理センターでは、Copilot コントロールを使用して、Copilot Chat (基本)、Microsoft 365 Copilot (基本)、Microsoft 365 Copilot (プレミアム) などのCopilot Chatエクスペリエンスを管理します。
Copilot コントロールでは、次のようなユーザーが Copilot および関連する AI エクスペリエンスと対話する方法を構成できます:
ライセンスに基づいて、Copilot Chat を Microsoft 365 アプリや他の Copilot サーフェスなど、エクスペリエンス間でピン留めするかどうかを制御します。
ユーザーが Copilot Chat で画像を生成できるかどうかを管理します。
ユーザーが エージェントを作成および使用する方法を制御します。 エージェントには、Microsoft 365 Copilot (Premium) ユーザー向けの機能と統合オプションが拡張されている場合があります。
[Copilot での Web 検索の許可] ポリシーを使用して Web 検索の基礎を管理します。 このポリシーは、すべてのライセンスにわたる Copilot Chat エクスペリエンスに適用されます。
Copilot Chat (Basic) ユーザーを含め、Copilot Chat へのユーザー アクセスを完全に削除します。
より広範なガバナンスのために、AI 管理者ロールを割り当てることができます。これにより、グローバル管理者のアクセス許可を必要とせずに、Copilot Chat (Basic)、Microsoft 365 Copilot (Basic)、Microsoft 365 Copilot (Premium) 全体で Copilot と AI 機能を管理するための最小限の特権アクセスが提供されます。
ユーザーをトレーニングする
次のリソースを指示することで、Copilot を使用して作業タスクを支援する方法をユーザーが理解できるようにします。
Copilot Chat (基本) トレーニング
Microsoft 365 Copilot (基本) トレーニング
Microsoft 365 Copilot (Premium) トレーニング
Microsoft Copilot Chat、仕事用の AI アシスタント: 作業を開始する方法、さまざまなプロンプトを使用する方法、Copilot Chat と他の Copilot オファリングの違いを理解する方法に関するガイダンス。
Microsoft Copilot Chat ビデオ チュートリアル: 開始方法と Copilot Chat で実行できるタスクに関する短くてわかりやすいビデオです。
Copilot を使用してアイデアを行動に変える: このコースでは、Microsoft Copilot の使用を開始し、効果的なプロンプトを作成し、AI 搭載機能を使用して生産性を高め、作業を効率化し、リアルタイムで安全に共同作業する方法を学習します。
Copilot プロンプト ギャラリー: ユーザーの作業に役立つプロンプトの例 (例: "変更管理についてより簡潔に説明するにはどうすればよいですか?")。
Copilot サクセス キット: これを使用して、Microsoft 365 Copilot (Premium) 用にテナントを準備し、ユーザーがエージェントを作成して使用できるようにします。 このキットには、管理コントロール、ライセンスと支払い方法、トレーニング資料、オンボーディング メール テンプレートなどの情報が含まれています。
Copilot トレーナー キット: 企業が Copilot Chat を使い始めるのに役立つダウンロード可能な PowerPoint トレーニング プレゼンテーションです。
Copilot ユーザー ツールとテンプレート: organization をすばやくオンボーディングするためのユーザー向けのツールとテンプレートのコレクション。
Copilot の導入状況を追跡して向上させる
Microsoft Copilot Chat使用状況レポートでは、ユーザーが Copilot Chat (すべてのライセンスに適用) および関連するチャットベースのエクスペリエンスにどのように関与しているかに関する分析情報が提供されるため、導入傾向を追跡し、時間の経過と共にアクティビティを迅速にするのに役立ちます。 このレポートには、7、30、90、または 180 日間のビューにわたる、アクティブ ユーザーの合計数と毎日のアクティブ ユーザー数、送信されたプロンプトの合計数、ユーザーあたりの平均プロンプト数、匿名化されたユーザーごとのエンゲージメントの詳細 (たとえば、最後のアクティビティ日、アクティブな日数) などのメトリックが含まれます。
対照的に、Microsoft Copilot 使用状況レポートは、Teams、Outlook、Word、Excel、PowerPoint などの Microsoft 365 アプリ内での Microsoft Copilot の使用状況に焦点を当てています (Microsoft 365 (Basic) または Microsoft 365 Copilot (Premium) ライセンスが必要)。 Microsoft Copilot 使用状況レポートを使用して、ライセンスされた Copilot 機能がアプリ内でどのように使用されているかを理解するには、このレポートは、ワークロード全体で統合された Copilot 採用のより広範なビューを提供することで、Copilot Chat 使用状況レポートを補完します。
これらのレポートを組み合わせることで、スタンドアロンのチャット エンゲージメント (Copilot Chat (Basic)) と、アプリに統合されたより深い Copilot の使用状況 (Microsoft 365 (Basic) と (Premium)) を区別し、両方のエクスペリエンスで導入を促進する機会を特定できます。
組織のメッセージ機能を使用してレポートの分析情報に基づいて行動し、ターゲットを絞ったコンテキスト ガイダンスをユーザーのワークフロー内で直接提供して、認識と効果的な使用を高めます。
その他の Copilot 製品
次の Copilot 製品は個別にライセンスされており、Microsoft 365 Copilot (Premium) ライセンスは必要ありません。 組織は、特定のニーズ、対象ユーザー、ユースケースに基づいて各オファリングを購入して使用できます。
Microsoft Security Copilot: インシデント対応、脅威の捜索、インテリジェンス収集、ポスチャ管理などについてセキュリティ担当者を支援します。
GitHub Copilot: は、コードをより高速に記述するのに役立つ AI コーディング アシスタントです。 この Copilot は、職場の organization によってライセンスされています。
Microsoft Copilot Studio: は、エージェントの作成や他のデータ ソースへの接続に使用できるローコードのグラフィカル ツールです。 エージェントを使用すると、organization の Copilot エクスペリエンスをカスタマイズできます。 ヘルプ デスク、変更管理、会議でのゲストの管理など、ビジネス プロセスを自動化して実行できます。
その他の Microsoft Copilot 製品については、Microsoft Copilot ラーニング ハブを参照してください。
