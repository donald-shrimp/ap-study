エージェント ビルダーと Copilot Studio のどちらかを選択してエージェントを構築します
フィードバック
Agent Builder と Copilot Studio は、Microsoft 365 や基幹業務システム全体で動作する、安全でスケーラブルでインテリジェントなエージェントを構築するための強力なツールです。 どちらのツールでもエージェントを作成できますが、異なるニーズに対応します。 この記事では、シナリオに最適な方法を選択できるように、2 つの違いについて説明します。
使用するツールを選択するときは、次の要素を考慮してください。
対象ユーザー – エージェントを使用するのは誰ですか?
展開スコープ – エージェントをどのくらい広範囲に共有する予定ですか?
機能 – エージェントが実行するタスク
ガバナンスのニーズ – エージェントにきめ細かなアプリケーション ライフサイクル管理が必要ですか?
次のデシジョン ツリーは、シナリオを適切なツールにマップするのに役立ちます。
まとめると、以下のようになります。
自然言語と既存のコンテンツ (たとえば、チームの SharePoint ファイルや電子メールからの質問に回答するボットなど) を使用して、自分または小規模チームのエージェントをすばやく作成する場合は、[エージェント ビルダー] を選択します。 Agent Builder はシンプルでアクセスしやすく、Microsoft 365 Copilot エクスペリエンスと統合されているため、コードなしでコンテキスト内でエージェントを構築できます。
より幅広い対象ユーザー (部門全体、organization、外部の顧客など) 向けのエージェントが必要な場合、エージェントにマルチステップ ワークフローやカスタム統合などの高度な機能が必要な場合、またはデプロイと管理をより細かく制御する必要がある場合は、Copilot Studio を選択してください。 Copilot Studio の通常版は、複雑またはスケーラブルなソリューション用の豊富なツール セットを備えたスタンドアロンの Web ポータルです。
注:
エージェント ビルダーでエージェントを作成し、後で Copilot Studio で利用可能な機能を利用する場合は、エージェントを Copilot Studio にコピーできます。

ユース ケース
エージェント ビルダーを使用して、以下をビルドします。プロジェクト ドキュメントに基づいて一般的な質問に回答するプロジェクト FAQ ボット。従業員が社内の製品マニュアルや Wiki から情報を見つけるのに役立つ製品ドキュメント アシスタント。新しいチーム メンバーが内部ナレッジ ベースから回答を得るのに役立つオンボーディング エージェント。
Copilot Studio を使用して以下を構築します。サポート チケットを作成し、問題を人間にエスカレートするカスタマー サポート エージェント。IT ヘルプ デスクは、従業員の IT 要求を処理し、適切なサポート チームにルーティングするトリアージ エージェントです。営業データを取得したり、メモを作成したり、承認ワークフローを開始したりする CRM の営業アシスタント。
管理とガバナンス
主に Microsoft 365 管理センターを通じて管理されます。
エンタープライズ シナリオ向けのきめ細かな制御を備えた Power Platform 管理センターを通じて管理されます。
エージェント ビルダーから Copilot Studio にエージェントをコピーする
高度な機能や広範な統合オプションが必要な場合は、エージェント ビルダーで作成したエージェントを Copilot Studio にコピーできます。 このプロセスにより、Agent Builder で行われた作業が失われることはなく、最初からやり直すことなく Copilot Studio で拡張できます。
Copilot Studio に移行すると、豊富なカスタマイズ、ガバナンス制御、拡張されたコネクタなどの追加機能が利用可能になります。 エージェントをコピーしても、エージェントのコア構成と命令は保持され、Copilot Studio でのみ使用できる詳細設定でそれらを強化できます。
次のような場合は、エージェントを Copilot Studio にコピーすることを検討してください。
エンタープライズ レベルの展開オプションが必要です。
より多くのデータ ソースと統合するか、高度なセキュリティ ポリシーを適用したい場合。
詳細については、「エージェント ビルダーから Copilot Studio にエージェントをコピーする」を参照してください。
ライセンスの要件
Agent Builder と Copilot Studio はどちらも、認証されたユーザー向けの Microsoft 365 Copilot アドオン ライセンスに含まれています。 Copilot ライセンスをお持ちでない場合は、Copilot クレジットまたは従量課金制プランを使用して、いずれかのエクスペリエンスにアクセスできます。
また、エージェントビルダーを無料で使用して、Web知識のみに基づいたエージェントを構築することもできます。 詳細については、「Microsoft 365 Copilot Chat でのエージェントの使用」を参照してください。
エージェント ビルダーのガバナンスの原則
エージェントビルダーを使用すると、ユーザーは、繰り返し可能なプロンプトとコンテンツ接続をパッケージ化するエージェントを作成できます。 これらのエージェントは、Microsoft Graph から分析情報を取得するのに役立ちます。 これらは既存のエンタープライズ境界内で動作し、Microsoft 365 のコントロールを尊重します。
エージェントビルダーは、次の主要なガバナンス原則を適用します。
新しい権限はありません - エージェントは既存の Microsoft 365 アクセス許可を尊重します。 ユーザーが SharePoint サイト、Teams チャネル、または Outlook メールボックスにアクセスできない場合、エージェントはこれらのソースからのコンテンツを表示しません。
組み込みの可視性と監査機能 - エージェントは Microsoft 365 内に表示されます。 Standard の監査ログ、アクティビティ レポート、DLP/保持ポリシーが適用されます。
IT 管理者は、[Copilot>Agents] ページを使用して、エージェントの表示、共有、ライフサイクル ポリシーを Microsoft 365 管理センター で管理します。 管理者は次のことができます。
エージェント インベントリとエージェント メタデータを表示します。
エージェントを有効、無効、割り当て、ブロック、または削除して、組織のポリシーに合わせて実行します。
従量課金を構成し、エージェントの使用状況と使用量を確認します。
Microsoft Purview (秘密度ラベル、監査ログ) を使用してコンプライアンスを実施します。
管理者は、Microsoft 365 管理 センター>Copilot>設定>データ アクセス>エージェント ページでエージェント共有制御を管理することもできます。 詳細については、「 エージェントの共有」を参照してください。
エージェントを共有するときにガバナンス制御がプライバシーを確保する方法の詳細については、「 プラグイン共有のガバナンスと管理制御」を参照してください。
Copilot Studio ガバナンスの原則
Copilot Studio では、多くの場合、メーカーまたは開発者による、より高度なエージェントの作成がサポートされています。 これらのエージェントは、外部データ ソースの統合、API の呼び出し、複雑なワークフローの調整、Microsoft 365 以外のシステムへの接続が可能で、部門または企業全体のソリューションに最適です。
Copilot Studio には、次の主要なガバナンス原則が適用されます:
構造化開発 - アプリケーション ライフサイクル管理 (ALM) を使用すると、開発環境、テスト環境、運用環境全体での開発が可能になります。
コネクタのガバナンス - 管理者はエージェントが接続できるシステムを制御し、不正アクセスのリスクを軽減します。
環境レベルのポリシー - データ損失防止 (DLP)、ロールベースのアクセス、監査は、環境レベルで適用されます。
柔軟なデプロイ - きめ細かなアクセス制御を使用して、Teams、Web サイト、カスタム エンドポイントにエージェントを公開できます。
安全なコラボレーション - エージェントは、監視を備えた部門横断的なチームワークの表示/編集権限をサポートします。
開発と公開の監視 - organization のアプリ カタログに公開するには管理者の承認が必要であり、広く利用できるものの可視性と制御が確保されます。
IT 管理者は、Power Platform 管理センターを使用して以下を管理します。
エージェント環境とコネクタ。
ライフサイクル ポリシーと公開ワークフロー。
Microsoft Purview によるコンプライアンス (秘密度ラベル、監査ログ、保持)。
テレメトリと使用状況の分析を使用して、エージェントの動作を監視し、ポリシーの整合性を確保します。
エージェントを共有するときにガバナンス制御がプライバシーを確保する方法の詳細については、「 プラグイン共有のガバナンスと管理制御」を参照してください。 Copilot Studio 固有のセキュリティの詳細については、「Copilot Studio のセキュリティとガバナンス」を参照してください。
