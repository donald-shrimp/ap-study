コード インタープリター機能をエージェントに追加する
フィードバック
コード インタープリター機能を追加することで、Microsoft 365 Copilot の宣言型エージェントのユーザー エクスペリエンスを向上させることができます。 マニフェストリファレンスの機能要素とエージェントビルダーの機能セクションには、ユーザーの機能をロック解除するためのいくつかのオプションがあります。
コード インタープリターは、Python コードを介して複雑なタスクを解決するように設計された高度なツールです。 推論モデルを使用してコードを記述および実行し、ユーザーが複雑な数学の問題を解決したり、データ分析をしたり、視覚化を生成したりできるようにします。 コードの実行後、コード インタープリターは結果と生成された関連コードを出力します。 また、シナリオに基づいてダウンロード可能な画像やファイルを生成し、変更や分析のための入力としてファイルを受け入れることもできます。
コード インタープリター機能は、Microsoft 365 Copilot ライセンスを持つユーザーと、従量制課金が有効になっていない Copilot Chat ユーザーが利用できます。
注:
コードインタプリタは、コンテキスト内エージェントに対してデフォルトで有効になっています。 この設定を変更するには、次のスクリーンショットに示すように、[設定] アイコンを選択し、必要に応じて [コード インタープリター] 設定を更新します。
Microsoft 365 エージェント ツールキットでコード インタープリターを有効にする
Agents Toolkit と Visual Studio Code を使用してエージェントを作成し、コード インタープリターを有効にする場合は、次の例に示すように、マニフェスト ファイルの capabilities プロパティに CodeInterpreter 値を追加します。
注:
CodeInterpreter 機能を追加するには、宣言型エージェント マニフェスト スキーマのバージョン 1.2 以降を使用する必要があります。
{
"capabilities": [
{
"name": "CodeInterpreter"
}
]
}
エージェント ビルダーでコード インタープリターを有効にする
Agent Builder では、コード インタープリタが常に有効になっています。 この機能は、すべてのエージェントに自動的に含まれています。
コード インタープリター機能の例
コード インタープリター機能は推論モデルを使用して、宣言型エージェントがサンドボックス環境で Python コードを作成および実行できるようにします。 この機能により、ユーザーは複雑な数学の問題を解決したり、データを分析したり、視覚化を生成したりできます。 コードの実行後、コード インタープリターは結果と生成されたコードを出力します。 また、シナリオに基づいてダウンロード可能な画像やその他のファイルを生成し、変更や分析のための入力としてファイルを受け入れることもできます。
コード インタープリターは、次の機能を提供します。
データのグラフ化
データ QR コードとデータの視覚化
合成データを含むファイルの作成
複雑な数学の問題の解決
アップロードされた画像の変更
ダウンロード可能なファイルの生成
Copilot は、これらのタスク実行時に生成されるコードのコピー可能およびダウンロード可能なバージョンも提供できます。
グラフとチャートを作成する
ユーザーは、コード インタープリターが有効になっているエージェントを使用してグラフやチャートを作成できます。 たとえば、「フィボナッチ シーケンスの最初の 20 個の数値をグラフ化してください」というプロンプト応答して、Copilot は次の折れ線グラフを生成します。
ユーザーが </> Code ボタンを選択すると、エージェントは対応する Python コードを提供します。
ユーザーはデータ ファイルをアップロードしてグラフやチャートを生成し、データを視覚化することもできます。 サポートされているファイル形式は、Word、Excel、PowerPoint、PDF、CSV/TSV、TXT/UTF8 です。 たとえば、ユーザーが売上データを含む Excel ファイルをアップロードし、「アップロードした売上データの縦棒グラフと折れ線グラフを作成してください」というプロンプトを入力すると、エージェントは次の応答を返します。
QR コードとデータ視覚化を作成する
コード インタープリターを有効にすると、ユーザーは QR コードやワード クラウドなど多様なデータ視覚化を作成できます。 たとえば、「Microsoft の企業 Web サイトの QR コードを作成してください」というユーザーのプロンプトに応答して、エージェントは対応する URL と一致する QR コードの両方を提示します。
ワード クラウドの場合、「人気のペット名のワード クラウドを作成してください」というプロンプトで、最も一般的な名前を含む画像が生成されます。
合成データを作成する
ユーザーが操作用のサンプルデータを必要とする場合、コード インタープリターを統合することで、さまざまな目的に応じた合成データを作成できるようになります。 エージェントは、要求されたサンプル データを生成し、Word、Excel、PowerPoint、または PDF ファイルとして出力できます。 ユーザーは、生成されたファイルをエージェントの応答から直接ダウンロードできます。 プロンプトと応答の例を次に示します。
プロンプト:日付、金額、店舗、カテゴリを含む 10 件の架空の金融取引の表を作成してください。
プロンプト:請求の問題に関する 20 件の合成カスタマー サポートのチャット トランスクリプトを生成してください。
複雑な数学の問題を解決する
エージェントにコード インタープリターを追加すると、次の例に示すように、ユーザーはエージェントに複雑な数学の問題を解決するように指示することができます。
プロンプト:関数 ( f(x) = x^3 - 4x^2 + 6x - 2 ) の ( x = 0 ) から ( x = 3 ) までの曲線下の面積の積分を求めてください。
アップロードされた画像を変更する
コード インタープリターを統合すると、ユーザーはアップロードした画像を変更することもできます。 この機能を持つエージェントは、画像にバナーやキャプションを追加したり、カラー画像の白黒版を生成したりできます。 (次の画像は Copilot によって生成されました。)
この画像を編集するには、ユーザーは「添付画像の白黒バージョンをください。"1934 ベントレー 4" と書かれたバナーと "Copilot によって生成された画像" というキャプションを追加してください」というプロンプトを入力します。エージェントは次の結果を返します。
ダウンロード可能なファイルを生成する
コード インタープリタは、ダウンロード可能なファイルを生成してホストできるため、エージェントはユーザーがエージェントが生成したファイルをダウンロードできるようにします。 コード インタープリターが出力ファイル (画像、グラフ、スプレッドシート、ドキュメントなど) を生成すると、Copilot は応答にダウンロード リンクを自動的に提示します。 ユーザーは、リンクを選択してファイルをローカルに保存できます。
この機能は、次のような多くのシナリオで役立ちます。
データのエクスポート: 計算されたデータまたは分析結果の Excel スプレッドシートを生成し、ダウンロードとして提供します。
レポート: 結果を要約した書式設定された PDF または Word ドキュメントを作成し、ダウンロードできるようにします。
生成されたビジュアル: ダウンロード可能な画像ファイルとして、グラフ、QR コード、ワード クラウドを生成します。
処理されたファイル: アップロードされた画像またはドキュメントに変更を適用し、結果をダウンロード可能なファイルとして返します。
次のプロンプトの例は、ファイル生成と自動ダウンロード リンク作成をトリガーします。
プロンプト:1から10までの九九表を含むスプレッドシートを作成し、Excelファイルを提供します。
エージェントは Excel ファイルを生成し、応答にダウンロード リンクを表示します。
注:
コードインタプリタによって生成されたFilesは一時的にホストされ、アクティブなセッション中にのみダウンロードできます。 セッションが終了した後、Files は保持されません。
