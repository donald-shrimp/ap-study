Microsoft 365 と Microsoft Copilot でデータを保護し監査する方法
適用対象: ✅ Microsoft Copilot
フィードバック
Microsoft Copilot は Microsoft 365 サービス境界内で動作し、Microsoft 365 全体に適用されるのと同じデータ保護、アクセス制御、コンプライアンス機能を尊重します。
この記事では、Microsoft Copilot のデータ保護アーキテクチャについて説明します。 Copilot が Microsoft Purview の秘密度ラベルと暗号化とどのように連携するか、SharePoint と OneDrive のアクセス制御が Copilot に与える影響、監査とコンプライアンスのシナリオで Copilot の対話データが保存される場所について説明します。
この記事は、Copilot を通過するデータの流れと、既存の Microsoft 365 保護がどのように適用されるかを理解したい IT 管理者を対象としています。 デプロイ手順や修復ガイダンスは提供されません。

Microsoft Copilot が秘密度ラベルと暗号化とどのように連携するか
Copilot は、Microsoft Purview の秘密度ラベルと暗号化と連携して、グラウンディングおよびコンテンツの生成中にアクセス制御と保護設定を適用します。
このフローの場合:
Copilot は、ユーザーがアクセスを許可されているコンテンツのみを要約または参照できます。
暗号化が適用される場合、Copilot がコンテンツを操作するには、ユーザーに EXTRACT および VIEW の使用権限が必要です。
秘密度ラベルを付けずに Azure Rights Management によって暗号化されたアイテムには、Copilot がコンテンツを要約するために、ユーザーの EXTRACT または VIEW 使用権限が引き続き必要です。
Copilot Chat の対話では、返されたデータに対して秘密度ラベルを表示できます。 応答には、最も優先度の高いラベルが反映されます。
Copilot がラベル付けされたソースに基づいて新しいコンテンツを生成すると、サポートされている場合は、最も優先度の高い秘密度ラベルが継承されます。
ラベル付きファイルが Microsoft 365 テナントの外部に保存されている場合でも、保護設定は適用されたままです。
注:
ユーザー定義の秘密度ラベルのアクセス許可は、Copilot によるファイル コンテンツの抽出と操作をブロックする可能性があります。 たとえば、Copilot エージェントは、ユーザー定義の秘密度ラベルのアクセス許可を持つファイルを読み取ることはできません。

SharePoint と OneDrive のアクセス制御が Copilot に与える影響
SharePoint と OneDrive のアクセス制御は、ユーザーのアクセス許可を変更することなく、Copilot が検出および参照できる内容に影響します。
これらのコントロールには次が含まれます。
Copilot および organization 全体の検索に表示されるサイトを制限する検索と検出の設定。
コンテンツにアクセスできる範囲に影響を与える共有とメンバーシップの制御。
長期的な過剰共有のリスクを軽減するガバナンスとライフサイクル ポリシー。
秘密度ラベルと DLP 条件に基づいて Copilot アクセスを制限する情報保護ポリシー。
処方的な修復ガイダンスについては、「Secure & governed data foundation for Microsoft Copilot: A deployment blueprint」を参照してください。
Copilot の使用状況データの保存場所と監査方法
Copilot の対話データは Microsoft 365 サービス内に格納され、Microsoft Purview 機能を使用して検出、監査、保持できます。
Microsoft 365 は以下をキャプチャできます。
Copilot のプロンプト、応答、参照されるコンテンツの監査レコード。
電子情報開示およびコンプライアンス調査のための Copilot の対話式操作データ。
クラウド添付ファイルとアイテム保管ライブラリを使用して、参照されたファイルの保持バージョンを保持します。
OneDrive Copilot Chat フォルダーに保存されているユーザー アップロード ファイル。
ユーザー所有の SharePoint 埋め込みコンテナーに保存されている Copilot ページで作成されたコンテンツ。
保持と削除の動作は、構成された Microsoft Purview 保持ポリシーに従います。 詳細については、「 Copilot の保持について」を参照してください。
