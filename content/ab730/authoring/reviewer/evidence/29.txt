エージェント ビルダーでエージェントを構築する
フィードバック
Agent Builder は、自然言語を使用して宣言型エージェントをすばやく構築するために使用できる単純なインターフェイスを提供します。 この記事では、エージェント ビルダーを使用して Microsoft 365 Copilot 用のエージェントを構築する方法について説明します。
Microsoft 365 Copilot で新しいエージェントを選択すると、次のことができます:
自然言語を使用してエージェントを説明し、Copilot がそれを構築する (推奨)。
[ 構成 ] タブを使用してエージェントを手動で構成します。
テンプレートから始めて、特定のユース ケースのエージェントを作成します。
自然言語を使用してエージェントを説明する (推奨)
エージェント・ビルダーを使用すると、自然言語を使用してエージェントを作成できます。 会話形式で情報を提供すると、エージェントの名前、説明、および指示が自動的に更新され、動作が改善されます。 この方法:
自然言語によってユーザーの意図を理解します。
提案、ガイダンス、次善のプロンプトを提供します。
最適化されたエージェント命令を生成して、正確で高品質のエージェントを構築します。
自然言語を使用すると、時間を節約し、手動設定なしで効果的なエージェントを作成するのに役立ちます。 自然言語の記述に応じて、エージェント ビルダーは次のようにします。
エージェントを自動的に構成します。
改善点を提案して適用します。 例: "サマリーにメールの添付ファイルを含める"。 エージェントビルダーは、次のことを提案します。
未読メッセージの添付ファイルのみを表示する
添付ファイルをファイルの種類別に要約する
ナレッジ ソースを追加します。 例: "毎日のメールを要約し、添付ファイルを含めてください。"Agent Builder は、 マイ メールを ナレッジ ソースとして追加します。
機能を統合します。 たとえば、「このアウトラインから PowerPoint プレゼンテーションを作成してください」または「この Excel データを分析してグラフを生成してください」などです。コード インタープリターと画像ジェネレーター機能は自動的に利用可能です。
チャット ボックスでプラス記号 (+) を選択して、ナレッジ ソースを選択して追加または検索することもできます。
エージェントの記述とナレッジ ソースの追加が完了したら、[ 構成] タブで構成を表示します。このツールでは、次の項目が事前に設定されます。
名前
説明
手順 (ガイドライン、手順、エラー処理、例を含む)
ナレッジ ソース
推奨プロンプト
エージェントを作成したら、[試してみる] タブでテストします。自然言語を使用して引き続き絞り込むことができます。 提案されるプロンプトや意図を変更する場合は、自然言語で言うだけです。たとえば、「エージェントを更新して、メールではなく Teams チャットを要約してください。」
注:
自然言語エクスペリエンスは、Microsoft 365 言語を 使用可能な言語のいずれかに設定している場合にのみ使用できます。 優先言語で自然言語がサポートされていない場合は、 エージェントを手動で構成できます。
[構成] タブを使用してエージェントを手動で作成する
自然言語を使用せずに、Agent Builder にエージェントを構成させたい場合は、[ 構成] タブでエージェントの動作を手動で構成できます。
エージェントを手動で構成するには:
Microsoft 365 Copilot で、[新しいエージェント] を選択します。
[ 新しいエージェント] で、[ スキップして構成] を選択します。
エージェントビルダーで[ 構成 ]タブが開き、エージェントの名前、説明、指示、知識、および推奨されるプロンプトを指定できます。
次の表では、エージェントを構成するフィールドについて説明します。
フィールド
説明
名前
エージェントの名前。 わかりやすく、独自性のあるものを使用します。 文字数制限は 30 文字です。
Icon
AI を使用してアイコンを生成したり、アイコン ライブラリからアイコンを選択したり、画像を手動でアップロードしてエージェントを表し、独自の個性を付与したりできます。 エージェントのアイコンを更新するには、鉛筆アイコンを選択し、[ 生成]、[ 参照]、または [アップロード ] を選択して新しいアイコンを追加します。アイコンをアップロードする場合、アイコンの周囲に既定で余分なパディングが適用されるため、背景が透明な PNG ファイルが最適に機能します。サポートされるファイルの種類: PNGカラー アイコンの解像度の上限: 192 x 192 ピクセルファイル サイズの上限: 1 MB アイコンの詳細については、「 エージェント アイコンのデザイン」を参照してください。
Model
エージェントの既定の応答モードを指定できます。 ユーザーは、エージェントを使用する場合、いつでもこれを上書きできます。 詳細については、 デフォルトの応答モードの設定を参照してください。
説明
この説明は、大規模言語モデル (LLM) が特定のタスクまたは状況のエージェントを識別して使用するのに役立ちます。 できるだけ短く、正確に、そしてシンプルにしましょう。 また、ユーザーがエージェントを見つけたときにも表示されます。 文字制限は 1,000 文字です。
手順
Microsoft 365 Copilot の機能を拡張するために使用する LLM に対する具体的な手順。 エージェントのタスクや完了方法など、エージェントの動作を指示します。 [ 説明] タブを使用している場合は、自動生成されます。 文字数制限は 8,000 文字です。 詳細については、「 効果的な手順を記述する」を参照してください。
知識
パブリック Webサイト、組織および個人の作業コンテンツ、埋め込みファイル、Microsoft 365 Copilot コネクタをナレッジ ソースとして追加します。 可用性と制限は、ソースの種類によって異なります。 詳細については、 ナレッジ ソースの追加を参照してください。
スターター プロンプト
スターター プロンプトは、他のユーザーがエージェントによって一般的にサポートされているシナリオを理解するのに役立ちます。 各スターター プロンプトには、名前と説明が表示されます。 スターター プロンプトの最小数はありません。
エージェントを作成したら、[試してみる] タブでテストします。エージェントの指示、知識、推奨されるプロンプトを引き続き絞り込むことができます。
テンプレートからビルドする
Microsoft 365 Copilot のエージェント ビルダーには、特定のユース ケースのエージェントを構築するために使用できるテンプレートが含まれています。 テンプレートには、説明、手順、プロンプトが事前構成されています。 テンプレートをそのまま使用するか、ナレッジ ソースの追加など、特定のニーズに合わせてカスタマイズします。
テンプレートを使用してエージェントをビルドするには:
Microsoft 365 Copilot で、[新しいエージェント] を選択します。
[New agent] ページの [ Start with a template] で、使用するテンプレートを選択します。 エージェントは自動的に作成されます。
エージェントをさらに絞り込み、自然言語を使用してナレッジ ソースを追加したり、[ 構成] タブで絞り込みを手動で追加したりできます。
詳細については、「 エージェントビルダーテンプレート」を参照してください。
エージェントを作成したら、[試してみる] タブでテストします。エージェントの指示、知識、推奨されるプロンプトを引き続き絞り込むことができます。
ナレッジ ソースの追加
コンテキスト認識エージェントを構築するには、テナントで有効になっている SharePoint アイテム、一般向け Web サイト、Teams チャット メッセージや Outlook メールなどの個人的な仕事情報、 Copilot コネクタ などのソースを参照します。
自然言語を使用してエージェントを作成している場合は、[ 説明 ] タブのチャット ボックスでエージェントに追加するナレッジ ソースを選択するか、[ 構成] タブでナレッジ ソースを選択します。
サポートされているソースとその制限については、 エージェント・ビルダーでのエージェントへのナレッジ・ソースの追加を参照してください。
注:
ナレッジ ソースの可用性は、ユーザーのライセンスによって異なります。 詳しくは、「 エージェント機能とライセンスモデル」を参照してください。
機能
エージェントで次の機能を使用できます。
コード インタープリター - 複雑な数学の問題を解き、データを分析し、視覚化を生成します。 この機能を追加するには、[ ドキュメント、グラフ、コードの作成] の横にあるトグルを選択します。
画像ジェネレーター - ユーザー プロンプトに基づいて画像を生成します。 この機能を追加するには、[ 画像の作成] の横にあるトグルを選択します。
[ 説明] タブで自然言語を使用する場合も、[ 構成] タブで手動構成を使用する場合も、これらの機能は自動的に取得できます。
注:
エージェントビルダーは、外部サービスを統合するアクションの作成をサポートしていません。 ローコード アクション、コネクタ、またはワークフローを追加するには、エージェントを Microsoft Copilot Studio にコピーします。 シナリオで別のプロコード実装が必要な場合は、「 プラグイン用の開発ツールを選択する」を参照してください。
スキル (プレビュー)
Agent Builder で構築されたエージェントにスキルを追加するには、スキル パッケージを提供するか、自然言語でスキルを記述します。 Agent Builder のスキルはプレビュー段階であり、Microsoft Frontier プログラムに登録されている組織のみが利用できます。 詳細については、「 エージェント ビルダーで宣言型エージェントにカスタム スキルを追加する (プレビュー)」を参照してください。
既定の応答モードを設定する
[構成] タブの [モデル] セクションで、エージェントの既定の応答モードを設定します。 応答モードは、エージェントが各質問にアプローチする方法 (速度を優先するか、詳細な分析に時間がかかるか) を制御します。 ユーザーは、エージェントの使用時にモデル セレクターを使用していつでもこの設定を上書きできます。
次の応答モードを使用できます。
モード
説明
自動 (既定)
エージェントは、各質問に基づいて最適なアプローチを自動的に選択し、分析の速度と深さのバランスをとります。
クイック応答
エージェントは迅速に応答し、応答を簡潔に保ちます。 このモードは、詳細な分析を必要としない簡単な質問に最適です。
深く考える
エージェントは、応答する前に質問を注意深く分析するためにより多くの時間を要します。 このモードは、より詳細な回答の恩恵を受ける複雑なタスクに最適です。
エージェントをテストする
「 試してみる」 タブには、オーサリング・エクスペリエンス内でエージェントをテストおよび改良するために使用できるエージェントのインスタンスが表示されます。 これを使用して、エージェントの作成または更新中にエージェントをテストします。 エージェントに名前、説明、および指示が用意された後、[ 試してみる] エクスペリエンスが有効になります。 エージェントは、指定された知識の範囲内で複雑なクエリに応答する機能を含め、作成後と同じ方法でこれらの指示に従います。 エージェントは、自然言語を使用して、またはエージェント ビルダーの [構成 ] タブで手動で新しい情報を追加すると、会話の各ターンで更新されます。
一部のエージェント機能は、[ 試す] エクスペリエンスでは使用できません。 たとえば、プロンプトを共有したり、フィードバックを提供したり、Microsoft 365 Copilot アプリ内の他のエージェント@mentionするために使用することはできません。 これらの機能は、エージェントの作成後に使用できます。
試 すエクスペリエンス には、推奨されるプロンプトが含まれています。選択すると、プロンプトが呼び出されて会話が開始されます。 [ 新しいチャット ] を選択してエージェントとの新しい会話を開始し、提案されたプロンプトをもう一度表示できます。
