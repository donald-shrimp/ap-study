Microsoft Copilot および Microsoft Copilot Chat におけるエンタープライズ データ保護

注:
Microsoft 365 Copilot の名前が Microsoft Copilot になり、Microsoft 365 Copilot Chat の名前が Microsoft Copilot Chat になりました。 一部のエクスペリエンス、ライセンス、機能は、移行期間中、引き続き Microsoft 365 Copilot と Microsoft 365 Copilot Chat を参照する場合があります。 組織のセキュリティ、コンプライアンス、プライバシーに変更はありません。
Microsoft Copilot と Microsoft Copilot Chat におけるエンタープライズ データ保護とは
組織が使用する Microsoft Copilot と Microsoft Copilot Chat の使用には、Microsoft 製品とサービスのデータ保護に関する補遺 (DPA) および Microsoft 製品条項の条項が適用され、Microsoft はデータ処理者として機能します。
エンタープライズ データ保護 (EDP) とは、データ保護補遺 (DPA) および製品条件に基づいて、Microsoft CopilotおよびMicrosoft Copilot Chatユーザーの顧客データに適用されるコントロール[1]とコミットメントを指します。 EDP という用語の使用は、DPA および製品条件に基づいて提供される利点を制限することを意図したものではありません。
プロンプトと応答のエンタープライズ データ保護
Microsoft Copilot と Microsoft Copilot Chat は、Microsoft 365 商用サービスで利用できるのと同じエンタープライズ利用規約[2] を提供しています。
Microsoft CopilotとMicrosoft Copilot Chatの使用には、プロンプト (ユーザーが入力したもの) と応答 (Copilot によって生成されたコンテンツ) が含まれます。 EDP を使用すると、Exchange のメールと SharePoint のファイルに対してお客様から広く信頼されているのと同じ契約条件とコミットメントによってプロンプトと応答が保護されます。
Microsoft では、お客様のデータをセキュリティで保護します。 保存中および転送中の 暗号化 、厳格な物理的セキュリティ制御、テナント間のデータ 分離 を使用して、データの保護を支援します。
データは非公開です。 お客様の指示がある場合を除き、お客様のデータは使用されません。
プライバシーに対する Microsoft の取り組みには、一般データ保護規則 (GDPR)、EU データ境界[3]、ISO/IEC 27018、およびデータ保護補遺へのサポートが含まれます。
アクセス制御とポリシーは Copilot に適用されます。 Copilot は、 ID モデル と アクセス許可を尊重し、 秘密度ラベルを継承し、 保持 ポリシーを適用し、相互作用の 監査 をサポートし、管理設定に従います。 具体的な制御とポリシーは、基になるサブスクリプション プランによって異なります。
AI セキュリティおよび著作権リスクから保護されます。有害なコンテンツやプロンプト インジェクションなどの、AI にフォーカスしたリスクから保護するのに役立ちます。 コンテンツの著作権に関する懸念については、 保護された素材の検出 と お客様著作権コミットメントを提供します。
データは基礎モデルのトレーニングには使用されません。Microsoft Copilot Chat はユーザーのコンテキストを使用して関連する応答を作成します。 Microsoft Copilot は Microsoft Graph データも使用します。 他の Copilot オファーと同様に、Microsoft Graph 経由でアクセスされるプロンプト、応答、データは 基礎モデルのトレーニングには使用されません。

Web クエリのプライバシーとセキュリティ
最新のデータで回答を根拠に
プロンプトと応答に加えて、Web 検索クエリ (Microsoft Graph クエリとは異なります) も Copilot の操作の一部です。 Copilot がこれらのクエリを介して Web コンテンツを参照できるようにすると、Bing 検索サービスを介した Web からの最新情報に基づいて Copilot の応答の品質が向上します。
Web クエリには独自のデータ処理方法があります
Bing 検索サービスに送信された Web クエリは、両方の Copilot によって同じように処理されます。 クエリは、プロンプトからいくつかの単語に生成されます。 これらは、ユーザーとテナントの識別子が削除されたセキュリティで保護された接続を介して送信されます。 これらは広告主と共有されず、基礎となる大規模言語モデル (LLM) のトレーニングには使用されません。
Bing 検索サービスは Microsoft 365 とは別に動作し、各ユーザーと Microsoft の間で、 Microsoft サービス規約 および Microsoft プライバシー ステートメントによってカバーされるデータ処理の慣行が異なります。 これは、Microsoft が独立したデータ コントローラーとして機能し、適用されるすべての法規およびコントローラーに対する義務に準拠する責任を負うことを意味します。 このアプローチは、 Bing に依存する他のオプションの接続エクスペリエンスと一貫しています。
Microsoft 製品条項は、Bing 検索サービスに送信される Web クエリに関する追加の規定を規定しています。 詳細については、「Microsoft Copilot および Microsoft Copilot Chat での Web 検索のデータ、プライバシー、およびセキュリティ」を参照してください。
Microsoft Copilot のエージェント
Microsoft Copilot でエージェントを使用する場合は、エージェントのプライバシーに関する声明と利用規約をチェックして、エージェントがorganizationのデータをどのように処理するかを決定してください。
脚注
[1] 特定の制御は、顧客の Microsoft サブスクリプション プランによって異なります。
[2] Microsoft Copilot と Microsoft Copilot Chat は、適切に構成された実装のために HIPAA コンプライアンスをサポートします。 HIPAA コンプライアンスは、DPA およびビジネス アソシエイト契約 (BAA) の対象ではないため、Web 検索クエリには適用されません。
[3] EU データ境界は、Web 検索クエリには適用されません。 さらに、Anthropic モデルは現在、EU データ境界から除外されており、該当する場合は国内での処理コミットメントから除外されています。
Anthropic モデルが Microsoft Copilot とどのように連携するかの詳細をご確認ください。
