Microsoft Copilot と Microsoft Copilot Chat での Web 検索のデータ、プライバシー、セキュリティ
フィードバック
注:
Microsoft 365 Copilot の名前が Microsoft Copilot になり、Microsoft 365 Copilot Chat の名前が Microsoft Copilot Chat になりました。 一部のエクスペリエンス、ライセンス、機能は、移行期間中、引き続き Microsoft 365 Copilot と Microsoft 365 Copilot Chat を参照する場合があります。 組織のセキュリティ、コンプライアンス、プライバシーに変更はありません。
Microsoft Copilot と Microsoft Copilot Chat には、Copilot がユーザーのプロンプトに応答するときに Web コンテンツを参照できるオプション機能があります。 Microsoft Copilotと Microsoft Copilot Chat が Web コンテンツを参照できるようにすると、Web からの最新情報に基づいて Copilot の応答の品質が向上します。
注:
この記事では、Microsoft Copilot と Microsoft Copilot Chat の Web 検索機能について説明します。 Microsoft Copilot Search は、Microsoft Copilot ライセンスを持つユーザーがすべての Microsoft 365 およびサード パーティのデータ ソースを検索できるようにする、追加のユニバーサル検索エクスペリエンスです。
Microsoft Copilot 検索 の詳細をご覧ください。
この記事の Web 検索に関する情報は、Microsoft Copilot のリサーチ ツール、アナリスト、Cowork にも適用されます。 リサーチ ツール、アナリスト、Cowork を使用するための前提条件は Web 検索ではありませんが、これらの使用の価値を最大限に引き出すためには、Web 検索を有効にすることをお勧めします。 リサーチツールには、入力ボックスでアクセスできる Web検索 トグルがあります。 アナリストと Cowork には、ユーザーの Web 検索トグルがありません。
Web 検索
Web 検索が有効になっている場合、Web からの情報がより適切で根拠のある応答を提供するのに役立つ場合、Microsoft Copilot と Microsoft Copilot Chat は Bing 検索サービスから情報を取得する場合があります。 管理 コントロールとユーザー レベルの Web コンテンツの切り替えは、対象となるMicrosoft Copilotおよび Microsoft Copilot Chat ユーザーが利用できます。
Web 検索のしくみ
Web 検索が有効になっている場合、Microsoft CopilotとMicrosoft Copilot Chatはユーザーのプロンプトを解析し、Web からの情報によって応答の品質が向上する用語を識別します。 これらの用語に基づいて、Copilot は、詳細を求める Bing 検索サービスに送信される検索クエリを生成します。
この生成された検索クエリは、ユーザーの元のプロンプトとは異なり、ユーザーのプロンプトによって通知されたいくつかの単語で構成されています。 次の情報は、Bing 検索サービスに送信される生成された検索クエリには含まれません。
ユーザーのプロンプト全体 (プロンプトが非常に短い場合 ("地元の天気" など) でない限り)
Microsoft 365 ファイル全体 (メールやドキュメントなど) または Copilot にアップロードされたファイル
Microsoft Edge の Copilot によって要約された Web ページ全体または PDF (Microsoft Copilot Chat のみ)
ユーザーの Microsoft Entra ID に基づく識別情報 (ユーザー名、ドメイン、テナント ID など)
Microsoft Copilot を使用する場合、生成された検索クエリには、プロンプトに関連付けられている Microsoft 365 ドキュメント全体は含まれません。 ただし、次の条件下では、Microsoft 365 ドキュメント内のデータによって通知される場合もあります。
ユーザーが Microsoft 365 アプリケーション内の Copilot にプロンプトを入力するとき (たとえば、関連するドキュメントが開いている間に Microsoft Word の Copilot にプロンプトを書き込む)。
ユーザーがプロンプトで特定のドキュメントを明示的に参照している場合。
ユーザーのプロンプトと Copilot の応答は Microsoft 365 内に格納され、顧客の指示なしにMicrosoft CopilotとMicrosoft Copilot Chatの両方のサービスの境界を離れることはありません。
エンタープライズ データ保護、 データ保護補遺 (DPA)、および 製品契約 は、プロンプトと応答に適用され、Microsoft はデータ処理者として機能します。
Microsoft CopilotとMicrosoft Copilot ChatがBing検索サービスから追加情報を受信した後、この情報を使用してユーザーに返される応答を作成します。
Web 検索クエリの引用
生成された検索クエリの可視性を高めるために、Web 検索クエリの引用は、Copilot 応答のリンクされた引用セクションにユーザーに表示されます。 このセクションには、Bing 検索サービスに送信された (ユーザーのプロンプトから派生した) 正確な Web 検索クエリが表示されます。 正確な Web 検索クエリを表示すると、ユーザーは、プロンプトに対する Copilot の応答を強化するために、検索されたサイトと共に検索クエリが使用されたかを理解するのに役立ちます。 この情報は、ユーザーがプロンプトを改善し、Copilot をより効果的に使用するのに役立ちます。
Web 検索クエリの引用は、Microsoft Copilot Chatでのみ使用できます。 引用は、Word や PowerPoint などの Microsoft 365 アプリ内の [Copilot] ウィンドウでは使用できません。 また、Web 検索クエリはチャット スレッドでのみ 24 時間使用できます。
Web 検索クエリのログ
Web 検索クエリのログを使用して、管理者はユーザー プロンプトから Copilot が引き出した正確な Web 検索クエリに対して、検索、監査、電子情報開示を行うことができるようになります。 管理者は、プロンプトと応答に対してこれらのアクションを既に実行でき、使い慣れたツールを使用して、それらのアクションを検索クエリに拡張できます。 詳細については、「 監査ログ アクティビティ」、「 Copilot 対話イベントの概要」、「 電子情報開示での AI アプリケーション データの検索と削除」を参照してください。
管理者は、AI 向け Microsoft Purview データ セキュリティ態勢管理 (DSPM) のアクティビティ エクスプローラーを使用して、Copilot が使用した実際の Web 検索語句を、元のプロンプト、応答、およびサポート リソースと並べて表示することもできます。 詳細については、「AI のデータ セキュリティ態勢管理 (DSPM) について学ぶ」を参照してください。

Microsoft が生成された検索クエリを処理する方法
Microsoft Copilot と Microsoft Copilot Chat はどちらも、生成された検索クエリを Bing Search サービスに送信して、Web データの応答の基礎にします。 Microsoft がこれらのクエリを処理する方法は、両方のサービスで同じです。
生成された検索クエリは、ユーザーとテナントの識別子が削除された状態で Bing 検索サービスに送信されます。 また、Bing に送信された Web 検索クエリは、次のいずれにも影響しません。
検索ランキング
リッチ キャプションなどの回答または機能
自動提案、トレンド、ゼロ入力などのソーシャル機能
製品契約の「Microsoft CopilotとMicrosoft Copilot Chat」セクションでは、Bing Search Service に送信される生成された検索クエリについて、次の追加のコミットメントを提供します。
Microsoft は、サービスを提供するために必要とする以外の権限を持っていません。
これらは、Bingを改善するために使用されません。
広告プロファイルの作成やユーザーのビヘイビアーの追跡には使用されません。
これらは広告主と共有されません。
これらは、生成 AI の基盤モデルのトレーニングには使用されません。
これらは顧客の機密情報として扱われ、適切な技術的および組織的な手法によって保護されます。
Bing 検索サービスは、Microsoft 365 とは別に動作し、データ処理のプラクティスが異なります。 Copilot によって生成され、Bing に送信される Web 検索クエリは、各ユーザーと Microsoft の間の Microsoft サービス規約、および Microsoft プライバシー ステートメントの対象となります。
製品の使用条件は、Web クエリ データの処理に関して、コントローラーとしての追加のコミットメントを Microsoft に追加します。 Microsoft はデータ管理者として機能し、適用されるすべての法律および管理者の義務を遵守する責任を負います。 Microsoft Copilot および Microsoft Copilot Chat での Bing の使用に関して矛盾が生じる場合は、製品条項が Microsoft サービス規約および Microsoft プライバシー ステートメントに優先します。
Microsoft 製品およびサービスのデータ保護に関する補遺 (DPA) は、Microsoft Copilot、Microsoft Copilot Chat、または Bing 検索サービスで生成された Web 検索クエリの使用には適用されません。 また、HIPAA コンプライアンスと EU データ境界は、生成された検索クエリには適用されません。
Web 検索の管理に使用できる制御
組織のポリシー、ユーザー設定、セキュリティに関する考慮事項に一致するように Web 検索を管理するために、IT 管理者用とユーザー用の 2 つの異なるコントロールを使用できます。
Microsoft Copilot と Microsoft Copilot Chat の両方に対する IT 管理者の制御
IT 管理者が Web 検索へのアクセスを制御する主な方法は、[ Copilot での Web 検索を許可 する] ポリシーを使用することです。これは、 Microsoft 365 のクラウド ポリシー サービスでのみ利用できます。 このポリシーにより、IT 管理者は、組織のポリシー、データ プライバシー法、またはその他の規制要件に従って、管理するテナント全体でユーザーまたはユーザー グループの organization 検索を有効または無効にすることができます。 このポリシーは、Microsoft Copilot と Microsoft Copilot Chat の両方に適用されます。
IT 管理者が [Copilot での Web 検索を許可 する] ポリシーを有効にした場合、Copilot での Web 検索のオプションには次の 3 つがあります。
Microsoft Copilot および Microsoft Copilot Chat で有効
Microsoft Copilot と Microsoft Copilot Chat で無効にする
Microsoft Copilot 作業モードで無効になっています。Microsoft Copilot Web モードと Microsoft Copilot Chat で有効
IT 管理者が Microsoft Copilot ユーザーの Web 検索を有効にした場合でも、それらのユーザーには Web コンテンツの切り替えを使用して Web 検索をオフにするオプションが引き続き表示されます。
IT 管理者が Web 検索をオフにすると、 Web コンテンツ の切り替えがオフになり、淡色表示されます。 ユーザーはトグルをオンにして Web 検索を使用できません。
注:
IT 管理者が Microsoft Copilot 作業モードで [無効] を選択した場合。Microsoft Copilot Web モードとMicrosoft Copilot Chat オプションで有効にすると、リサーチ ツールでの Web 検索と Microsoft Copilot でのCoworkが無効になります。
IT 管理者が [Copilot での Web 検索を許可する] ポリシーを構成していない場合、IT 管理者が [Office での追加のオプションの接続エクスペリエンスの使用を許可する] ポリシーを無効に設定していない限り、Microsoft CopilotとMicrosoft Copilot Chatの両方のユーザーが Web 検索を利用できます。 ただし、オプションの接続エクスペリエンスをオフにすると、Microsoft 365 全体でMicrosoft Copilot Chat、Microsoft Copilot、および複数のエクスペリエンスが制限されます。
注:
Microsoft 365 (または Office 365)、Government Community Cloud (GCC)、または DoD サービスを使用している米国政府機関のお客様の場合:
Web 検索は使用できますが、既定ではオフになっています。
Web 検索を有効にするには、Microsoft 365 のクラウド ポリシー サービスの [Copilot での Web 検索を許可する ] ポリシーを使用します。 このポリシーの詳細については、このセクションの前半の情報を参照してください。
[Copilot での Web 検索を許可する] ポリシーを構成していない場合、[Office での追加のオプションの接続エクスペリエンスの使用を許可する] ポリシーがどのように構成されているかに関係なく、Web 検索はオフのままになります。
ユーザー用の Web コンテンツの切り替え
Web コンテンツの切り替えを使用すると、ユーザーはMicrosoft Copilot応答にリアルタイムの Web コンテンツを含めるかどうかを制御でき、Microsoft Copilotユーザーと Microsoft Copilot Chat ユーザーの両方が利用できるようになりました。
IT 管理者が Web 検索を有効にすると、[Web コンテンツ] の切り替えが既定で有効になります。 有効にすると、ユーザーはリアルタイムの Web コンテンツに基づいて応答を受け取ります。 IT 管理者が Web 検索を無効にすると、 ユーザーは Web コンテンツ の切り替え機能を使用できず、Web 検索は無効になります。
ユーザーが Web コンテンツ の切り替えをオフにすると、Web コンテンツは Copilot の応答に含まれなくなります。 ユーザー設定はセッション間で保持され、サポートされている Copilot クライアントとデバイスに適用されます。
ユーザーは次の手順に従って Web 検索を管理できます。
Microsoft Copilot アプリで、[設定] を開き、[個人用設定] を選択します。
[ 詳細設定] を展開し、[ Web 検索 ] トグルをオフにします。
注:
Microsoft 365 アプリ (Word、Excel、Teams など) でユーザーが利用できるオプションの接続エクスペリエンスのプライバシー設定は、Web 検索の可用性には影響しません。 たとえば、ユーザーがオプションの接続エクスペリエンスをオフにしても、ユーザーは Web 検索を引き続き利用できます。
