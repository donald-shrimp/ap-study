Microsoft Copilot Chat
Copilot Chat は、 対象の Microsoft 365 サブスクリプションを持つ組織に自動的に含まれて使用可能になる、AI のプロンプトと応答のエクスペリエンスです。 Copilot Chat では、Web ベースのチャットと職場ベースのチャットの 2 種類のオプションが提供されています。
Web ベースのチャット:
インターネットからの結果を表示します。
追加料金なしで、対象の Microsoft 365 サブスクリプションに自動的に含まれます。
職場ベースのチャット:
Microsoft Entra の職場または学校アカウントからのアクセスが可能な結果を表示します。
Microsoft Copilot ライセンスで使用できます。

Microsoft 365 Copilot アプリが Microsoft Copilot と呼ばれるようになりました。 更新された Copilot アプリにアクセスするためのプライマリ URL が copilot.cloud.microsoft に変更されます。 ユーザーの接続がブロックされないようにするには、次のことを確認してください。
許可 *.cloud.microsoft。

個人用アカウント アクセスを防ぐためにcopilot.cloud.microsoftをブロックしないでください。 代わりに、 テナントの制限 を使用して、個人の Microsoft アカウントのサインインを制御します。
