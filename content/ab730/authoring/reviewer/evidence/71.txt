Microsoft 365で研究者とClaudeをどのように使用できますか？
リサーチ ツール エージェントは、Microsoft Copilot のインテリジェントなアシスタントであり、複雑な複数ステップの調査に取り組み、構造化されたソース引用レポートを作成するために構築されています。 Web から、また職場でアクセスできるファイル、電子メール、会議、チャットから情報を収集、分析、要約するのに役立つ、強力なリサーチ パートナーと考えてください。 リサーチ ツールを使用すると、詳細な回答を取得し、意思決定をより迅速に行うことが容易になります。
注
リサーチ ツールは現在、Microsoft 365 Premium および Pro サブスクライバーと、Microsoft 365 Copilot アドオン ライセンスを持つ Microsoft 365 Business および Enterprise ユーザーが利用できます。
Microsoft 365 プランの詳細情報をご覧ください。
リサーチ ツールと標準の Copilot エクスペリエンスの違いは何ですか?
リサーチ ツール は、タスクのより深い推論を目的として設計されています。 思慮深い分析を必要とする複雑で階層的なタスクに取り組むことに優れています。 処理時間が長くなることで、Researcherはより包括的な出力を提供し、詳細な研究プロジェクトに最適です。
標準の Copilot エクスペリエンス は、Microsoft 365 アプリ全体で日常のさまざまなタスクを支援します。 スピードと効率性が最適化されており、メールの要約や短い返信の作成など、より迅速なタスクに最適です。

リサーチ ツール エージェントを使用する理由
時間を節約: 作業コンテンツと Web から取得し、構造化された合理的な応答を作成します。
信頼の構築: ソースを表示し、結果を整理して、自信を持って検証して共有できるようにします。
作業方法に合う: Microsoft Copilot の内部にあります。 職場では、既に依存しているのと同じアクセス許可、ポリシー、コンプライアンスが尊重されます。

リサーチ ツールの使用方法
Microsoft Copilot で リサーチ ツール ( [エージェントの下)] を開きます。
質問する: 最初に、「教育における AI の利点は何ですか?」などのトピックや質問を入力します。—リサーチ プロンプトに挿入します。 または、組み込みプロンプトの例のいずれかを使用します。
明確にする (オプション): リサーチは、何を探しているのかをよりよく理解するために、フォローアップの質問をする場合があります。 質問に答えることも、単に "進んでください" と言うこともできます。
動作を確認する: エージェントは、独自の作業ファイルや Web など、信頼できるソースから情報を検索して分析します。
レポートを取得する: 主要な分析情報、ソースの引用、次の手順を含む構造化された要約を受け取ります。
アクションを実行する: レポートを編集したり、共有したり、プレゼンテーションやドキュメントの作成に使用したりできます。
リサーチツールはディープリサーチと同じですか?
リサーチ ツールとディープリサーチは非常によく似たエクスペリエンスであり、お客様が詳細な調査レポートと分析を作成するのに役立ちました。 Copilot の継続的な更新の一環として、ディープ リサーチは廃止され、リサーチ ツールは Microsoft 365 Premium および Pro のサブスクライバーが利用できる詳細なリサーチ エクスペリエンスになりました。 既存のDeep Researchレポートは削除されません。 Microsoft 365 Premium および Pro サブスクライバーは、リサーチ ツールで以前のレポートに引き続きアクセスできますが、Microsoft 365 Personal および Family サブスクライバーはチャット履歴で以前のレポートを見つけることができます。
最良の結果を得るためのヒント
プロンプトを具体的に書く
明確で詳細な質問は、より焦点を絞った信頼性の高い結果につながります。 たとえば、次のように言う代わりに:
"パフォーマンス レビューのレポートを書いてください。"
試してみてください:
"パフォーマンス レビュー用に Contoso プロジェクトに対するビジネスの影響に関するレポートを書いてください。"
検索範囲を定義する
職場のリソース、Web、またはその両方からデータを取得するかどうかを決定します。 これにより、よりターゲットを絞った関連性の高いレポートを作成できます。
明確な質問に取り組む
リサーチャーは、アウトプットを導き、あなたを関与させるために、明確な質問をするかもしれません。 このフェーズは、調査を主導し、最終レポートがニーズを満たしていることを確認するために重要です。
Microsoft Copilot のリサーチ ツールで Claude を使用する
リサーチ ツールは Anthropic の AI モデルをサポートするようになりました。 この新しいサービスを有効にすると、ResearcherでClaudeを使用して、分析と研究ワークフローを強化できます。
リサーチ ツールで Claude を使用するには、管理者が Microsoft 365 管理センターで Anthropic AI モデルへのアクセスを許可する必要があります。 管理者に問い合わせてください。
詳細については、「 Microsoft Copilot のリサーチ ツールで Claude を使用する」を参照してください。
