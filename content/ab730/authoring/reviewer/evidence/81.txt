Microsoft Copilot を使い始める
この記事の対象:すべての Microsoft Copilot エクスペリエンス — 個人用アカウント (個人、ファミリー、Premium、Pro)、職場または学校アカウント、無料の Copilot Chat。
Microsoft Copilot は、AI の力とデータやアプリを組み合わせて、創造性を解き放ち、生産性を解き放ち、チャット エクスペリエンスで回答をすばやく取得できるようにします。 職場または学校のアカウントでサインインしている場合、Copilot Chat は Web だけでなく、チャット、メール、ファイルなどのorganizationのデータを使用します。 個人用 Microsoft アカウントでサインインしている場合、Copilot は代わりにユーザー独自のコンテンツと Web を描画します。
職場で Copilot を入手する
Web ブラウザーで Copilot に移動し、職場または学校アカウントでサインインします。
また、Web、デスクトップ、モバイル上の Microsoft 365 アプリ、Microsoft Teams、Outlook など、既に作業しているアプリ内で Copilot を使用することもできます。
モバイルでは、iOS または Android 用の Microsoft Copilot モバイル アプリをインストールできます。
ログインすると、左側のナビゲーションに、 新しいチャット、 検索、 ライブラリ、 エージェントとスキル、 ノートブックと共に 3 つのエクスペリエンスが表示されます。
会話の質問と回答、要約、下書きのための Chat。
Cowork は、Copilot に引き渡して独自に完了させる、より長い複数ステップの作業に対応します。 詳細については、「Cowork の概要」を参照してください。
コーディング アシスタント タスクのコード。
Work IQ: Copilot が組織データをどのように使用するか
Chat の上部で、[自動モデル ピッカー] の横に Work IQ コントロールが表示されます。
Work IQ を選択してオンとオフを切り替えます。
Work IQ on (既定値): Copilot は、ファイル、メール、Teams 会議、Web からの情報などのorganizationのデータを使用してプロンプトに応答します。
仕事 IQ オフ: Copilot は、Microsoft 365 データを一切使用せずに、Web と AI モデルのトレーニング データのみを使用して回答します。 オフの間、プロンプトの提案と参照メニューは Web ベースのソースに制限されます。
ヒント
どちらの設定も、エンタープライズ レベルのセキュリティ、プライバシー、コンプライアンスを提供します。 Copilot は、プロンプトに応答するときに、既にアクセスが承認されている作業コンテンツのみを使用します。 「 Copilot はプロンプトに応答するためにどのような情報を使用しますか? 」を参照して、Copilot が組織データにアクセスして使用する方法の詳細を確認してください。
Work IQ の横にある自動ピッカーは、個人用 Copilot エクスペリエンスで使用できる会話モードと同様に、プロンプトに応答する AI モデルを制御します。
Copilot Chat でできること
コンテンツの作成とブレインストーミング。 ストーリーボードやスクリプトから議題や概要に至るまで、あらゆるものに基づいて新しいコンテンツを下書きします。 「Copilot Chat を使用してコンテンツを作成する」を参照してください。
すばやい回答を取得します。 特定のファイルやメッセージについて質問したり、存在することはわかっているが保存場所を思い出せない情報を検索したりできます。 「Copilot Chat を使用して質問をして回答を得る」を参照してください。
最新情報を確認します。 大量のデータをシンプルで読みやすい更新に集計します。 「Microsoft Copilot Chat を使用して見逃したものを取り戻す」を参照してください。
音声コマンドを使用します。 マイク ボタンを選択して、Copilot Chat と話します。 音声応答を中断してもかまいませんが、Copilot は新しい入力に応答します。
マルチステップの作業を引き継ぎます。 Copilot に処理させ、何度も繰り返すことなく完了させたい長いタスクには、[Cowork] タブを使用します。 「Cowork の使用を開始する」を参照してください。
コーディングのヘルプを入手してください。 コーディング アシスタント タスクには [コード] タブを使用します。
優れたプロンプトを書く
適切に作成されたプロンプトにより、より良い結果が得られます。
必要なものを明確、簡潔、具体的に示してください。 試すプロンプトを参照してください。
繰り返しを受け入れます。 最初の結果に満足しないでください。 絞り込み、実験して、必要なものに近づけます。
特定のコンテンツを参照します。 スラッシュ (/) を入力し、ファイル、人物、または会議の名前を入力して、Copilot に意図するソースを示します。 特定の情報を参照しない場合、Copilot は応答に最適なデータ ソースを選択します。

Copilot は会話型であるため、最初の応答が正しくない場合は、フォローアップします。 期間を絞り込んだり、形式を変えたり、ある点を深く掘り下げたりするように依頼してください。
AI の今後の改善
AI はエキサイティングなテクノロジですが、まだ開発は初期段階にあります。 Copilot で問題が発生する場合があるため、生成される内容を確認することが重要です。 任意の応答でサムズ アップ ボタンとサムズ ダウン ボタンを使用して、何が機能しているか、何がそうでないか、およびどこを改善できるかを伝えます。
個人用アカウントを使用している場合
職場または学校のアカウントではなく、個人用の Microsoft アカウントでサインインしている場合、Copilot はほぼ同じように動作しますが、いくつかの違いがあります。
より多くの場所からアクセスします。 Copilot は、Microsoft Copilot の Web に加えて、Windows、macOS、iOS/iPadOS、Android で専用アプリとして利用できます。
他のアカウント タイプでサインインします。 Web、モバイル、macOS では、Microsoft アカウント、Apple ID、または Google アカウントでサインインできます。 Windows アプリには Microsoft アカウントが必要です。
Work IQ の切り替えはありません。 Copilot は、organization のデータではなく OneDrive ファイル、Outlook.com メール、Web など、ユーザー独自のコンテンツを使用するため、管理する作業と Web の設定はありません。
