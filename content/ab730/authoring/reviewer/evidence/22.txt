Microsoft Copilot 検索
フィードバック
Microsoft Copilot 検索 は、organization 向けに最適化された AI 搭載のユニバーサル検索エクスペリエンスです。 ユーザーが organization から関連する結果をすばやく見つけるのに役立つ使い慣れた検索エクスペリエンスが提供されます。 シンプルなユーザー エクスペリエンスが提供されるため、高速で安全な統合検索で、必要なときに必要なものを見つけることができます。
すべてのアプリケーションにわたる統合検索:Copilot 検索 は、Microsoft 365 アプリケーションやその他のアプリケーション全体でコンテンツを解釈することで、organizationのデータに関する包括的な分析情報を提供します。 現在 Microsoft カタログに 100 を超えるコネクタがあり、カスタム コネクタがサポートされ、統合ソフトウェア ベンダー (ISV) からの数百のコネクタが提供されているため、Copilot 検索 は、Microsoft と Microsoft 以外のすべてのデータ ソースにわたる情報をすばやく入手できる 1 つの場所です。
Microsoft 365 Copilot コネクタ ギャラリーの詳細を確認します。
次の場合に使用します。Microsoft Copilot と統合されているため、ユーザーは検索を使用して必要な結果を見つけ、チャットにシームレスに移行して、より深い探索やフォローアップ タスクの完了を行うことができます。
Copilot 検索と Microsoft Copilot のしくみ
Copilot 検索 は、専用の検索モジュールとして Microsoft Copilot アプリに統合されています。 この統合により、Copilot 検索は次のようになります:
包括的: ユーザーがすべての Microsoft 365 とサード パーティのデータ ソースを検索して、必要なものをすばやく見つけることができるユニバーサル検索エクスペリエンス
高速: 組織コンテンツ全体にわたって大規模に迅速な応答を提供します
関連性: 意味理解を使用して、文脈に関連した正確な結果を得る
シンプル: 直感的で最新のユーザー エクスペリエンスが特徴
接続: Copilot の回答と概要リンク 検索から Chat へ
パーソナライズ: 個々のユーザーとテナントに合わせて調整
セキュリティ: エンタープライズ レベルのセキュリティとプライバシーを提供します
この設計では、検索が AI の組織レイヤーとして位置付けられますが、チャットはタスクの実行とより深い対話のためのワークスペースのままです。 たとえば、ユーザーが 第 2 四半期レポートの状態を検索した場合、Copilot 検索は要約された回答を返し、より微妙な調査やフォローアップ アクションのためにチャットで会話を続行することを提案する場合があります。
アクセスと適格性
Copilot 検索 は、対象となる Microsoft Copilot ライセンスを持つユーザーに追加料金なしで利用できます。 デスクトップ、Web、モバイル プラットフォーム上の Microsoft Copilot アプリからアクセスできます。 このアプリは、Entra アカウント (職場または学校) を持つユーザーが利用できます。
管理者またはユーザーが Copilot 検索を設定するために必要な操作はありません。 ユーザーが対象の Microsoft Copilot ライセンスを持っている場合、Copilot 検索は Microsoft Copilot アプリのタブとして表示されます。
プライバシーとセキュリティ
Microsoft Copilot Search は、Microsoft Copilot と同じデータ保護、プライバシー標準、セキュリティ構成に準拠しています。
Microsoft Copilot のデータ、プライバシー、セキュリティの詳細について説明します。
自然言語検索
Copilot 検索 は自然言語クエリをサポートしており、ユーザーは日常の言語で質問や要求を入力できます。 たとえば、先 週送信された第 4 四半期予測に関する John からのメール や、 マーケティング ROI を地域別に分類するスプレッドシートはどこにあるかなどを検索すると、Copilot 検索が意図を理解し、メール、ファイル、チャット、会議など、Microsoft 365 全体から関連する結果を返します。
Copilot 検索は、キーワード (keyword) 一致を超えて、AI を使用してコンテキスト、関係、意味を解釈し、必要なものをより迅速かつ直感的に見つけるのに役立ちます。 また、特定の単語や短いフレーズに対する従来の キーワード (keyword) クエリもサポートされており、完全一致または部分一致に依存しています。 しかし、自然言語のクエリは AI を使ってクエリのコンテキストをより適切に解釈し、より関連性の高い結果に導くことができます。
回答の種類
Microsoft Copilot 検索 の Copilot の回答は、Microsoft Copilot Chat を利用した AI によって生成された簡潔な応答です。 特定の自然言語クエリを入力すると、検索結果ページの上部に表示されます。
Copilot Answers には、オプションの接続されたクラウド バックアップ サービスや Web など、外部ソースからの参照や情報が含まれる場合があります。 そのグラウンディングは、Copilot Chat に対して有効にしたグラウンディングと一致しています。 Copilot 検索 と Copilot Chat が Bing 検索サービスを使用して、Web からの最新情報に基づいていくつかの回答と応答を作成する方法について詳しく説明します。
Copilot 検索 を使用すると、管理者は、特に organization に関連する簡潔で信頼できる結果を提供する回答をキュレーションすることもできます。 これらの回答は検索結果に直接提供され、organization の頭字語、ブックマーク、およびユーザーに関する情報を伝えます。
頭字語: 職場で使用される用語を定義します。
ブックマーク:Promote key resources in your organization.
People: 同僚の役割を明示し、彼らが organization にどのように適合しているかを示します。
詳細については、「 Copilot 検索の回答をキュレートする方法」を参照してください。
