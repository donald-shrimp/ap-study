このコースでは、PowerPoint、Word、Excel、Teams、Outlook などの Microsoft 365 アプリで一般的なプロンプト フローを学習するようにユーザーに説明します。 また、Microsoft Copilot Chatを紹介し、作業データと Web ベースのデータの違いについても説明します。
前提条件
学生は、Microsoft 365 サービスの基本的な機能体験をしたことがある必要があります。

このラーニング パス内のモジュール
Microsoft Copilot で作業する準備をする
Microsoft Copilot が Microsoft 365 アプリ全体で組織データと Web に応答を作成する方法、エージェントが複雑な複数ステップのタスクを処理する方法、エンタープライズ データ保護と秘密度ラベルによってデータを安全に保つ方法を理解し、4 つの要素からなるプロンプト フレームワークを適用して正確で有用な結果を得る方法について説明します。
追加
AI を利用したチャットで生産性を高め、創造性を解き放ちましょう
このモジュールでは、Microsoft Copilot Chat が、ファイル、会議、チャット、メール、ユーザー、および Web 間でコンテンツを操作するのにどのように役立つかについて説明します。
追加
AI を使用して効果的なプレゼンテーションを作成する
Idea Coach エージェントを使用した計画から作成、改良、配信準備まで、プレゼンテーションのライフサイクル全体にわたって PowerPoint の Microsoft Copilot を適用します。
追加
AI を使用してインパクトのあるドキュメントを下書きする
このモジュールでは、Microsoft Word の高度な Copilot の中級レベルの機能について説明します。 複数のソースからのドキュメントの起草、編集テクニックの適用、作文コーチ エージェントを使用した洗練されたプロフェッショナルなドキュメントの作成について説明します。
追加
AI を使用して会議の生産性を高める
このモジュールでは、Microsoft Teams で Copilot とファシリテーター エージェントを使用して、構造化された結果主導の会議を実行する方法を説明します。 会議の AI 設定を構成し、リアルタイムの議題管理と共同編集ノートにファシリテーターを適用し、インテリジェント要約を使用して意思決定をキャプチャして共有し、音声要約を使用して効率的に最新の状況を把握します。
追加
AI を使用して新しいデータ分析情報を明らかにする
このモジュールでは、「Copilot で編集」を使用した複数ステップのブックの作成、Python を使用した予測、Microsoft 365 と Web からの Graph ベースのデータエンリッチメント、アナリスト エージェントを使用したファイル間の探索など、Excel の Copilot を使用した高度なデータ分析について説明します。
追加
受信トレイから影響まで: AI を使用してメール ワークフローを改善する
このモジュールでは、Microsoft Outlook で Copilot を使用して大容量の受信トレイを管理する方法について説明します。 Copilot Chat を使用したメールのトリアージ、スレッドと添付ファイルの要約、手順の下書きを使用したパーソナライズされたメッセージの下書き、コーチングを使用して下書きを絞り込み、スレッドを会議に変換し、メッセージに詳細なフィードバックが必要な場合に作文コーチを使用してワークフローを拡張します。
