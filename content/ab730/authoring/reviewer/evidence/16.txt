注
Microsoft 365 Copilot の名前が Microsoft Copilot になり、Microsoft 365 Copilot Chat の名前が Microsoft Copilot Chat になりました。 一部のエクスペリエンス、ライセンス、機能は、移行期間中、引き続き Microsoft 365 Copilot と Microsoft 365 Copilot Chat を参照する場合があります。 組織のセキュリティ、コンプライアンス、プライバシーに変更はありません。
Microsoft Copilot Chatプロンプトと応答は、エンタープライズ データ保護を提供する Microsoft 365 サービス境界内で処理されます。 つまり、Microsoft Copilot で利用できるセキュリティ、プライバシー、コンプライアンスの管理とコミットメントは Copilot Chat にも拡張されます。 プロンプトと応答は、基になる基礎となる基礎モデルのトレーニングには使用されません。
プロンプト: ユーザーが事前に記述されたプロンプトを選択するか、Web からの Copilot Chat、Microsoft Copilot アプリ、Teams、または Outlook で独自のプロンプトを作成します。 プロンプトは、処理のために Copilot オーケストレーターに送信されます。 Copilot Chat では、Microsoft Copilot と同じオーケストレーターを使用してプロンプトと応答を処理します。 プロセス全体を通じて責任ある AI (RAI) の安全性チェックを調整し、監査/電子情報開示のために相互作用を記録します。
具体的な制御とポリシーは、基になるサブスクリプション プランによって異なります。
グラウンディング: Copilot は、Bing 検索サービスを介して Web グラウンディングを使用して入力プロンプトを前処理します (Web グラウンディングが有効な場合にのみ適用されます)。 Web グラウンディングは、プロンプトから生成されたいくつかの単語で構成される Web 検索クエリを Bing に送信して、応答の関連情報を提供します。 クエリは Bing へのセキュリティで保護された接続を介して送信され、ユーザー識別子やテナント識別子は含まれません。 Bing に送信された場合、これらのクエリには追加の契約上の保護が適用されます。 Web 検索クエリの詳細については、「 生成された検索クエリのプライバシーとセキュリティ」を参照してください。
Microsoft Copilot とは異なり、Copilot Chat はチャット エクスペリエンスの一部としてファイル、メール、チャットなどの組織のコンテンツに基づいているのではなく、Web からのデータのみに基づいています。 Copilot Chat ユーザーがチャットで組織のコンテンツを使用する場合は、次の 4 つの方法で実行できます。
プロンプトの一部として (コンテンツのコピーと貼り付け、「+」ボタンを使用したファイルのアップロード、チャット ボックスへのファイルのドラッグ アンド ドロップなど。これには、「/」と入力して ContextIQ メニューからファイルを選択する、ファイルを含む提案されたプロンプトの選択が含まれます)。
Outlook で Copilot Chat を使用します。 このシナリオでは、Copilot Chat は、メール、予定表、会議、チャット、限定されたファイル コンテンツ (OneDrive と SharePoint) などのユーザー データにアクセスできます。
組織のコンテンツにアクセスできる従量課金制エージェントを使用する。
組織データと Copilot Chat (この記事内) について詳しく説明します。
大規模言語モデル (LLM): Copilot は、関連する応答を生成するために、根拠に基づいたプロンプトを LLM に送信します。 Copilot Chat は、応答を生成するために複数のモデルを使用する場合があります。
ログ記録: ユーザーに応答を送り返す前に、プロンプトと応答の両方がログに記録され、監査/電子情報開示のために Exchange (Microsoft 365 テナント) に保存されます。
応答: Copilot は責任ある AI (RAI) の安全性チェックを調整し、アプリとユーザーに応答を返します。
次のビデオでは、Copilot Chat のプライバシー、セキュリティ、コンプライアンスの概要について説明します。 長さは 2 分 27 秒です。
プロンプトと応答のエンタープライズ データ保護
Copilot Chat は、プロンプトと応答にエンタープライズ データ保護 (EDP) を提供します。 EDP は Copilot Chat で追加料金なしで利用できます。 Copilot Chat は、ユーザー インターフェイスの上部の [New Chat] ボタンの横に緑色のシールドを表示することで、エンタープライズ データ保護が適用されることを明確にしています。
エンタープライズ データ保護とは、データ保護補遺 (DPA) および製品契約に基づくコントロールとコミットメントを指し、Microsoft がデータ処理者として機能する Microsoft Copilot および Copilot Chat のユーザーの顧客データに適用されます。
Microsoft Copilot および Copilot Chat でのプロンプトと応答のエンタープライズ データ保護の詳細を取得します。
生成された検索クエリのプライバシーとセキュリティ
応答の品質を向上させるために、Copilot Chat は Bing 検索サービスに送信される Web 検索クエリを使用して、Web からの最新情報を回答の基礎にすることができます。
Bing 検索サービスは Microsoft 365 とは別に動作し、プロンプトや応答に使用されるものとは異なるデータ処理方法を採用しています。 これらのデータ処理の方針は、各ユーザーと Microsoft との間で締結 される Microsoft サービス規約 と、 Microsoft プライバシーに関する声明によってカバーされます。 これは、Microsoft が独立したデータ コントローラーとして機能し、適用されるすべての法規およびコントローラーに対する義務に準拠する責任を負うことを意味します。 このアプローチは、 Bing に依存する他のオプションの接続エクスペリエンスと一貫しています。
Web クエリのデータ、プライバシー、およびセキュリティに関する詳細情報をご覧ください。
生成された検索クエリのしくみ: Copilot Chat はユーザーのプロンプトを解析し、Web 検索によって応答の品質が向上する用語を識別します。 これらの条件に基づいて、Copilot Chat は検索クエリを生成し、セキュリティで保護された接続を介して Bing 検索サービスに送信し、詳細情報を求めます。
この生成された検索クエリは、ユーザーの元のプロンプトとは異なります。これは、ユーザーのプロンプトによって通知されたいくつかの単語で構成されています。 アップロードされたファイルまたは Edge でアクティブに表示されているコンテンツからの追加用語は、Copilot Chat がユーザーのプロンプトを理解するためにそれらを必要とする場合は、応答を根拠にするために Bing 検索サービスに送信されることもあります。
次の情報は、Bing 検索サービスに送信される生成されたクエリには 含まれません 。
任意のユーザー識別子またはテナント識別子 (例: ユーザー名、ドメイン、テナント ID)
ユーザーのプロンプト全体 (プロンプトが非常に短い場合 ("地元の天気" など) でない限り)
Copilot Chat にアップロードされたファイル全体 (アップロードされたファイルは、エンタープライズ データ保護の一環としてユーザーの OneDrive for Business に保存されます)
Edge の Copilot Chat によって要約された Web ページ全体または PDF
生成された Web 検索クエリは広告主と共有されません。 また、Bing に送信された Web 検索クエリは、次のいずれにも影響しません。

Web 検索クエリの引用
生成された検索クエリの可視性を高めるために、Web 検索クエリの引用は、Copilot Chat 応答のリンクされた引用セクションにユーザーに表示されます。 このセクションでは、Bing 検索サービスに送信された (ユーザーのプロンプトから派生した) 正確な Web 検索クエリを示します。 正確な Web 検索クエリを表示すると、ユーザーは、プロンプトに対する Copilot Chat の応答を強化するために、検索されたサイトと共に検索された検索クエリを理解できます。 この情報は、ユーザーがプロンプトを改善し、Copilot Chat をより効果的に使用するのに役立ちます。 Web 検索クエリの引用は、チャット スレッドで 24 時間利用できます。
プロンプトと応答のログ記録

組織データ
Copilot Chat は、Bing 検索サービスのパブリック Web からのデータに基づいた生成 AI サービスです。 Microsoft Copilot とは異なり、Copilot Chat は特定の状況でのみ組織のコンテンツにアクセスできます。 ユーザーには、Copilot Chat を使用するために organization のコンテンツにアクセスする 4 つのオプションがあります:
オプション 1 – プロンプトの一部としてコンテンツを提供します。ユーザーは、Copilot Chat のプロンプトの一部として組織のコンテンツを提供できます。 次の方法で実行できます。
ユーザーは、この情報をチャットに直接入力または貼り付けます。
ユーザーはチャット ボックスの [+] ボタンを選択してファイルをアップロードします。 ファイルをチャット ボックスにドラッグ アンド ドロップすることもできます。 アップロードされたファイルは、エンタープライズ データ保護の一環としてユーザーの OneDrive for Business に保存されます。
ユーザーはプロンプトボックスに「/」と入力してContextIQメニューを開き、アクセス権を持つ特定のファイルを検索します。 これにより、ファイルがアップロードされたかのように、Copilot Chat が推論を行うためのプロンプトにファイルが追加されます。
ユーザーは、ユーザーがアクセスできるファイルを含むプロンプト ボックスの下から、提案されたプロンプトを選択します。 ファイルを含む推奨プロンプトは、操作信号 (ファイルがユーザーとアクセス、変更、共有されたかどうかなど) とファイルのプロパティ (ユーザーがファイルを作成または最後に更新したときなど) に基づいてユーザーに表示されます。
オプション 2 – オープン コンテンツで Copilot Chat を使用する: 一部のシナリオでは、Copilot Chat はユーザーのオープン コンテンツを認識し、これにより Copilot Chat がそれと関わることができます。 これは、次の状況で発生することがあります。
Word、Excel、または PowerPoint エージェントを使用する場合、Copilot Chat はファイルやスプレッドシートなどのユーザーの開いているコンテンツを認識します。 これにより、ユーザーは Copilot Chat の使用中に、質問したり、コンテンツを生成したり、その他の方法でそのコンテンツと連携したりできます。 Copilot Chat は、ユーザーが開いている特定のコンテンツのみを認識し、ユーザーが提供しない限り他の作業データにアクセスできません。
Microsoft Copilot モバイル アプリを使用し、ファイルで提案されたプロンプトを選択すると、Copilot Chat はファイルのコンテンツを応答の一部として使用します。
Edge で Copilot Chat を使用する場合、ユーザーまたは管理者によって [Web ページまたは PDF へのアクセスを許可する] 設定が有効になっていて、ブラウザーでイントラネット ページが開いている場合。 このシナリオでは、Copilot Chat はこのページのコンテンツを使用して質問に答えることができます。
オプション 3 - Outlook で Copilot Chat を使用する: Outlook の Copilot Chat は、ユーザー データにアクセスして、関連する応答を提供できます。 アクセス可能なユーザー データには、メール、予定表、会議、チャット、ファイルが含まれますが、これらは以下の境界に制限されます。
ユーザーの OneDrive およびアクセス権を持つ他の OneDrive ファイル内の Files
よくアクセスする SharePoint サイトからの Files
Files that was shared with directly with them
ユーザーが表示、編集、または作成した Files
これにより、ユーザーは Outlook で Copilot Chat を使用するときに、受信トレイに関する質問、メールの優先順位付けとトリアージ、今後の会議の準備などを行うことができます。 Copilot Chat が応答で使用するユーザー データには、字句インデックス作成を介してアクセスします。 Work IQ およびセマンティック インデックス作成の一部としての完全な作業データへのアクセスは、Microsoft Copilot ライセンスを持つユーザーのみが利用できます。
オプション 4 – 組織のコンテンツにアクセスできるエージェントを使用します。ユーザーは、SharePoint や Microsoft 365 Copilot コネクタ コンテンツなどの共有テナント データに基づいているエージェントを介して組織のコンテンツにアクセスすることもできます。 これらのエージェントを使用している間、ユーザーはエージェントがアクセスできるデータまたはコンテンツについて Copilot Chat にプロンプトを表示できます。
エージェントの検出、作成、または利用について詳しくは、こちらをご覧ください。
Copilot Chat では、基礎モデルのトレーニングにデータは使用されません。

Word、Excel、および PowerPoint エージェントでのファイルの生成
Copilot Chat を使用すると、ユーザーは Word、Excel、PowerPoint エージェント内のプロンプトからファイルを生成できます。 Copilot Chat によって生成された PowerPoint プレゼンテーションは、ストレージが使用可能な場合、ユーザーの OneDrive に保存されます。 Copilot で生成された Word ドキュメントと Excel ブックは、ユーザーがダウンロードできます。 OneDrive ストレージが利用できない場合は、PowerPoint プレゼンテーションをダウンロードすることもできます。
一般データ保護規則 (GDPR)
2018 年 5 月 21 日の Microsoft のブログ記事では、GDPR コンプライアンスに対するコミットメントと、Microsoft が企業やその他の組織が GDPR の義務を果たすのをどのように支援しているかについて概説しています。 エンタープライズ データ保護により、Copilot Chat は GDPR をサポートしています。
Microsoft の製品とサービスを使用する場合の GDPR の詳細をご確認ください。
EU データ境界 (EUDB)
LLM への Copilot Chat 呼び出しは、リージョン内の最も近いデータ センターにルーティングされますが、使用率が特に高い場合は、より大きな容量を使用できる他のリージョンに呼び出すこともできます。
欧州連合 (EU) ユーザーの場合、Copilot Chat には EU データ境界に準拠するための追加のセーフガードがあります。 EU のトラフィックは EU データ境界内にとどまりますが、世界中のトラフィックは LLM 処理のために EU やその他の国や地域に送信できます。
Copilot Chat データ所在地のコミットメントについては、Microsoft 製品利用規約とデータ保護に関する補遺に記載されています。
Copilot Chat から Bing に送信される Web 検索クエリは、EUDB に準拠していません。
Microsoft が生成された検索クエリを処理する方法の詳細をご覧ください。
